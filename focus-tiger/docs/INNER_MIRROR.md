## 0. 大白话

Thought Drop / 觉察一句已经能让人写下心里闪过的一句、被固定句接住。那是**第一层**：不是聊天、不存原文、不当日记。

**Inner Mirror（内在镜子）是同一入口上默认关闭的第二层。** 只有用户明确点过「留下」，本机才保存那一句。攒过一段时间之后，用户**自己点开**，镜子用本地记录帮他看见自己前后说了什么——不贴标签、不替他解释自己是谁。

用户说「我不完全这样认为」时，镜子改口并记住这次纠正，以后不得再搬出被否定的判断。关授权或点「忘掉」后，原文和纠正记录一起真删，镜子当场空白。

## 1. 一名 · 四看 · 一层入口

对外统一名：**Inner Mirror / 内在镜子**。禁止再拆成四个产品或四条任务线。

四种回看是**同一面镜子的看法**，不是四个 App：

| 对外名 | 人话 | 本锁时点 |
|---|---|---|
| **Weekly Inner Reflection** | 这一周留下的话里，重复出现了什么 | **首包后第一刀**（用户点开才出） |
| **「攒完问一句」** | 周回看里可选的一句开放问（解释权在用户） | 与周回看同刀或紧随 |
| **Monthly Growth Reflection** | 近一个月 vs 再前一个月，用词有没有不一样 | 周回看稳定后 |
| **Personal Pattern Journal** | 镜子用过、**用户纠正过**的主题清单 | 随纠正权进第一版数据面；不做新日记本 UI |
| **Moments of Change** | 用户自己点「这是一次改变」 | 只由用户标记；可与周回看同期补；**禁止** AI 自动颁发 |

**不挂在成长旅程圆点上**（圆点只读坐下分钟，见 [`GROWTH_JOURNEY.md`](./GROWTH_JOURNEY.md)）。

## 2. 两层同一入口（不修改第一层承诺）

| 层 | 行为 | 存原文 | 开口 |
|---|---|---|---|
| **第一层（已锁 · 首包）** | 写下 → 固定句接住 | **不存**（哈希 / 计数；不翻旧留言） | 当场固定句；**不**自由生成 |
| **第二层（本锁 · 默认关）** | 用户点「留下」才进本机日志 | **只存主动留下的句子** | 用户点开周回看才出；失败则不显示，不挡静坐 |

第一层条文仍以 [`NOTICING_ONE_LINE.md`](./NOTICING_ONE_LINE.md) 为准。本锁**不得**被读成「可以把默认 Thought Drop 改成日记」。没有第二层授权，镜子退化为阿寅记忆摘要——**做不到**「三次提到批评」；PO 已接受该张力，用独立第二层解开，而不是改第一层。

职责禁止混：

- **不是** Reflection Companion shipping（练完再照一次；实验室名 second mirror，对外不抢 Inner Mirror）。  
- **不是** 重开倾诉 / 桌面现场生成进用户气泡。  
- **不是** Daily Noticing（每日结构问句；自我觉察入口）。镜子 = **自我理解**回看。

## 3. 授权（三勾 · 分期）

缺授权不读。默认全关。

| 勾 | 数据 | 分期 |
|---|---|---|
| **1** | 用户点过「留下」的 Thought Drop 原文 | **第一期唯一数据源** |
| **2** | 到达 / 回顾 / 觉照打卡 | 最后评估，**可能不做** |
| **3** | 对话（倾诉原文） | 风险最高；最后评估，**可能不做** |

第一期禁止静默并入勾 2 / 勾 3。不进练习备份白名单、不进研究共修上传、不上云。

## 4. 三条硬约束（实现 Brief 必须可检验）

### 4.1 纠正权持久且可检查（灵魂）

用户改写或作废的观察，**之后模型不得再提**。须有结构化记录（主题 id、状态：active / corrected / void、用户替换句），用确定性闸拦截，**不能只靠提示词**。界面须能看见「这条已按你的意思改过」。

### 4.2 数据不足要诚实；主题用规则

不够条数 / 不够重复 → 固定诚实句「还不够」，**禁止编造**。次数与主题归类用确定性规则（重复词、计数、时间窗），**不让模型自由归纳主题**。模型最多在规则已锁定的主题上把句子写成观察式问话或并列事实。

允许：「过去一个月，你留下的句子里有三次写到面对批评时不舒服。最近两周，同样主题里，你写得更多的是自己怎样说出不同意见。」  
禁止：「你变得更有耐心 / 你在克服自卑 / 回避型人格好转。」（V5、C-01）

时期对照沿用已拍板的 **Bounded Temporal Compare**：两窗并列事实，禁止人格进步判词。

### 4.3 「忘掉」是真删

关授权或忘掉 → 留下的原文 **与** 纠正记录一并清空；镜子当场空白。禁止软删除当完成、禁止备份里残留第二层原文。

## 5. 开口纪律

- **用户点开才出**（Weekly 默认不推送、不连签、不功课化）。  
- 电脑宽屏、本地；失败不显示，不挡静坐。  
- 危机句不进回顾（现网安全层；不把高危原文当成长材料）。  
- 周回看可选「攒完问一句」：只问开放问题，不给结论、不进入新一轮倾诉。  
- 第 3 步验收门槛（失败则关门，沿用觉察一句纪律）：纠正后的观察不再出现；输出无人格/进步判词；数据不足诚实提示。
