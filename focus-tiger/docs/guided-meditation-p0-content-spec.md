## 1. 原创脚本结构模板

每课同一骨架，时长靠「静默秒数」拉开，不靠加教条。

| 段 | 目的 | 时长比例（约） | 写法约束 |
|---|---|---|---|
| 落座 | 姿势、可闭眼可睁眼、随时可停 | 10–15% | 不命令「必须」；给许可 |
| 锚定 | 呼吸或房间里的声音 | 25–30% | 只指一个锚；不讲生理学 |
| 走神 | 承认念头会离开 | 15–20% | 不评判「失败」 |
| 拉回 | 回到锚，可重复 1–2 轮 | 25–35% | 短句；句间留白 |
| 收尾 | 睁眼/活动手指、结束 | 10–15% | 不承诺变好、不布置作业 |

**长度规格（口播，不含过长器乐前奏）：**

| 课 | 口播目标 | 句数（单语，约） | 静默 |
|---|---|---|---|
| 3 分钟呼吸锚定 | 2:40–3:10 | 12–18 | 句间 3–8s |
| 5 分钟身体与声音 | 4:40–5:20 | 18–28 | 句间 4–10s |
| 10 分钟完整练习 | 9:20–10:20 | 28–40 | 可有 20–40s 无词段 |

## 2. 候选三课大纲（不是成稿）

### 课 1 · 3 分钟呼吸锚定（冷启动若将来直达，用这一课）

- 落座：脚、手、不必改呼吸。
- 锚定：鼻端或胸腹一起一落，选一个就好。
- 走神：发现走了就标记「想」，回来。
- 拉回：再跟 4–6 次自然呼吸。
- 收尾：抬眼，结束。

### 课 2 · 5 分钟身体与声音觉察

- 落座 + 可睁眼看光线。
- 锚定：接触点（椅、地面）或室内一声。
- 走神：声音与念头都可出现。
- 拉回：回到接触点。
- 收尾。不做「扫描全身治疗酸痛」叙事。

### 课 3 · 10 分钟完整练习

- 落座更从容。
- 呼吸锚 → 短静默 → 走神/拉回两轮。
- 收尾含「练习到这里即可」。
- 不做慈心、创伤暴露、身体扫描医疗版（那些属 P3，另审）。

## 3. 语音来源对比

| | 运行时 TTS | 预渲染高质量 TTS | 真人录音 |
|---|---|---|---|
| 音质/停顿 | 差；系统音色；newest-wins 会切句 | 可控；可留白 | 最好 |
| 商用授权 | 系统 TTS 条款因 OS 而异；Web 无桥 | **须书面**：再分发 mp3、en/ja、应用内播放 | 合同 + 肖像/声纹 |
| 体积 | 0 音频文件 | 约十几到几十 MB / 3 课双语文 | 同左或更大 |
| en/ja | 桌面 en-US / ja-JP 映射已有；Web 无 | 一次做两语文件 | 两语演员 |
| 与字幕同步 | **不满足** | JSON cue **满足** | 满足 |
| MVP | 否 | **是（最合理）** | P3，留存数据好再上 |

现网 `systemTtsBridge.js` 明确 Web 无桥，且为倾诉/结束句设计，**不适合**冥想。
