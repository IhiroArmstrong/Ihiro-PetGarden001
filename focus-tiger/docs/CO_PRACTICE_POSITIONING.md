## 0. 大白话

Focus Tiger 仍然是一只陪你练习专注和觉察的小老虎。可以再加一句「我们一起练习」。这不是新按钮，也不是「干活模式 / 修行模式」两套界面。

现在只有一件事是真的：人在练，Yin 陪着坐。Yin 按这个人把话说得更合适，产品里还没有。所以不能先说「Yin 懂你」或「已经证明有用」。功能做出来、写进下面的「已实现」之后，才可以如实说。

## 1. 定位（叠加，不替换）

| | 说法 |
|---|---|
| 原定位 | 正念数字伙伴。帮人回到当下、练习专注，按自己的节奏。 |
| 叠加层 | 人机共修：人和 Yin 一起练习。人练习觉察；Yin 陪着安静。 |
| 不是 | 替换成宗教产品、治疗、禅师开示，或一套新的功能入口。 |

对外可以分两层讲，不必同时把两层喊满：浅层仍是专注与正念练习；深层是「一起练习」的陪伴方式。差异化要靠做出来的适应，不靠提前许诺。

---

## 2. 现在可以说 / 现在不能说

**可以说**

- 一起练习、陪着坐、不催、不评判。
- 产品会记住你上次选的专注时长，下次时长条按这个回显（见下表）。不要加成「Yin 因此更懂你」。
- 练习结束可以自己点「顺 / 乱 / 倦」。这是你的话，不是分数。

**不能说**（直到对应行变成「已实现」，并且文案过了契约）

- Yin 在适应你、越来越懂你、只有 Yin 懂你。
- 共修已经被评估为有效、有共修成功分。
- 倾诉原文会用来训练 Yin。
- 专注进行中可以向 Yin 倾诉。
- Yin 看出你熬夜、连续熬夜多少小时、该改善作息。

「Yin 不是治疗师」已经写在问号简介里（不能替代咨询师 / 治疗师 / 医生）。用户可见文案里还没有「不是禅师」这几个字。那是以后单独的文案改动，不写进本页的界面。

## 3. 已实现 / 未实现

功能上线后只改本表，再放开对应的话。研发用评测集调倾诉，不算用户侧的「Yin 在学习」。

| 能力 | 状态 | 依据 | 可以说的话 |
|---|---|---|---|
| 一起坐、不催、不评判 | **已实现** | 定位；契约 C-04、C-07 | 一起练习；慢慢来 |
| 下次时长条回显上次选的分钟 | **已实现** | `focus-tiger.focus-duration-pref.v1`；场景 T | 只可说「还是上次的时长」。这句话本身尚未写进界面，见 **T59** |
| 结束时自己点顺 / 乱 / 倦，只存本机 | **已实现** | **T52** #1424；`awakenCheckInStore.js` | 你点过哪一种。不说分数，不说性格 |
| 到达时选过的情绪有本机记录 | **已实现（仅记录）** | `appendArrivalNoticeSignal` | 不得说「下次仪式会按上次的心情预选」——现网不会预选 |
| Privacy「改进产品」研究数据分享开关 | **已实现** | **T54** 分享刀 #1434；Brief #1432。上送只有计时专注的去身份计数（坐完与否、后来有没有回来）+ 重装即作废的研究代号。**不含倾诉原文**、邮箱、付款。说明页已写「没有倾诉原文」 | 只可说用户自愿开关与说明页口径；不得说已证明干预有效；不得说分享了倾诉 |
| 邀请被忽略或拒绝后，这类邀请变少 | **未实现** | **T57** 记下场；**T58** 才变安静 | 不得说 Yin 会少问 |
| 按「倦」把下次建议时长放短一点，仍须自己点 | **未实现** | **T58**（第一版只用倦，不用乱；手动选过的分钟优先） | 不得说 Yin 已按你的状态调好了 |
| 看得见、改得了、忘得掉的小本子 | **未实现** | **T58**；并进既有旅程记忆，不另建模块 | 不得说 Yin 记得你是怎样的人 |
| 按倾诉原文学习说法 | **不做** | 倾诉不存原句；本页维持 | 不得暗示 |
| 专注中打开倾诉 | **不做** | 生成只在空闲、且由你打开 | 不得暗示 |
| 适应或共修「已被证明有效」 | **未实现** | **T54** 分享开关（已合）与 **T54** 90 天实验（搁置）是两行。开关已合 ≠ 开工实验。口令「开工 T54」「做 90 天实验」仍不执行 | 不得说已评估有效 |
| 作息提醒（Yin 判断熬夜并开口） | **未实现** | 盘点 [`late-night-behavior-inventory.md`](./late-night-behavior-inventory.md)。深夜披毯与 0–6 免责不是睡眠诊断。用户自设收工时间 = **T61**（Brief 待点头；须 T60→T57→T58 已合）。晚间练习事实 = **T62** 暂不做 | 不得说 Yin 看出你熬夜 |
