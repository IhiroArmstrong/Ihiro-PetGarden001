# Confide · 工作约定（一页）

> 配套：[现行一页](./CONFIDE_NOW.md)。本页取代「按文件封存、额度、再开一套关卡」的开工方式。  
> 产品红线仍在 [`PRINCIPLES.md`](./PRINCIPLES.md)（英文第一、禁止按症状加词表、不贴心理标签）。本回合 **不改** `.cursor/rules`。

## 1. 任务合同（开工只贴这 8 行）

```
目标：一句话的用户可见结果
只许改：文件或目录
禁止：不许新增词表、不许开新任务、不许新开封存集
验证：一条命令加黄金脚本里的哪几句
完成条件：点名句子的对错，或一个写死的数字。禁止写「明显上来」
时限：N 小时或 N 个提交
交接：结束时只写 5 行（做了什么、证据、未完、风险、下一步）
默认选项：遇到分歧按「缩范围、不加流程；新想法只追加停车场一行」走
```

没有这 8 行，只许读、不许改倾诉代码。会改用户听到的回复才写 Brief，**一页为限**。影子和纯文档不写 Brief。

## 2. 会话纪律

- 同一时间只有一个实现会话改倾诉代码。
- 代号只由治理会话分配。别的会话只写任务名，不许自己编 T 号。
- 现行实现只排 **T14** 支持入口，接着 **T17** 事实卡判定一刀。**T16** 黄金脚本 v1 待合入。**T15** 诊断结论已交；10/19 只补四批英文占比一行，不占现行名额。
- 不开新 Brief，除非就是 T14 或 T17 里会改用户听到的回复的那一项。
- 衍生想法只往 [`CONFIDE_NOW.md`](./CONFIDE_NOW.md) 停车场追加一行。升到现行必须同时满足：不做它这次放行就过不了，并且完成线已写死。缺一条就留下。
- 到完成线就停。不自己判断下一步，不新开任务。开发中每一刀不要求未见题；固定句子可看可调。
- 会话开头只读主干上的 [`CONFIDE_NOW.md`](./CONFIDE_NOW.md)。工作副本和旧术语表不作现行。
- 记账不单开 PR。状态和决定一周由本治理会话合并一次。
- `.cursor/rules` 里的倾诉条文不再加，除非出了真实事故。
- 你每天在倾诉上最多 1 小时；每周复盘 30 分钟。

## 4. 默认推进

给出推荐方案后，**24 小时内没有反对，就按推荐做。**「待你决定」只留真正卡住的事。专业复核日期已拍板：**2026-10-20（周二）**。

分歧时的默认：缩范围，不加流程；不追分类器把间接危机做到九成；上线看黄金脚本，不看封存通过率。出口已经安全时，识别率的残余缺口不挡放行。

不收回「放行时再跑一份新的封存集」（安全最终一次除外）。不把已经定下的现行三条收成一条；同一时间仍只有一个实现会话在改代码。

## 5. 规则合并稿（Agent 读这一节即可）

| 还生效 | 一句话 |
|---|---|
| 英文唯一放行语言 | 欧美市场：验收、黄金脚本、手测、专业复核以英文为准；中文只记录对照，不挡放行。禁止只测中文就说通过。 |
| 禁止症状词表 | 不得为当天的问法新增正则、关键词、别名或意图桶。 |
| 四条通道 | 安全 → 个人事实 → 产品问 → 其余情绪或生成。前面命中就停。先不缩到约 10 张卡；判定一刀不过才缩。 |
| 先批量后肉眼 | 能一条命令跑完的，先跑命令。请人只看黄金脚本里点名的句子和手感。 |
| 用户可见才写 Brief | 改用户听到的回复、等待或路由：一页 Brief，点头后再改。 |
| 安全最终一次 | 只保留专业人士定标准的那一次。其余不封存、不占额度。 |
| 完成线 | 黄金脚本英文 60 句全对且「不得出现」0 次；安全英文句 0 漏判、0 误转介。到线就停。禁止「明显上来」。10/31 未到线直接从三选一（降目标、延期、再砍产品问答）选一个，不开讨论。 |
| 出口已安全 | 诚实空态或情绪生成已接住、且英文安全句没漏时，识别率缺口不挡放行。 |

**不再执行：** 按盲测文件计额度、每份一次机会、用封存通过率证明泛化、函数 A、路由仲裁 v1、为不过关再出一份新封存集。
