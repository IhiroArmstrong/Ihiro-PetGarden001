# Focus Tiger · Slack Community Guidelines

> **状态：公约草案（2026-08-29）** — Early Yin Community / culture laboratory 的运营约定。  
> **性质**：Slack workspace 人工运营与 pinned 文案依据；**不是** App 运行时、不新增 entitlement。  
> **IA SSOT**：五空间架构见 `FROM_APP_TO_CULTURE.md` §8.2–§8.4。  
> **入口**：App 菜单 **Join our community** → `communityLink.js` 永不过期 Slack 邀请链接（2026-08-29 已接线）。

---

## 1. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 约 **100 个真正在乎** Focus Tiger 理念的人的炉火实验室 | 5000 挂名成员的「社区平台」 |
| 安静、克制、可缺席的共享在场 | 另一个信息噪音源 |
| 验证文化假设（见 `FROM_APP_TO_CULTURE.md` §10） | App 内社交功能的替代品 |
| Yin 作为 spirit / companion 的在场 | Yin 作为客服或版主催更 |

对外可称 **Early Yin Community** 或 **culture laboratory**。**禁止**宣传成已上线的 App 内社区。

## 3. Quiet Room 规则

Quiet Room 是 Focus Tiger Community **最有差异化的空间**。

**鼓励**

- 只发 🌙、一个句号、或 “Here for a moment.” / “Just being here.”
- 共同安静练习时段的轻量在场（“Starting a 25-min sit.” 即可，不必汇报结果）
- 读完就走，**不必回复任何人**

**不鼓励**

- @channel 或 @here 催回复
- 「你怎么还不说话？」类社交压力
- 长文辩论、热点搬运、meme 刷屏
- 把 Quiet Room 当 `#general` 用

**Moderation 原则**：Quiet over noisy。若某帖让空间变吵，温和移至 `#the-den` 或删除，并私信说明——不公开评判。

## 4. Support 分流（Slack ≠ 客服）

以下问题 **不要** 在 Slack 任何频道提问（含 `#the-den`）：

| 类型 | 请走 |
|---|---|
| Bug / 闪退 / 功能异常 | App 内 **Support FAB** 或 GitHub Issues |
| 付款 / 订阅 / 退款 / entitlement | 邮件 **hello@twinsology.com** |
| Feature request | GitHub / 邮件（Slack 可**旁听**文化讨论，不当工单队列） |
| 账号 / 数据恢复 | 现有 OTP / 练习备份流程（见 App 内说明） |

`#focus-and-flow` 的 **Questions & Insights** 只收**实践类**问题，例如：

- ✅ “What helps you enter flow?”
- ✅ “What do you do when you can't focus?”
- ❌ “App crashed on iOS 18.”
- ❌ “I paid but didn't get Sanctuary.”

---

## 5. 隐私红线

**禁止**在 Slack 发布（含截图、转述、摘要）：

- Private reflections（Reflect 私密内容）
- Personal Memory / Confide 对话明细
- Journey Log 完整导出或 AI 对话记录
- 他人未同意分享的练习数据

**可以**（自愿、片段、观察式）：

- “I focused for 25 minutes today.”（自己的 moment，适合 `#journey`）
- 自己选择分享的一句 Reflection 或 Quiet Line 片段
- Ambient 文件名或自制 soundscape 的**链接**（注意版权）

原则：**Personal before social**（`FROM_APP_TO_CULTURE.md` Culture Principle 04）。App 不会自动同步任何私人数据到 Slack。

---

## 6. 发帖语气（与产品一致）

- 观察式、邀请式、可跳过；不说教、不追因、不贴「你不够专注」
- **禁止**连续打卡绑架、公开分钟数排行榜、FOMO 共修
- **禁止**把寅币余额、清供数量当社交财富炫耀
- Small Wins 留在 `#journey` 子讨论里，**不要**单独开打卡竞技场

Yin 的留言（`#the-den` · Yin's Messages）是陪伴语气，不是运营广播或促销。

---

## 7. 频道治理

- **一级空间封顶 5**：不新增 `#general` / `#random` / `#announcements` 等。新需求用 thread 或 pinned collection。
- **Newcomers 防闲聊化**：Welcome / How it works 做成 **pinned + 只读**（Slack 权限或定期归档）；活跃对话引导至 `#the-den` 或 `#focus-and-flow`。
- **The Den 子区**：Community Chat 与 Casual Conversation 若重叠，可合并为一个 `#the-den` 主频道 + thread，避免二级频道膨胀。
- **邀请**：当前使用永不过期 shared invite（`communityLink.js`）。大规模公开宣传须另拍板（目标仍是 ≈100 真在乎的人）。
