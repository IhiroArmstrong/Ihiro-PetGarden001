## 0. 大白话

练习走得够久，可以留下一张**永远不进货架**的画。这不是星巴克金星礼，也不是「恭喜升级」。

Yin 已经会变安静、会改默认时长建议。这仍**不等于**「已适配到某个里程碑」。发画若要体现共修，必须用下面的 B 和 C，不能把适应开关打开当成成就。画名和句子里不得出现晋级、够格、懂你、共修成功，除非口径表那一行已经写成「已实现」。

## 1. 为何单独成线

纪念印和静思典藏已经是「练到点，出一个纪念物」。本线值得做的**唯一**理由：它能接上 **T57** 邀请下场和 **T58** 适应层的**可审计共修证据**，礼物是一张画，不是印、不是诗。

若实现时最后只靠累计分钟（只有条件 A），本线停工，改去加强纪念印，**禁止**再开一条换皮奖。

| 轨 | 怎么得到 | 目录 |

## 4. 礼物形状

- 新画 **3～5** 张，独立 kebab-case id，新预览图，一句短故事。
- 一次只发一张；发过不收回；中断练习不撤画。
- 两张之间须有**冷却间隔**（形状：上一张发放日之后，须再满足该档的 B 窗口；数字后定）。
- 出卡强度 **不超过** 每日首次 `Celebrating`：坐完后安静出卡，可关，不挡菜单逃生舱。与芥子印 / 纪念印同一仪式队列时，本画出卡排在它们**之后**，同一次完成最多一张画。
- 本机键建议名：`focus-tiger.co-practice-gift-art.v1`（实现时登记进 `FOCUS_TIGER_LOCAL_STORAGE_KEYS`；**T60 漏登过先例，本键必须进删除所有数据白名单**）。
- **不进**研究分享白名单（不得进入 `T54_RESEARCH_RECEIVE_FIELDS`）。
- 不要求邮箱，不走 Stripe，不下在售套的高清桶。
- 导入备份是否带走已发的画：**待定**，与成长旅程「阶段下限是否随备份带走」**同一口令一起定**。未定前实现只写本机，不进练习云备份六/七 key。

## 5. 触发接口（只写形状，不写数字）

核心：**不量化「Yin 懂你多少」**。只量化可审计的行为回合。不向用户展示共修分、命中率条、等级条。条件 C 只当后台二值门。

不用采纳率当门槛（会诱导 Yin 越来越爱推建议）。

### 条件 A · 练习底盘

| 项 | 形状 |
|---|---|
| 读什么 | `scoreEligibleLifetimeMinutes` 的**本机高水位**（与成长旅程圆点同源；沿用每天 180 分钟封顶） |
| 不读什么 | 成长旅程阶段名；会变少的 `practiceDayCount`；`scoreFormula` 新消费者 |
| 错开 | 分钟门槛**必须避开** 35 / 360 / 720 / 2160，否则等于阶段奖换皮 |
| 作用 | 证明「练过，且不是一天刷完」 |

Honesty 补登计入分钟的规则与莲花池现网一致，不另开一套「真假专注」。

### 条件 B · 共修回合的独立日数

一个**共修回合**必须是可验证的往返，且**三件都真**：

1. Yin 给过一次具体的邀请**或**时长默认（见下表通道）；  
2. 用户有过一次明确响应（不是自己消失）；  
3. **同一场**后来真的坐完（计时达标或 Honesty 补登完成）。

| 通道 | 现网数据 | 算不算 B |
|---|---|---|
| 专注中邀请（停一下 / 再坐一会 / 长坐舒展） | **T57** `accepted` **且同一场坐完** | **计入 B**。仅有 `accepted`、当场未完成 → 不算 |
| 时长条上 Yin 出示的默认档 | 当场出示的建议分钟 + 这场坐完 | **可计入 B**。只回显「上次选的」、适应层未改默认 → **不算**（那是 T59 记忆，不是适配） |
| 觉照邀请（T51） | 邀请出过 | **默认不计入**。另 Brief 才能算 |
| 收工邀请（T61 / T57 `work-end`） | 下场记录 | **默认不计入**。收工不是共修坐完 |
| `dismissed` / `ignored` | T57 | **不算**回合。只给变安静，不发画 |

**现网缺口（必须写进实现 Brief，不得假装已经能算）：**

- T57 行只有 `kind` / `outcome` / `ts`，**没有场次 id**。禁止用「那天 accepted 过、那天另有一场完成」冒充同一场。v2 须补接合键（场次 id 或等价）。
- T58 状态是开关、暂停、手动锚点，**没有**「这场出示的默认分钟 vs 实际坐完分钟」流水。C 在补这条账之前恒不可算。

计数形状：

- 每天最多 1 次（日历日，本机时区）。  
- 数的是**窗口内累计独立日数**，不是连续天数（每周深练不被罚；无断签压力）。  
- 窗口须有跨度下限（挡住短期集中刷）。日数、窗口长度、档差 **后定**。

接合键补上之前，B 接口存在但**不可发放**（算不出来就当假）。

### 条件 C · 默认命中（「适配到某个程度」的量化）

记录 Yin **当场出示的默认分钟**，对比用户**这场实际坐完的分钟**。

| 项 | 形状 |
|---|---|
| 命中 | 实际分钟落在当场默认的相对带宽内（带宽后定；分析师建议量级 ±20%） |
| 样本 | 最近 N 场已完成的坐（N 后定；分析师建议量级 ≥10） |
| 门 | 命中比例达到阈值（后定；分析师建议量级 0.7）则为真，否则为假。**不展示该比例** |
| 关适应 / 按种类暂停 | **C 为假**。Yin 没在学，就不发「一起走的画」 |
| 时段 | **预留槽，T58 v1 没有**。不得发明「Yin 猜你在哪一小时练」。T61 收工钟也不是时段默认。要做时段须另 Brief |
| 不用 | 情绪标签、顺/乱/倦当命中、熬夜判断、倾诉原文 |

C 衡量的是 **Yin 预测准不准**，不是用户听不听话。用户改档再坐，只要实际分钟仍落在**出示默认**的带宽外，本场不算命中——不因此催他去点「接受」。

场次默认分钟账补上之前，C 接口存在但**不可发放**。

### 合取与分期

| 版 | 发放 | 文案 |
|---|---|---|
| **v1（可先做）** | **仅 A**。先能发出一张「练出来的画」 | 只说练过、留下一张。不说适配 |
| **v2（本线成立的理由）** | **A ∧ B ∧ C**。须先补接合键与场次账 | 仍不得说懂你。可说一起走的一张，须先改口径表 |

**我认为最合理的实现序：** 不要先发一版纯 A 的画就停——那只是换皮纪念印。若第一刀就要上用户可见出卡，**直接做 v2**（补账 + A∧B∧C + 新画）。若只想先锁数字、不出卡，可先做 persona 表和接合键，仍不出画。

发放分期 ≠ 文案分期。门即使用了 B/C，句子仍受 C-11 管。

第 1 张到第 4 张：B 的日数、C 的门、A 的分钟逐档略升；A 始终错开阶段点。具体数字走成长章程 **persona 回归表** 再拍板，本锁不写死。

Persona 验收形状（数字后填）：

| persona | 期望 |
|---|---|
| `steady-light` | 合理时间内能拿到第 1 张 |
| `single-binge` / `single-binge-extreme` | 拿不到（A 日封顶 + B 独立日数挡住） |
| `deep-weekly` | 能拿到（所以 B 数独立日不是连续日） |
