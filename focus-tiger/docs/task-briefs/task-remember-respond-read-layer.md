## 0. 大白话

Yin 已经会记住你上次坐多久，倦的时候建议短一档，你不要某类提醒就少说几天。可是这些记事分散在好几本小本子里，开表、观察纸、旅程、收工、配方各翻各的。人感觉不到「越来越懂」，多半是因为没有一条看得见的「记住 → 问你一声 → 再改默认」。

这一份书先锁 **读侧**：一本只存事实的本地账、所有入口只从一个读门拿默认。点头后第一刀只做「记住」和读门，不新发明传感，不说懂你。

## 2. Resolver 契约（第一刀必须写进单测）

给定同一份本机存储，下列问法必须得到同一组答案（纯函数，不读 DOM）：

- `preferredFocusMinutes`（高亮档）  
- `lastManualAnchorMinutes`  
- `habitualFocusMinutes`（同一档 ≥3 次才有，否则 null）  
- `adaptationEnabled`  
- `tiredSuggestsShorter`（沿用 T58：近 5 次结束倦 ≥3）  
- `latestEndCheckInLabel`（ease / restless / tired / null）  
- `workEndClock`（用户自设或 null）

**禁止** `sittingSessionPromptHost`、配方、芯片、接合账入账再各读生键。第一刀至少把 **芯片高亮 + T67 offeredDefault + 配方写回后的下次读** 收进同一函数。配方 **写** 仍可写 `focus-duration-pref`，但写完后的「下次出示」必须再走 resolver（这样锚点/习惯规则只有一处）。

「≥3 次同一选择」计数只认 **手动点芯片**（与 T58 锚点同一事件），不认「没拨就开表」。
