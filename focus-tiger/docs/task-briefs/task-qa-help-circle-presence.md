# QA · Help Close、在线人数、痕迹回复、灯笼、两张玻璃卡

PO 2026-10-11 书面决定。一次只在一个圈里。不画圈子网络。

## 已好清单

- 坐下成功仍只在圈子面板里出现「你坐下了」。灯笼只表示别人正在打坐，不表示应用开着。
- 菜单和提示条不占两张玻璃卡的名额。
- 同一台设备重新打开，仍是原来的成员，不新占一个座位。

## 行为

- Help Center 的 Close 当次就把卡片藏起来。
- 圈子人数是最近约 50 秒内还连着的人。关掉浏览器或断线后，人数下降（离开请求送到就马上降，否则最多约 50 秒）。
- 八人上限按在线人数，不按历史上留下的空名单。
- 已经在一个圈里时，座位码输入框消失。想进另一个圈，先离开。客户端直接拒绝，不自动退出。
- 自己留下的痕迹，没人回复时不出现在「同伴痕迹」。有人回复后，留下的人也能看见这句和回复。
- 灯笼宽高改为原来的两倍。
- 玻璃卡按住非按钮区域可拖。同时最多两张。再开第三张时，关掉较早的那张。遮罩不盖住另一张卡。

## 后台请求

1. 第一次在线心跳延后 4 秒，不挤在进门或第一次空闲呼吸上。
2. 只有人数变化时才改写本机记录。
3. 动画不等待这次请求。失败时保留上次人数。

## 部署

在线人数和痕迹回复要等云端部署后，正在用的应用才会变。Close、灯笼、拖动、座位码隐藏在刷新后即可。
