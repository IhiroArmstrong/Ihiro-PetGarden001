## 0. 大白话

下次选专注多久时，时长条已经停在你上次用的那个数字。现在只是没有人把这件事说出来。这一刀只加一句老实话：「还是上次那个」。不假装 Yin 更懂你，也不等适应层攒够拒绝才出现。

## 1. 目标与非目标

**目标**

1. 当本机已有上次时长偏好时，在开表前的时长条旁出现一句固定文案，意思是还用上次的分钟。位置与样式见 §2.1。
2. 文案走 `src/locales/slices/`（en / zh / ja 同片），不改总字典。
3. 过契约：无「懂你」、无疗效、无性格。en / ja 为正式，须人审。zh 草稿可先写，不对外当正式。

**非目标**

- 不改回显逻辑、不改默认 10 分钟、不改档位列表。
- 不做 T58 的下调、暂停、小本子。
- 不写「Yin 记得你是怎样的人」。

## 2. 锁定文案（点头后可微调标点，不得改意思）

出现条件：已有 `focus-duration-pref`。没有偏好（全新安装、重置后第一次）→ **不出这句**，避免撒谎。

| locale | 建议句 | 备注 |
|---|---|---|
| zh（草稿） | 还是上次那个 | 点头可改成「还是上次的时长」；禁止加成「Yin 知道你喜欢」 |
| en（正式 · 须人审） | Same as last time | 时长条上已是分钟数，不再写 minutes。待人审。禁止 `Yin knows you` / `getting better at this` |
| ja（正式 · 须人审） | 前回と同じ時間 | 保留。待人审。禁止「理解している」「慣れてきた」 |

禁止子串（大小写不敏感）：`懂你` / `knows you` / `only Yin` / `已证明` / 临床病名。

## 2.1 位置与样式（开工前锁定）

- **位置**：开表前时长档那一行的旁边（`#focus-duration-picker` 旁），作为该行的附属说明，不另开卡片、不另开遮罩。
- **样式**：低对比度小字说明（弱于档位数字）。**无动画**、无闪、无呼吸。不挡档位点击热区。
- **375 宽屏**：整句可见、不被裁切、不把 Sit 挤出可点范围。
- 点这句无独立动作（静态说明）。
