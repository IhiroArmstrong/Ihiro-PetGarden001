# Task Brief · T53 输入节奏（默认关 · 只定时机）

> **状态（2026-10-28）**：Brief 已点头 2026-10-25；**已合 develop #1437**（`feat(t53): default-off Mac input rhythm for invite timing`）。依赖 T50 口径 + **T51** 编排接口（把「节奏偏乱」当成邀请时机，不产出用户可见诊断）。**勿再开同内容实现旁支。**  
> **类**：B 类（设置项 + 可选系统权限）。  
> **平台**：仅 **Mac Electron**。Web / 窄屏 / 无壳 = 本刀不采集，行为保持 T51。

## 一句话

设置里默认关掉。打开且系统允许「输入监控」之后，本机只看击键间隔和是否退格，用来**稍微提前或推迟 T51 的邀请**。不记你打了什么字，不读窗口标题，不显示分数，不出现「焦虑」。

## 已拍板

1. 默认关；没权限 = **SB-21**，退回 T51。  
2. 只记时间戳 + 是否退格；禁止键值、禁止截屏、禁止窗口标题。  
3. 采集在 Swift Helper 内存里聚合成每秒计数再交给主进程；原始事件不落盘。  
4. 对外话术：「感知你的专注节奏」，禁止「AI 读心」。  
5. 设置页须有「阿寅看到了什么」：只显示切换次数、退格率等**统计**，可一键关、一键清。

## 冲突扫描

对照场景 **E** 跨工具心流、**B** 离开、隐私声明、Companion Mode。

| 轴 | 结论 |
|---|---|
| **a. 强度** | 授权说明必须可跳过；不授权产品完整能用。 |
| **b. 语气** | 透明面板是说明不是成绩单；禁止红字警告「你很乱」。 |
| **c. 职责** | 不替代 Companion Mode 声明。`Flow State` 下即使节奏「乱」也 **不得** 发离开类邀请；节奏只影响 `Here & Now` 的 LONG_SIT / 邀请冷却微调。 |

**易混**：写作大量退格 ≠ 邀请。规则：退格升高且**同时**切去非任务应用才允许提前邀请；单纯改稿不邀请。
