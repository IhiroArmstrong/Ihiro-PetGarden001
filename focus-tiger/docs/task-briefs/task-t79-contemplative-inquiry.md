## 2. 冲突扫描（对照 `SCENARIO_TESTS`）

相邻：场景 **U2** Quiet Line、**B / X** Recover 与觉照邀请（**T51**）、倾诉安全线、Arrival / Sit、结束低语。

| 轴 | 结论 |
|---|---|
| **a. 强度** | 比 Quiet Line 重（要约五分钟坐），但 **仅用户自己点进**。不得比危机路径更「讲道理」。提前结束仍落地，禁止追问「为什么离开」。 |
| **b. 语气** | 同参，不教练。禁体验层宗教词、禁功效、禁「空是好状态」。与 T64「不是禅师」一致。 |
| **c. 职责** | 新可选栏目。不替代 Sit、不替代 Quiet Line、不替代 T51、不替代倾诉。危机只交接，不在本栏处理。 |

无冲突的前提就是上表入口隔离。实现时若把本问写进每日一句或专注中邀请 = **职责冲突，禁止合入**。
