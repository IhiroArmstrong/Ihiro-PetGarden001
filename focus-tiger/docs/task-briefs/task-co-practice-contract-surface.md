## 0. 大白话

一起练习这件事，产品里已经会记住时长、结束自评、拒绝后少开口、你自己定的收工时间。可是这些散在各处，人很难感到「我能看见、能关掉」。这一刀不新增劝告，只在成长旅程详情、小本子下面，放一张安静的说明：Yin **可能**在哪些地方开口、此刻开着还是停着、要关去哪点。用户永远保有选择权。

## 1. 目标

1. 一张**契约面**（不是新一级页、不是 FAB）：挂在已有成长旅程详情卡内，小本子之下、练习观察纸之上。  
2. 只**陈述现网已为真的通道**（专注中邀请、每日来坐、收工轻问、研究分享、适应更安静）。每行：现在怎样 + 怎么关/降。  
3. 开关全部**复用已有存储与控件**；本刀**不新增**键、不新增邀请种类、不改触发逻辑。  
4. 文案过契约：观察事实，不说「Yin 懂你」，不泄漏内部状态名，不写连续熬夜。

## 2. 非目标

- 不做档 1/2/3 升档干涉，不把并行通道画成阶梯。  
- 不根据时钟判断熬夜、不写「这周几点后还坐着」（那是 **T62**）。  
- 不读倾诉原文、不喂向量。  
- 不改邀请冷却数字、不改 T58 暂停规则。  
- 不新开 Privacy 大改；最多加一句「成长旅程里可看可关」（locale 切片，过契约）。  
- 不把内部 `SETTLED` / `DRIFTING` / `STRUGGLING` 或「熬夜」标签给人看（**C-09 / C-01**）。

## 3. 现网承接点（实现时对照代码，勿另造账本）

| 行 | 用户该看见的事实 | 已有开关 / 去处 |
|---|---|---|
| 专注中「停一下」类邀请 | 开着；或「这类提醒先停到某日」（T58 暂停） | 小本子上方适应总开关；暂停是算法结果，契约面只读显示，不另造关钮 |
| 每日来坐 | 已设时分 / 未设=关 | 现网提醒设置（`reminder-preference`）；契约面给「去改」打开**已有**提醒卡，不复制一套钟 |
| 收工轻问 | 已设时分 / 未设=关 | **T61** 收工设置；同样「去改」打开已有卡 |
| 研究分享 | 开 / 关 | Privacy 已有开关；契约面只读 +「去 Privacy」 |
| 适应（更安静） | 开 / 关 | **不要第二颗总开关**；写明「开关在本页上方小本子」 |

锚点（实现时核对，勿在点头前改代码）：`GrowthJourneyDetailUI.js` 的 `notebookEl` / `paperEl`；`yinAdaptationStore.js`；`reminderPreference.js`；`workEndPreference.js`；T54 研究分享键。

## 4. 交互锁

- **入口**：现网首页成长旅程一行 → 同一张详情卡。禁止新 FAB、新菜单项。  
- **宽屏**：详情卡继续遵守不挡阿寅（**T42**）；契约面是卡内滚动内容，不另起居中大卡。  
- **「去改」**：0–1 秒内打开已有设置卡或滚到已有控件；禁止哑点击。关掉设置后回到详情，契约面数字已更新。  
- **无设置时**：该行写「现在关着」或「还没设」，不要假装有观察。
