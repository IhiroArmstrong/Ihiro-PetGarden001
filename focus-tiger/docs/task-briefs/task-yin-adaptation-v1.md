## 0. 大白话

Yin 开始按你这个人调整，但第一版只许更安静，不许更积极。你连续不理某一类提醒，这类提醒就少出现，过一阵没再出现同样的情况就回到现在的默认。你常点「乱」或「倦」，下次时长条可以先停在更短的一档，仍要你自己点才开始。

这些调整写在旅程里的一小块白话上，每一句对应一条真规则。你可以改正、忘掉，或整档关掉。全部只留在这台机器上。

## 1. 两条规则

数字是建议，点头时可改。未点头前不要写死进代码。

**变安静（靠 T57 的下场）**

- 同一种邀请，连续 **3** 次是拒绝或没理，才拉长这类邀请的冷却（建议变为现在的两倍，有上限）。
- 点头不缩短冷却，也不增加次数。
- **14** 天里没有新的「拒绝 / 没理」来维持，这条回到默认冷却。
- 第一版只动专注中邀请那几类。不动场景 B 的离开后再聚焦提示，不动倾诉。

**换默认（靠 T52 的顺 / 乱 / 倦，外加已经存在的时长偏好）**

- 最近 **5** 次结束打卡里，「乱」或「倦」至少 **3** 次：下次时长条先停在更短的一档。不自动开表。
- 你自己选过的分钟，继续用现有 `focus-duration-pref`。不另做第二套时长记忆。
- 不因为常点「顺」就加长、加提醒、加祝贺。

**护栏**

- 只描述行为（「这类提醒我先少说」「你常选短一点」）。不写性格（「你很急」）。守 C-01、C-03。
- 一键关闭适应：冷却与建议回到今天的默认。一键忘掉：清掉适应状态，不删练习记录本身。
- 每条规则给定历史就有确定输出。不调用模型。
- 倾诉原文不回流。专注中不开倾诉。

## 2. 小本子

不新开模块，不新开遮罩。挂在已有成长旅程阅读面上（实现前再读 `YIN_EVOLUTION.md` 与 `YIN_PERSONAL_MEMORY.md`，避免第三套记忆）。

每句是固定模板，对应一条规则 id。没有规则被触发时，这块不出现，或只留「还没有需要记住的调整」。

示例方向（正式 en / ja 在实现 PR 的 locale 切片里写，须过契约）：

- 你连续几次没理「停一下」。这类提醒我先少说。
- 你近几次结束时点了乱或倦。下次时长可以短一点，仍由你决定。

旁边三个动作：改正（这条不再自动调）、忘掉（清这条状态）、关闭适应（全部回到默认）。

对照觉照邀请、场景 **T** 时长条、场景 **B**、**T52**、倾诉、成长旅程详情。
