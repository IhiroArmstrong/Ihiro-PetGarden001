## 一句话目标

在现有计时专注结束时，本机只追加一条研究用流水；另开一个只收白名单字段的接收口。默认不上送、不抽签、不发研究招呼。阿寅对用户说的话本刀完全不变。

## 背景

阶段 1 已锁定第一轮对照的口径，但现网练习日只在本机，云上没有合格沉寂人数。要攒触发人数，须先有流水和接收口。用户指定本刀可影子，且**不改**看见的招呼文案。

**T52** #1424 已合。T54 本条 **排队中 · 可选**（不是立即做）。实现只许影子流水 + 接收口，**禁止**改招呼文案。

## 范围（in）

1. **本机流水**（只追加，对齐阶段 1 §9.1）  
   - 只在**计时专注**结束时写一行（与「回来」同一口径）。  
   - 字段：开始时间、来源（本刀只写「自己打开」；招呼/补登/仪式枚举预留但本刀不产生招呼来源）、计划/实际分钟、结束方式、招呼编号与实验编号（本刀空）、用户反应（本刀空）。  
   - 不记倾诉原句，不记情绪分数。不改长现有 90 天练习日账本。  
2. **接收口**（Worker 新接口 + 单独存储，对齐 §9.2）  
   - 只收白名单：研究编号、组别、本机研究代号、入组时刻、是否第一次合格沉寂、观察状态、14 天内是否回来（观察期满才取值）、回来隔了几天、6 小时窗口内是否坐下、退出标记。  
   - 多出的字段直接丢弃并告警（阶段 1 测试情境 12）。  
   - 本刀客户端**默认不调用**该口。若实验室开关打开，仍须：未同意研究 → 永不上送（情境 1）。  
3. **门闩（默认关）**  
   - 无研究同意 → 永不抽签、永不上送、永不写组别。  
   - 本刀**不**做同意页 UI。同意标志保持未勾选。  
4. **单测**  
   - 纯函数：白名单过滤、未同意不上送、补登/一分钟呼吸不写入「计时专注」流水来源。  
   - 能单测的阶段 1 情境先锁 1、7、12；2–6、8–11 依赖入组/招呼，留给下一刀。
