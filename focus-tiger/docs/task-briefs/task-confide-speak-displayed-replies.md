## 0. 大白话

语音开着时，倾诉卡里 Yin 写在屏上的每一句都要念出来——包括危机转介、攻击他人、Help Center 跳转。念的就是屏上那些字，不加戏。用户仍可立刻停：关卡、再发一句、或点听写开始录音。不新增设置项。Web / 窄屏本来就没有桌面朗读，写进复核纸已知缺口。

## 一、拍板锁

1. **「全部朗读」= 语音可用时全部念。** 不是无法关闭。危机句最私密，办公室 / 公交 / 家人在旁必须能马上停。  
2. **跟着屏上展示的文字走，不跟路由名走。** 去掉路由白名单静音。未知路由也不再默认静音。空正文仍不念。  
3. **念的内容与屏上完全一致。** 不增删、不加第二套话术。  
4. **保留现有停止办法，不新增开关。** 见下节「现有停止控件」。Voice announcements 菜单行继续只管练习结束等公告，**不**拿来关倾诉朗读（现网本就切开）。  
5. **不改路由。** 不改 safety-01 正文、不改危机阈值、不改对象归一。T29 的对象归一与跳转句文案保留。  
6. **T29 移交。** T29 已合的「跳转句进白名单」由本刀覆盖为「凡屏上正文都念」。T29 Brief 里「危机仍静音 / 10/28 问要不要念」作废，改指向本刀。  
7. **10/28 复核人审朗读形式，不审开闭。** 开闭已由产品拍板。复核人听实际合成声：语速、语气、整句还是截短。地区号码另问，见复核纸。

**一句话：** 宽屏 Electron 倾诉出字就念屏上全文；停的办法还在；路由不管出不出声。

## 现有停止控件（核对结论 · 本刀须保持）

| 办法 | 现网 | 危机句在本刀后 |
|---|---|---|
| 关掉倾诉卡 | `close()` → `stopSystemTts()` | 同样立刻停 |
| 再开卡 | `open()` → `stopSystemTts()` | 同样清掉残留 |
| 再来一句回复 / 练习结束播报 | `speakSystemTts` 先停再念（最新一句赢） | 同样打断危机句 |
| 点 Speak to type 开始录音 | 修前**不停** TTS（会叠音） | **本刀补**：开录前 `stopSystemTts()`。不是新开关 |
| Voice announcements 菜单 | 只管练习公告；倾诉朗读独立、默认就念 | **不**改成用它关倾诉 |
| Web / 窄屏 | 无桌面 TTS 桥，本来无声 | 保持；写复核纸缺口 |

系统音量 / 机身静音仍有效。本刀**禁止**为危机句单独关掉上述停止路径。
