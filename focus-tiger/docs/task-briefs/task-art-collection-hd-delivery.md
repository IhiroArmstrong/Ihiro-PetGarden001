## 做的时候要满足

- 没买到的组，高清文件不进安装包，也不提交进公开仓库。公开目录继续只放 `preview-*`。
- 能不能看高清，只认服务器上的购买记录。本机「已拥有」或缓存不能单独放行。
- 付清后下载这一组。下载链接短时间有效，并且只发给这一次已核对过的购买。下一组上架时再下下一组。
- 下到本机之后，断网仍能在收藏里看。退款撤销后不再新发高清；已经下到设备上的文件收不回来。
- 高清图留一道很轻的购买者标记（肉眼几乎看不见，或写在文件信息里）。用来对上是哪一单，不拿来挡住普通观看。
- 不改写已经公开的 Git 历史。
