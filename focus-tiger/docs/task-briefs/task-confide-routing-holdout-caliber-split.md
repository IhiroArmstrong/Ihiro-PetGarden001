## 0. 大白话（给拍板用）

现在路由关单把八类绑在同一把尺子上：都要 **函数 A @ 0.01** 过 85%，八类同时过才算过。这把尺子只能回答「产品分是否明显高于情绪分」，**分不出**「该念短答」还是「该诚实空态」，也测不出徽章是不是被念成寅币。

后三次（及中文 b-v6）盲测里，诚实空态、产品压情绪、情绪占上风反复过不了 85%。继续用同一把尺子去打英文未见卷，多半再验证一遍旧结论，并占掉 `en/b-v6` 的第一次读数。

要改成：**按尺子能量的东西分带关单**。85% 线不降。函数 A 只关它该关的带。贴边混合句允许 CR-45 **影子**合并回应作为合法出口（用户听不到）。短答 / 空态 / 徽章用写死的带 C 读口。场景 AE 两锚是关单锁（各 n=1），**不要**写成「100% 通过率」。英文未见卷继续封存；**本口径点头不等于同意占额**。

## 一、为何必须拆（不是降线）

| 混在一起的东西 | 现 holdout 实际在量 | 问题 |
|---|---|---|
| `mixed` / `product-over-emotion` / `mixed-emotion-dominant` | 函数 A：分句 `product − mood` 最大差 vs 0.01 | 这是函数 A 的本职；三类是已知结构短板 |
| `life-emotion` / `chitchat` | 同上，期望不走产品 | 粗闸够用；与「短答 vs 空态」无关 |
| `product-short-answer` / `product-honest-empty` | 只判 `productPath` 真假 | **短答与空态在脚本里是同一个桶**；过了不等于念对 |
| `badge-yin-coin` | 同上，期望走产品 | **测不出**「不得念寅币短答」 |
| 场景 AE 两锚 | 被折进短答类的 60 条 | 关单锁，**不算未见**；`locale` 字段脚本不读 |
| G2 事实到达 | 另一套 `audit:g2-fact-arrival` | 已与八类脱钩；不可再绑回「八类同时」 |

**禁止**：为让三类过线而调 0.01、改函数 A、或把 85% 改成更低的数。拆的是 **关谁的单**，不是放水。

## 二、建议的五带（点头后才替换旧「八类同时」）

点头后：G2「够用」与仲裁 Brief 关单节改指向下表。旧「八类同时函数 A ≥85%」**不再**作为跑 `en/b-v6` 的理由（该文件仍禁止真跑，见第四节）。

`mixed` 与 `mixed-emotion-dominant` **互为镜像**，两类都要过 85%，用来看函数 A 是否整体偏向一边。保留。中文 b-v6 上 `mixed` 偏满分，正是这种偏向的信号，不是过关证明。

### 带 A · 函数 A 产品闸 + CR-45 影子出口

| 类 | 路径期望 | 过关形式（不降 85%） | n |
|---|---|---|---|
| `mixed` | 走产品 | **路径对，或** CR-45 影子发出合并回应 | ≥60 |
| `product-over-emotion` | 走产品 | **路径对，或** CR-45 影子发出合并回应 | ≥60 |
| `mixed-emotion-dominant` | 走情绪 / 观察翼 | **路径对，或** CR-45 影子发出合并回应 | ≥60 |

关单线仍是各类 **≥85%**。报表必须分列「路径对」与「靠合并过」（CR-45 Brief §6 / §7.5）。禁止只报一个合计来掩盖函数 A 仍判错。

点头不等于这三类已经能过。函数 A 单独仍可能是结构天花板。出路见 **第二节补充**，**不是**再刷未见卷、**不是**调 0.01。

### 带 B · 非产品粗闸（可与带 A 同一文件、同一脚本）

| 类 | 期望 | 尺子 | 过关 |
|---|---|---|---|
| `life-emotion` | 不走产品 | 函数 A `expectedPath=mood` | ≥85% 且 n≥60 |
| `chitchat` | 不走产品 | 同上 | ≥85% 且 n≥60 |

### 带 C · 产品闸细档（读口已写死 · **CR-52 自己验收**，不再当 CR-11 前置）

函数 A 的 `productPath` **不得**当本带关单（短答与空态在脚本里是同一个桶）。方向错误（产品问被送去情绪路径）是本带要抓的伤，检索层救不了已经走错的句子。

**硬闸（点头即锁，缺一不可）**

1. **产品问不得进情绪路径。** 操作问法 ∧ 产品对象（含 **目录里没有短答的功能**）→ 影子或现网路径须为产品闸（短答 `product_knowledge` **或** 诚实空态 `product_knowledge_honesty`）。**禁止** `generate` / 观察翼 / 情绪语料。统计用 `data-source` 或与之同义的影子路径字段，不用函数 A `productPath` 单独充数。  
2. **徽章不得念寅币短答。** `badge-yin-coin` → 不得 `product_knowledge` 命中寅币条目；期望诚实空态口径（或其它非寅币短答，以后若有专卡另 Brief）。  

**分母**：各类 n≥60。关单线按类：`product-short-answer` 与 `product-honest-empty` 里凡属操作问法 ∧ 产品对象的句子，**进情绪路径的句数 = 0**；`badge-yin-coin` **寅币短答句数 = 0**。短答是否对题 / 空态是否空态可另报 85% 细档，**不得**用细档绿掩盖硬闸红。

函数 A 汇总对本带仍可打印诊断，**不**写入函数 A 的 `pass_criteria_met`。

### 带 D · 场景 AE 锚（关单锁，不是统计）

两锚必须各 **1 句** catalog 短答正确。这是关单锁，**禁止**在汇报里写成「通过率 100%」（n=1 不是率）。原文来自场景表，不算未见。可放在英文信封里且 `locale: zh`；脚本按中文原文向量 / 全路径打分。不得因语言混放而从短答类剔除，也不得靠 CR-45 合并充数。

### 带 E · G2 事实到达（已有，不并入八类）

`audit:g2-fact-arrival`。关单仍看「问到的事实到没到」。禁止用带 A 通过率代替。
