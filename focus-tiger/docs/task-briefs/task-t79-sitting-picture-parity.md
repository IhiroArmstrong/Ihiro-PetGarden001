# Task Brief · T79 带着问题坐 = 主静坐画面

> **状态（2026-11-21）**：PO 书面改稿（原 T79 专用倒计时卡是按稿，不是漏做）。本 PR 实现。  
> **类**：**B**。  
> **不是**：FocusSession / 莲花分钟 / 练习日。**不是** 接地练习。**不是** 点选可见 PR。

## 0. 大白话

「带着问题坐」安静坐的那几分钟，应和主静坐同一套画面：老虎在，不跳分秒。仍是自己的五分钟，不算正式专注。提前结束仍落地，不像接地。

## 1. 已拍板

- 坐的阶段收起玻璃卡与遮罩，只留提前结束。  
- HUD 用静坐画面藏数字（`liveClockOverlay: false`）。  
- 不计 Focus 芯片、不写练习日。  
- 提前结束 → 落地，不是 Ground。

## 2. 冲突扫描

相邻：T45 静坐画面、T47 收控件、Sit/FocusSession、T79 防火墙/落地、接地练习。
