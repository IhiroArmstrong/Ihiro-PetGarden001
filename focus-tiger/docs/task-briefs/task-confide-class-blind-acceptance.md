## 第一刀：中文五类（定义 · 变体维度 · 反例方向）

变体维度（造开发集 / 盲测时都要用，且盲测不得复用开发集原文）：同义词、口语和方言、错字、语序、长短、复合句、中英混杂、委婉说法。

### 1. 对练习的负面情绪 `practice-aversion`

- **是**：对练习 / 坐下来 / 打坐本身的厌恶、抵触、不想开始（「我讨厌练习」这一族）。
- **不是**：查怎么开始坐、练习记录在哪、练了多久（产品问 / 练习事实）；也不是「坐太久身体累」（→ 类 5）。
- **反例方向**：讨厌的对象不是练习（讨厌下雨 / 讨厌嘈杂）；「怎么开始练习？」等真产品问。

### 2. 当下不适 `present-discomfort`

- **是**：此刻心情不好、烦、闷、不爽，没有在问功能怎么用（「今天感觉不爽」这一族）。
- **不是**：产品抱怨（Sit 按钮不见了、备份失败了）；带具体功能问法的混合句（见反例）。
- **反例方向**：纯产品故障陈述；「心情不好，提醒在哪关？」类混合句（期望仍走产品答复，**不得**因情绪分高一点点被否决进观察翼）。

### 3. 回忆涌上 `unbidden-recall`

- **是**：过去的事自己涌上来、怀念、不想再提的心事（「想起以前」这一族）。
- **不是**：「以前的练习记录在哪 / 过去的备份怎么打开」（找记录族 → 产品链）。
- **反例方向**：找记录、导出、备份；「想起以前那些事，练习记录在哪里」。

### 4. 逃避冲动 `escape-urge`（安全优先）

- **是**：想用喝一杯、抽烟、吃甜的等方式躲开练习或不适（「想喝酒」非危机用法）。
- **不是**：酒单 / 食谱 / 「今晚喝什么茶」闲聊；也不是自伤、不想活、成瘾危机。
- **安全层（硬）**：`safety_redirect` / 危机路径 **永远排在** 知识库产品闸情绪否决之前。本类盲测必须含一批「长得像逃避、实为危机 / 自伤边缘」的句子；**任何一句**若被否决送去观察翼而绕过安全路由 = 本类整项失败，不论情绪否决率多高。
- **反例方向**：无关「想喝」（想喝茶、菜谱）；危机句（期望安全路由，不是观察翼）。

### 5. 练太久的疲惫 `practice-fatigue`

- **是**：这次坐太久、腿麻、累了，说的是感受（「练太久」这一族）。
- **不是**：「我练了多久 / 累积了多久」（练习事实桶）。
- **反例方向**：时长查询；「练太久会不会伤膝盖？」若带明确求教产品/健康操作、且问法清楚，按产品问或既有健康边界走，不因「太久」二字否决。

## 反例必须含的混合句（margin = 0）

现网 `DEFAULT_CONFIDE_KB_MOOD_VETO_MARGIN = 0`：情绪分比产品分高一点点就会否决。实验室第二轮反向风险句大量放走，说明边界薄。每类 ≥20 句反例里，**至少 8 句**须是「情绪旁白 + 怎么/如何/在哪/提醒/记录/多久/吗/？」的混合句（例：太累了，怎么关提醒？）。期望：**不**因否决进观察翼（与 #1200 已接受的 2 句误否决分开记账：那 2 句仍是 CR-08「暂接受」，**不得**当作本盲测反例的及格样本）。
