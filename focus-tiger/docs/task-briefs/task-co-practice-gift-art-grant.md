## 5. 出卡与归档

### 5.1 出卡时机

**发放评估**（是否 grant、写盘、排队出卡）**只在「本场新增 B 接合记账」的那一场 Sit 计时达标完成之后**进行——即用户刚在专注中应了邀请且同一场坐完、T67 为本场记入 B 日历日的那一场。A、C 已满足但本场不是 B 记账场 → **不发、不挂起占位**；等下一次满足 B 的共修场再评估（可能延后，但画与一次真实往返绑定）。

仪式队列（仅当本场评估通过且尚未出过画）：计时达标完成仪式（含每日首次 Celebrating 若有）→ 芥子须弥若出 → 修行纪念印若出 → **本卡**。Continue / 关闭 → 再进 Reflection。未达标 Rise：不出。

### 5.2 出卡 UI

新玻璃卡（建议 `CoPracticeGiftArtCardUI.js`）。暖米玻璃，禁止深色厚卡。预览 + 画名 + 一句短故事 + 关闭。可保存 PNG **仅当** 本机已有该预览文件（与纪念印同类）；没有高清桶、不下载在售套原图。

### 5.3 归档

`#yin-coin-panel`（Yin's Collections）增加只读「收到的画」。空态一句「还没有一起走的一张」，不留白大玻璃。不提供 Buy / Stripe。宽屏继续不挡阿寅（T42）。
