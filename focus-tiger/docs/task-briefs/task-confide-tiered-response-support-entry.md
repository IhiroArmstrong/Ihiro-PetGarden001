## 本 Brief 验收的是什么 / 不代表什么

- **本条验收的是**：安全触达不再只靠分类器托底。三条路径都要能走到资源指引——（1）分类高置信命中、（2）分档中置信命中、（3）用户主动点常驻入口。  
- **不代表**：可以放宽明确危机 ≥90%；可以改 safety-01；可以在盲测上调阈值；中档轻句可以由实现会话定稿；常驻入口可以开 Support / 付款；可以存倾诉原句或上云。

## 0. 大白话（给拍板用）

分类器再准，也会有漏网和拿不准。漏网时不应只剩「没转介」；拿不准时也不该整句都上现有那句正式转介。

这轮做两件互补的事：

1. **分档回应**：很有把握是危机 → 继续用现在的转介句（一字不改）。有点像、但不够有把握 → 回一句更轻的关心，并带上**同一套**资源指引。不像 → 不额外插入关心句，走原来的闲聊 / 空态 / 事实答。  
2. **常驻入口**：倾诉卡上始终留一个用户自己能点的入口。分类没拦住时，人还可以自己打开资源。

轻句怎么写、档位数字取多少，交给懂危机表达的专业复核，不在这篇里定稿。明确危机那九成关单，维持原样。

## 二、分档回应

### 2.1 档位结构（阈值数字留空）

分数 **S** 来自现网安全栈（字面命中视为已达高档，不必再等向量）。结构如下；**`T_high` / `T_mid` 本 Brief 不填数字**。

| 档 | 触发条件（结构） | 用户可见回应 | 竖线 / 路由 |
|---|---|---|---|
| **高置信** | 字面 `matchesSafetyRedirect` **或** `S ≥ T_high` | **现网 safety-01，一字不改**（中英日） | `data-route=safety_redirect` · 竖线 `#7a5340` |
| **中置信** | 未达高档 **且** `S ≥ T_mid` | **一句更轻的关心（占位）** + **与 safety-01 相同的资源指引** | 新路由名（实现时建议 `safety_care` 或同等，禁止复用 `aggression_toward_others` / `practice_facts`）· 竖线须与高档可辨、且**不得**用攻击他人 `#8b6f5c` |
| **未达中档** | `S < T_mid` 且字面未命中 | **不**插入关心句；维持字面之后的原路 | 现网不变 |

**硬顺序**：先安全分档 → 再攻击他人字面 → 再产品闸 / Stage 2 / 情绪桶。高档或中档命中后，情绪否决 / #1188 / generate **不可达**。攻击他人字面若已命中，**本分档不跑**。

**明确危机不得降档**：开发集 `crisis-explicit` 金句若只走到中档，算**高档漏接**，与今天「未走到 safety-01」同等失败。禁止为了少打扰，把明确危机的 `T_high` 抬到金句过不去。

### 2.2 阈值只在开发集上定

| 准 | 不准 |
|---|---|
| 在**开发集**上锁 `T_high` / `T_mid`（明确危机召回 + 逃避 / 口语夸张误捕） | 看完盲测 / s-v* 再改阈值 |
| 灰区只报告 | 用灰区刷高档通过率，或把灰区算进 ≥90% |
| 锁完写入实现 PR 三行（无原句：只打 id + 分数桶） | 把开发集 / 盲测整句写入生产或单测 |

封存盲测只做**一次报告**：各档触达是否可用、有无误入高档 / 中档。报告不得反向改 `T_*`。实现会话 **禁止** Read / Grep 封存路径，**禁止**引用封存原句。

### 2.5 用户 0–1 秒看到什么（分档）

| 时刻 | 用户看到 |
|---|---|
| 点 Share 后 0–1 秒 | 发送钮不可点；倾听中；阿寅 **Idle 呼吸**（不鞠躬、不点头 oneshot）。分档计算**不得**把「正在听」拖成数秒冷启动；embedding 未就绪 → 立刻字面（高档仅字面命中；中档未就绪则**不**插入轻句，走原路） |
| 高档命中 | 与场景 AE 已锁：`data-route=safety_redirect` · safety-01 全文 · `#7a5340` · **不朗读** |
| 中档命中 | 轻句占位（复核前不可上线）+ 同一套资源指引出现在回复里；**不朗读**；Idle 呼吸；禁止茶句 / generate / 产品诚实空态冒充 |
| 未达中档 | 与切前相同（情绪桶 / 事实 / 空态 / generate） |
| 禁止 | 中档弹出第二层支付卡；中档自动打开常驻资源面板（资源已在回复里；面板留给用户主动点） |

设计静默：分档路径**不是**静默。

### 2.6 风险（须在实现与复核时对着看）

| 风险 | 含义 | 本 Brief 的约束 |
|---|---|---|
| **过度打扰** | 中档太宽，疲惫 / 逃避 / 夸张口吻反复收到关心+热线 | `T_mid` 从窄、复核填误伤上限；中档只回一句、不另开模态；常驻入口承担「人要再看」 |
| **误捕体验** | 用户本意是「想喝酒躲开练习」或「想死你了」，却看到关心+热线 | 既有负例（想死你了 / 你去死吧 / 烦死了 / 想喝酒）**不得**进中档；与高档同一负例表 |
| **关单被偷换** | 用「中档也算接住」凑 ≥90% | **禁止**。≥90% 只认高档 safety-01 |
| **人设说教** | 轻句变成指导 / 追因 | 占位 + 复核；禁止实现会话自拟上线句 |

**我认为最合理的是**：中档带宽从窄、常驻入口始终可点。

**为什么**：漏接的伤害在高档；中档过宽会把正常倾诉变成「被系统当成要寻死」。主动入口能补漏，而不必把分类器拧得过敏。更宽的中档只在复核给出误伤数字且 PO 另点头后才考虑。

## 三、常驻支持入口

倾诉界面**始终**保留一个用户可主动点的入口。不依赖本轮有没有 Share、不依赖分类结果。

### 3.1 位置

| 项 | 规格 |
|---|---|
| 宿主 | `#confide-to-yin-card` **卡内**（Web harness 与 Electron 宽屏同一卡） |
| 建议落点 | 输入区 / 回复区下方、主操作行（Share / Close）**之上**；与 `[data-testid=confide-to-yin-memory-list-link]` **并列次要文字链**，不得压过 Share |
| 可见性 | Confide 卡打开即可见（含尚未发送）；Focusing 中卡本就不可开，本入口不另做 Focusing 快捷 |
| 禁止落点 | 右上 `#yin-support-fab`；倾听耳；窄屏 ActionBar 新 FAB；菜单 ⋯ 新行（卡内已有则不必再占菜单） |
| 壳 | 有倾诉卡就有入口。CR-40（Web / 窄屏不上向量）**不**禁止本入口；窄屏无卡则无入口，不另发明 |

建议 `data-testid`：`confide-to-yin-help-resources`（实现可同义，须可点测）。

### 3.2 措辞占位

按钮 / 链文案 **不定稿**。

- 键建议：`CONFIDE_HELP_RESOURCES_ENTRY_PLACEHOLDER`
- 正文：`[PLACEHOLDER_HELP_ENTRY · 专业复核定稿]`
- **禁止**使用品牌词 **Support** / 「请茶」/ 「加入会员」，以免与 Support Yin 付费 FAB 职责重叠。

### 3.3 点开后 0–1 秒看到什么

| 时刻 | 用户看到 |
|---|---|
| 点击后 0–100ms | 链/钮按压态（接收反馈）。禁止哑点击 |
| 0–1 秒 | **同一张倾诉卡内**展开资源区（建议 `aria-expanded`），不必新遮罩、不必新 z-index 层 |
| 资源区内容 | 与 safety-01 **同一套**资源指引（信任的人 / 当地专业援助热线；三语与高档指向一致）。可加一句「阿寅不能代替专业帮助」。**禁止** Stripe、禁止 Checkout、禁止会员卡 |
| 再点 / 关闭 | 资源区收回；倾诉输入与未发送草稿仍在；阿寅保持 Idle 呼吸 |
| 与高/中档回复同时 | 若回复里已有资源句，点入口仍打开同一资源区（不重复弹第二套热线） |

持久化：默认**不写**练习备份、不写云。点击计数见第四节。无挂起/失败云态。O-04：若坚持「只在卡内展开」，**不**新建 `OVERLAY_UI_SURFACE` 行；若实现改成独立 fixed 叠层，须先补 registry + z 归属 + 付款契约，**本 Brief 默认不采用**。

设计静默：不是静默。不在 `SILENT_BEHAVIORS`。

### 3.4 是否记录点击

| 项 | 默认 |
|---|---|
| 记不记 | 允许本机 **按天计数**（点了几次入口、当天是否展开过） |
| 原句 | **不记**。即使当时输入框有字，也不得写入点击记录 |
| 云 | **不上云**。不进练习备份 6 key，不进 Backup JSON |
| 关联 | 不得把点击与 `queryHash` 拼成「这句触发了求助」 |

实现建议 `kind`（若进 `turns.jsonl`）：`confide_help_entry_daily`，字段仅 `at`（日精度或日 bucket）+ `count` + `locale`。不得带 `text` / `raw` / `reply`。

| 邻接 | 结论句 |
