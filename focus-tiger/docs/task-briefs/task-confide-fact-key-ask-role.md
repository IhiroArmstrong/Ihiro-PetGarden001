## 0. 大白话

上一刀把说明书切成短句去对用户的话，背景音乐更对不上了，「要不要打卡」仍然全错。吃饭闲聊本来就没进「没有手册」，这一头不要动。

问题不是「再切细一点」。用户在问「要不要 / 在哪 / 怎么开」，卡片却用陈述句和一整段短答去比；「在哪打卡」和「要不要打卡」两张卡还抢同一个近邻。换说法对不上，就会落到错卡、跳过、或空答。

这一刀改成：每张卡只留一句**和用户同一种问法形状**的事实键（不是用户原话名单）；用户的话先归到封闭的形状轴（在哪 / 怎么 / 要不要 / 是什么 / 都不是），只在同一形状的卡片里找够近的。线仍是 0.80。闲聊仍生成。

## 一、为什么不是再改检索切句

| 已做过 | 未见英文批 | 结论 |
|---|---|---|
| #1250 短答进近义、keywords 退出 | `sealed-v1`：0037 6/20，0038 0/20，闲聊 20/20 | 换说法未接住 |
| #1255 能力说明按句切开，改成 whether/where 覆盖句 | `sealed-v2`：0037 **4/20（更差）**，0038 0/20，闲聊 20/20 | 切句 + 更抽象的覆盖句不是下一刀 |

`sealed-v2` 计数（不写原句）：0037 没有靠字面关键词进卡；0038 是**错误邻居**和**跳过**，零次正确命中。

跳过的机制原因（不是某句原话）：CR-47 现网形状只有 how / where / what is / 故障，**没有**「要不要 / 必须吗 / 是不是可选」。未到 0.80 时，这类问法会 `skip` 去生成，到不了 0038。

错误邻居的机制原因：0020 短答里写了入口，也写了 optional；0038 短答里写了要不要，也写了入口。近义是全库短语取最大余弦，没有「在哪 vs 要不要」轴，0020 会把要不要问抢走。

#1255 把能力说明改成陈述覆盖句，和用户问句更不像，0037 从 30% 掉到 20%。再切句、再写 whether/where，**不合理**。

## 二、比对面改成什么

### 1. 封闭形状轴（问法，不是话题）

用户句先落到一档（可增形状，不可增卡片主题）：

| 形状 | 英文形状（封闭，实现时写成判定，不是问法名单） | 不是这一档 |
|---|---|---|
| `where` | where is / where do I / 在哪 | 动机 why |
| `how` | how do I / how can I / which button / turn on\|off | 「怎么坚持练习」动机 |
| `whether-required` | do I have to / must I / do I need to / is it required / is it optional / 要不要、必须吗、是不是可选 | **Do I have to meditate / practice**（活动词，不是产品对象） |
| `what-is` | 沿用 CR-47 已有 what is + 产品实体 | What is the point of practice |
| `none` | 其余 | 吃饭闲聊、动机、陈述想练 |

`whether-required` **必须**同时有产品对象（Honesty Check-in、check-in、streak、reminder 等产品里的东西）。只有活动词（meditate / practice / focus）→ 仍 `none` → 生成。禁止把「要不要练」收成产品问。

CR-47 仍成立：形状 ∧ 产品对象才允许诚实空态。目录已 ≥0.80 命中仍先于形状（现网 `catalogHit` 短路），本刀不改这条顺序。

### 2. 每张卡的事实键（一句，问句形，不是用户原话表）

检索短语 = **该卡声明的形状**上的一句事实键。短答仍给人听，**默认不再进入近义**（避免 0020/0038 互相掺 optional 和入口）。

先改这两张，实现时写入目录，本文件锁文案：

**KB-FUNC-0037** 形状 `where` + `how`。事实键（一句即可，两形状共用）：

> Where is the idle-screen control that turns background music or ambient sound on or off?

**KB-FUNC-0038** 形状只 `whether-required`。事实键：

> Is daily check-in or a streak required, or is it optional?

**KB-FUNC-0020** 形状只 `where` + `how`。为本刀补一句事实键（短答正文可仍含 optional，但 optional 那句**不得**进近义）：

> Where do I open Honesty Check-in to record quiet time I already did elsewhere?

禁止：把未见批失败句写入 `keywords` 或事实键。禁止为换说法新开第三、第四张卡。

### 3. 近邻怎么取

只在**同一形状**的事实键里取最大余弦。仍 ≥ **0.80** 才命中。不放低 0.80，不把 0.62–0.80 整段改成现写。

- 要不要打卡 → 只看 `whether-required` → 应是 0038，不应是 0020。
- 打卡入口在哪 → 只看 `where`/`how` → 应是 0020，不应是 0038。
- 背景音乐在哪 / 怎么开 → `where`/`how` → 0037。
- 吃饭闲聊 → `none`，且离事实键应低于命中线 → 生成，不进诚实空态。

不够近：已确认是产品问 → 诚实空态，日志只许 `nearestId` + 分数 + **形状名**。禁止写原句。
