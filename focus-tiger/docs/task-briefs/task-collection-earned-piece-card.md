# Task Brief · 珍藏单件凭证卡（存图）

> **状态（2026-10-07）**：你已书面「按这份 Brief 开工」。代码在 `feature/collection-earned-piece-card`。真机仍待人工。  
> **目的**：在阿寅的珍藏里，对已经得到的一件器物，存一张竖图。图上是器物、得到的日期（有记录才写日子）、累计专注分钟、一句沉静的话。用户自己下载，再发给朋友。炫耀的是耐心，器物是证物。  
> **第二步（本刀不做）**：`task-art-collection-chosen-piece-card.md`。买来的艺术品另说「这是我选的一件」，禁止写成练出来的。

## 产品契约

| 项 | 口径 |
|---|---|
| 入口 | `#yin-coin-panel` 结缘页里，**已经拥有**的清供行上出现 **Save image / 存图**。未拥有的行没有这个按钮。 |
| 交付 | 竖版 PNG（4:5，对齐今日静语明信片尺寸）。内容：器物静帧、名字、累计专注分钟、一句第一人称沉静句、品牌落款。 |
| 累计分钟 | **要**。数字用莲花池已有的 `lifetimeMinutes`（累计专注），不是寅币余额，也不是单次坐禅。 |
| 句子 | 用这一个累计数字，例如「这件是我累计坐满这些时间之后得到的。」不评价人品，不说「你很自律」。 |
| 得到的日期 | 见下一节。禁止编造日历日。 |
| 动作 | **Save image**。点后 0–1 秒内按钮变为 Saving…；成功下载 `focus-tiger-collection-piece-<id>.png` 并变为 Saved；失败变为 Could not save，可再点。 |
| 社交 | 存图就是方便拿出去。界面不写「发给好友 / 一键发到某 App」。 |
| 档位 | 免费。不绑 Sanctuary、不绑艺术品购买、不建付费墙。 |
| i18n | 按钮与卡面句子 en + ja（与现有珍藏文案同一套 `t()`）。 |

## 得到的日期（诚实）

钱包今天只记 `ownedIds`，**不记**哪一天得到。

| 情况 | 卡面 |
|---|---|
| 本功能上线后新兑换的一件 | 兑换当下写入本地 `acquiredOn`（日期键）。卡面写这一天。 |
| 上线前已经拥有、没有 `acquiredOn` | 仍然可以存图。卡面**不写**一个假的日子；日期那一行用一句「已在珍藏里」，累计分钟和句子照常。 |

我认为最合理的是上面这张表。禁止用「今天」或「第一次打开珍藏的日子」填旧藏品。

## 范围

**做**

1. 已拥有行的存图按钮 + canvas 导出（复用今日静语 / 纪念印的 `downloadCanvasPng`）。
2. 新兑换时记下 `acquiredOn`；旧钱包缺这个字段时照常解析，不丢已有藏品。
3. 单测：已拥有且有图 → 能导出；未拥有 → 不导出；旧藏无日期 → 卡面不含编造的日期；分钟来自传入的 lifetime 数字。
4. `TEST_TRACKER` 一行：主路径 + 关掉抽屉再开按钮回到 Save image + 375 不挡坐禅三球。

**不做**

- 艺术品收藏卡（第二步单独 Brief）。
- 个人主页、公开链接、`navigator.share`。
- 一次导出整架。
- 把凭证卡放进 `#yin-art-panel` 或请茶。
- 用全球人数、稀缺排名、售罄。

## 冲突扫描

对照相邻的今日静语存图、Journey 单日日记卡、纪念印存图、艺术品货架：

- **强度**：仍是抽屉里的一次轻点，不庆祝、不挡 Sit。
- **语气**：第一人称经历，不说教、不推销。
- **职责**：珍藏证明「练到了」；日记卡证明「某一天坐了」；艺术品卡（下一步）证明「买下了」。三处入口分开，文案不混用。

无冲突，可以在点头后实现。

## 共用机制核对

本次不新建可点击叠层，按钮留在已有 `#yin-coin-panel` 内。不改 `overlayBusy`、不改 HUD 呼吸驱动、不新开 z≥17 遮罩。存图是用户点击后的本机下载，不涉及后台网络。

## 保护面

- 未拥有的清供仍只能兑换，不能存成「已经得到」。
- 寅币价格、兑换门槛、清供八件名单不改。
- 艺术品结账与拥有记录不改。
