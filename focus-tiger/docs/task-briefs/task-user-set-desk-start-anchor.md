## 0. 大白话

用户自己说「我大概几点开始伏案 / 我想这时候先坐一下，也可以顺口问早餐」。Yin 只陪这个钟。到点轻轻问；可以关、可以拒绝、拒绝后不追问。和深夜「我也休息，你也可以」、收工钟是同一类善意，不是健康监测。

## 1. 已锁边界（点头前勿删）

1. **新存储键**只存用户设的开桌 `{ hour, minute }`（可空 = 关）。**禁止**写入 `reminder-preference` 或 `work-end-preference`。
2. **开桌邀请**登记为 **T57** 邀请族新种类，受 **T58** 暂停。
3. **专注进行中让位**；**每日至多一次**。
4. **文案可含早餐善意**（吃了没、要不要先坐）。无此用户目标时，**禁止**说「你长期没吃」。
5. 禁止体重、用药、饮食质量仪表盘。禁止环境光日程灯。
