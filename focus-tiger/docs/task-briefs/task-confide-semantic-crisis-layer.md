## 0. 大白话（给拍板用）

第一步已经把能用固定短语拦住的危机拦住了一部分。剩下的多半是换了说法的自伤：字面表里没有原词，今天仍可能听到闲聊或产品空态。

第二步只补这一段：字面说「不是危机」之后，才拿这句话去和一份**人看过的危机示例**比像不像。够像，就改成现在已经在用的那句「请找热线」。不够像，维持原路。模型还没准备好时，**立刻**按字面回复，不转圈。

喝酒抽烟想躲开练习的话，不能因为「心情不好」被送去热线。模糊句仍只记账。转介那句话本身这轮一字不改；专业人士只按文末清单看口径，改句要另点头。

## 二、做什么（S1 · 已锁）

发送链顺序（硬）：

1. **字面** `matchesSafetyRedirect` / 攻击他人既有优先 → 命中则本层 **不跑**，现网路由不变。  
2. 字面未命中 **且** embedding **已经 ready** → 与 **人审危机示例库** 算相似度。  
3. 高于召回向阈值 → `hit.route = safety_redirect`，语料仍是 **现网 safety-01**（一字不改）。  
4. 未过阈值 / 模型未就绪 / 计算失败 / Web·窄屏 → **立刻**维持字面之后的原路（情绪桶 / fallback / 产品闸），禁止空白、禁止干等、禁止改成观察翼来「顶」危机。

**S1 的意思**：相似度 **只**打在字面未命中的句子上。不是每句都打，也不是用向量换掉短语表。

### 我认为最合理的是：S1

**为什么**：第一步已经证明字面能从 16/63 补到 46/63，误捕收到 1/35；剩下的是说法变了，不是表里少抄一句。只对漏网句打相似度，冷启动成本最低，产品问 / 逃避句少一次近邻机会。召回偏向对齐「漏接比多接更伤」；误捕上限防止热线滥用。

### 方案 S2（较弱 · 本 Brief 不用）

每句都打 embedding，与字面取或。冷启动更重，逃避 / 产品问更容易误近邻。仅当 S1 在开发集上补不动、且误捕仍远低于上限时再另开 Brief。

### 方案 S3（不合理 · 不用）

用 embedding 替换字面。冷启动无安全网。

## 四、阈值怎么锁（实现开工时 · 无原句）

实现会话用第一步失败 id 的相似度分布锁一个 **召回向** 阈值，同时满足：

| 指标 | 门槛（与 CR-43 §8 同一把尺） |
|---|---|
| 明确危机（夹具 63） | 字面 + 本层合计 **≥90%**（至少 57/63） |
| 若沿用假设 58 口径 | 合计仍须 **≥90%**；不得用改标签把失败句挪进灰区来凑 |
| 逃避误捕 | 仍 **≤2/35**，且不得为纯逃避句（酒/烟/甜食等躲开练习、无自伤用语） |
| 灰区 | 只报告 |
| 冻表危机正例 | 100% 不退步 |
| s-v1 关单 | 明确危机 ≥90%；误捕 ≤2/20；每文件只跑一次；每 Brief 版本最多 2 个过关文件 |

任一门槛破 → **整层不切 live**，停手问人。禁止为刷通过率单独下调阈值。

阈值数字本身不在本稿写死（须看失败句分布）；写入实现 PR 三行说明。

实现 PR 锁定：**默认余弦 0.78**（`FT_CONFIDE_SEMANTIC_CRISIS_COSINE` 可改）。日文无原型、含假名则 fail-open。开发集合计 ≥90% 须真 embedding 再判，未跑不得把 live 写成已过关。

## 八、专业复核清单（只写入 Brief · 本刀不改 safety-01）

请 **懂中文危机表达** 的专业人士（危机干预 / 心理急救口径即可，不必产品工程师）按下列项看。**看完可以建议改句；本刀仍不改 safety-01，改句须另点头。**

1. **转介金句（只审不改）**  
   - 中：听见了。若此刻很难独自撑住，请联系信任的人或当地专业援助热线。寅陪着，却不能代替专业帮助。  
   - 英：Heard. If this feels too heavy to hold alone, please reach someone you trust or a local crisis line. Yin is here — not a substitute for professional help.  
   - 日：聴いた。一人で抱えきれない時は、信頼できる人や地域の相談窓口へ。寅はここにいる——専門援助の代わりにはなれない。  
   - 问：是否仍清楚「不是诊疗、不能代替专业帮助」？是否恐吓、说教、或假安慰？是否应改日另点头？  
2. **示例库准入**：每条原型是否 **明确自伤 / 不想活**，而不是疲惫、失恋、想喝酒、想消失一阵子？含蓄句是否仍能被专业人士标成「应当转介」？  
3. **误伤熟人说法**：想念口吻（想死你了）、骂人（你去死吧）、工作消失（让这个问题永远消失）、烦死了——须保持非转介。  
4. **否定**：不是想伤害自己 / not suicidal 不得进转介。  
5. **三语**：中英日都要有人审原型；不得只中文。日文母语审未做完时，日文本层可 **fail-open 回字面**（与 CR-04 暂时放过对齐），须在实现 PR 写明。  
6. **灰区**：专业人士有分歧的句子不得塞进明确危机分母，也不得拿来证明召回。  
7. **隐私**：复核材料用工作区外副本；禁止把用户原句、封存盲测句贴进 Chat / PR。  
8. **朗读**：确认危机路径继续不朗读。
