## 0. 大白话（给拍板用）

现在「像不像在问产品」主要靠句子里有没有某几个词。所以两头都会错：闲聊和半句话被当成产品问题，答成「没有手册」；换个说法问冥想，又对不上词库里那句原话，同样答成「没有手册」。  
这份说明要把这两头收成同一件事：离任何一条已审核知识都很远的话，去正常现写；离某一条很近的话，就用那一条。真的像在问产品、但又对不上任何一条时，仍然诚实说没有手册，不许现编。  
两层怎么改、冥想那句用哪一条、漏检率降到多少算过，2026-09-26 已锁（见第七节）。在口令「按知识库近义匹配 Brief 开工」之前，用户现在听到的回答不变。

## 三、问题 1 · 近义匹配接在哪一层？

沿用闸门 Brief 已选的**方案 B**（独立二分类，不把产品问并进情绪那三桶）。近义匹配要补的是：正例不该是一堆宽泛问句，而该是「和某一条已审核短答有多近」。

| 做法 | 含义 | 优点 | 缺点 |
|---|---|---|---|
| 只改闸门 | 仍先问「像不像产品问题」，条目仍靠原句 | 闲聊误拦可能下降 | 换说法的科普题仍可能进闸后对不上，继续「没有手册」 |
| 只改条目 | 闸门照旧，条目改成近义 | 对得上的问法能出科普答案 | 闸门仍可能把闲聊判成产品问题，条目再远也出不了现写 |
| **两层用同一套近义** | 离最近一条已审核条目够近 → 命中那一条；都远 → 不当成产品问题，去现写；像产品问但最近条目仍不够近 → 诚实空态 | 两头症状同一把尺子 | 阈值要同时守住「不误拦」和「能接住」 |

**已锁（2026-09-26）**：第三种。同一套相似度同时当闸门和条目选择。只改其中一层会留下另一头。

## 四、问题 2 · 怎样同时不误拦、又接住换说法？

相似度只和**已审核、允许检索**的条目比（含其已收录问法），不和「凡是问句」比。

- 闲聊 / 半句话（骑自行车、Who is Duke number?、When I see so much）应离每条产品知识都远 → **不进闸** → 现写。  
- 换说法的科普题应离对应条目近 → **命中该条短答**，不念练习步骤。  
- 已经能对上的原句（`focus vs meditation`、What is ground exercise?）不得变差。  
- 累了、朋友闲聊，继续走现在已经正确的路，不得被吸进知识库。

阈值先做成可调参数。校准方法：用下面这张锚点表，而不是先写死一个分数。分数本身见文末待拍板。

### 验收锚点（2026-09-26 肉测原句）

| # | 用户句 | 期望来源 | 期望条目 |
|---|---|---|---|
| A1 | Today I'm going to ride bicycles… How about you? … | 现写 | 无 |
| A2 | Who is Duke number? | 现写 | 无 |
| A3 | When I see so much | 现写 | 无 |
| A4 | You are my good friend I like you how about you | 现写（已确认可以） | 无 |
| A5 | I don't want to practice today. I'm a little tired. | 累了的固定回复 | 无 |
| A6 | What is ground exercise? | 知识库 | KB-FUNC-0002 |
| A7 | focus vs meditation | 知识库 | KB-EDU-0003 |
| A8 | What is meditation? | 知识库科普 | KB-EDU-0003 |
| A9 | What's the difference between focus and meditation? | 知识库科普 | KB-EDU-0003 |
| A10 | What is the observation wing? | 诚实空态 | 无（库里没有这条） |
| A11 | 冥想这套东西对我根本没用，我快要放弃了 | 现写 / 情绪路径 | 无（主题词撞上 KB-EDU-0003，但是倾诉，不得吸进知识库） |

A8 备注：内容可接受。这条从「冥想是什么」讲起再收到和专注的差别，用来接 “What is meditation?” 说得通。语气会比直接定义绕一点。如果以后有用户反馈觉得答非所问，再考虑拆成两条。不要在实现时偷偷换正文。

A11 用来卡住「字面带了知识主题词、其实是情绪」这一类。相似度只看离条目够不够近时，这类句子有被误答成科普的风险。期望必须是现写 / 情绪路径。
