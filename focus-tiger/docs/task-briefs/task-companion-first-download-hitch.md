## 一句话

用户第一次打开宽屏 Confide、磁盘上还没有合格 GGUF 时，慢网下载不得让 Idle 呼吸掉帧；已下过的文件继续跳过。

## 已拍板（审计结论）

1. 下载由 Confide `ensureReady` 触发，在 Node 子进程；不是冷启动自动下。  
2. `ensureGgufDownloaded` 已按文件存在 + 最小字节跳过（Q2 磁盘侧已过）。  
3. L0「Focusing hitch 无可见影响」**不能**代替本条：那次不是首次慢网大文件下载。

## 要做（口令后才改代码）

2. **Q2**：继续内容/文件已在则跳过；禁止每次开卡重下一份副本。  
3. **Q3**：在低速网络（或限速）下看 Idle 呼吸 + 卡淡入，记录是否掉帧。只测下载成功 ≠ 完成。
