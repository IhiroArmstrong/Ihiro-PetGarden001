## 0. 大白话

用户自己说「我想几点前收工」——Yin 只陪这个目标，不判断熬夜、不推连续熬夜小时数。到点轻轻问要不要收尾；可以关、可以拒绝、拒绝后不追问。

## 1. 已锁边界（盘点 + 分析师 · 点头前勿删）

1. **新存储键**只存用户设的收工 `{ hour, minute }`（可空 = 关）。**禁止**写入现有 `reminder-preference` / 提醒族键。不新增「几点坐着」时间序列。
2. **收工邀请**须登记为 **T57 邀请族的新种类**，并受 **T58 暂停规则**约束（忽略/拒绝若干次 → 暂停数天；不得绕开「只许更安静」）。
3. **专注进行中让位**；**每日至多一次**收工邀请。与叠层让位、提醒族约一小时限频对齐，不另造第二套频控。
4. **Work Transition** 仅作用户点头后的**可选去处**；须处理**未解锁会员**（盘点 §2）。
5. 禁止对外：Yin 看出熬夜、连续熬夜 X 小时、改善作息习惯。
