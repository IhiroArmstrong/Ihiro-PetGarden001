## 1. 目标与非目标

### 1.1 本刀锁住的

1. **表面**：只改 `#` / `data-testid=yin-adaptation-notebook` 已有小本子。禁止新 z≥17 遮罩、禁止专注中邀请、禁止 toast 追问。  
2. **数据槽位句（级 3）**  
   - **晚间**：若 T62 同意开且观察纸此刻会有晚间句 → 小本子用**同一句**（同一数据槽，禁止第二套晚间 ledger）。T62 关则不出这行。  
   - **常用分钟**：`habitualFocusMinutes` 非空 → 一句填空（locale 切片，过契约）。无常用则不出。  
3. **提议—确认（级 4）**  
   - 仅当常用分钟非空，且该分钟尚无「要/不要」答复（或常用分钟已变、旧答复作废）。  
   - 问句只谈**开表前高亮**，禁止谈提醒钟点、收工、邀请暂停。  
   - **要**：记下 accepted；resolver 继续走第一刀常用档（倦短一档仍优先）。  
   - **不要**：记下 rejected；resolver **跳过常用档**，直到「拒绝时刻之后」的合格手动再次满足窗口规则（近 12 次、同一档 ≥3、严格第一）。倦短一档与上次回退不变。  
4. 新字段只进现有 `focus-tiger.pref-state-read.v1`（或同键扩展），进删除白名单，**不进** T54 研究分享。

- `habitualHighlightConsent`: `null | { minutes, choice: 'accepted'|'rejected', at }`
