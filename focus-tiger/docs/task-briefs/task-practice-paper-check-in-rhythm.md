## 0. 大白话

结束练习时，你可以点顺、乱、倦。现在这些点只进这台机器，观察纸上看不见。这一刀仍用同一张成长旅程详情、同一张练习观察纸，在同坐与呼吸卡下面加一行「这几天你点过哪一种」。没有点过就整行不出现。不叫成长分数，也不跟昨天比输赢。

## 1. 拍板锁

1. **只读 T52 已有账本**，不加新 `localStorage` 键、不加新计数器产品名。  
2. **只用结束打卡（`phase === 'end'`）**。中途打卡不进这行，避免一场两记。  
3. **窗口**：滚动 **7 个本地日历日**（含今天），与观察纸近窗一致。  
4. **每天至多一个标记**：该日若有多次结束打卡，用**最晚一次**。没打卡的日子不画叉、不标失败。  
5. **没有结束打卡（整窗 0 条）→ 整块省略**，不要三个 0。  
6. **禁止**：红黄绿、箭头、百分比、排名、「变好了 / 变差了」、折线图当成绩单。允许等宽的七个空位 + 文字标签（顺 / 乱 / 倦 或 en Ease / Restless / Tired）。  
7. **免责**：在现网 `PRACTICE_PAPER_DISCLAIMER` 上**加半句**，方向：记录是为了看见，不是拿来和昨天比。不另起第二条免责。  
8. **隐藏**：随练习观察纸隐藏开关一起藏。  
9. **实现 PR 须同批改** [`PRACTICE_PAPER.md`](../PRACTICE_PAPER.md)：写明允许只读 T52 账本；仍禁止新计数器、禁止健康分。未改锁不得写运行时。
