## 一句话

宽屏点底栏 `⋯`，必须先看到五个组图标。不得再因为角色层整块矩形碰到图标，就直接打开以前那种手风琴列表。

## 地面真相（本刀不重做扇形）

1. 五组扇 `#ft-wide-more-radial` **已在 develop**（#1307）。组名、分组、点击后的暖米玻璃列表、窄屏抽屉、付费锁行 **一律不改**。
2. 用户确认测的是底栏 `⋯`，**不是**右下指南针三叶 `#home-sanctuary-nav-fan`（Home / Calendar / Collection）。指南针本刀不动。
3. 现网点 ⋯ 常直接出整页列表，是因为 `shouldDegenerateWideMenuRadial` 用 `#sprite-stage` 的整块 `getBoundingClientRect()` 做相交。该层是全屏 overlay 里 `top:6%; right:11%; bottom:20%; left:11%` 的大盒子，普通 Electron / 桌面窗几乎总会和图标相交 → **主路径被退化吃掉**。
4. 高度下限 `innerHeight < 520`、顶安全区 12px、窄屏 `<480` 抽屉 **保留**。

## 已经定下的做法

1. **主路径（本刀验收）**：宽 ≥480 且高 ≥520 → 点 `#ft-wide-more-btn` → **0–1 秒内**见五个组图标（Practice & moments / Records / Quiet gifts / You are not alone / Preferences）。点一个组才出该组列表。
2. **退化只留两处**：`innerHeight < 520`；或任一图标顶缘 `< 12px`。这两种仍直接出手风琴列表，不画扇。
3. **删掉**「图标外扩 8px 与 `#sprite-stage` AABB 相交则退化」这一条。第三刀 Brief「宽屏形态」里那句同步改掉；几何半径 96 / 图标 44 / 角 95°–175° **不改**。
4. 不新开角落，不搬 `⋯`，不改 Support FAB，不改指南针。
5. 减弱动画、键盘、Esc 一层，仍按第三刀 Brief。
