# Task Brief · T43 适中陪伴窗 + 全屏静坐

> **状态（2026-10-24）**：PO 书面「立刻开工 T43」，并明示 **Brief 无需再点头**，本回合连贯执行。  
> **类**：**B**（电脑版主窗口尺寸 / 系统全屏会改；网页不变）。  
> **代号**：**T43**（电脑版十二条对照 #9 · 执行序 6）。  
> **分支**：`feature/t43-companion-window-fullscreen` · 基线 `origin/develop`（含 T40 #1406）。

## 一句话

电脑版加两个**系统窗口动作**：适中陪伴窗、全屏静坐。走 Electron 原生窗口，不自绘红绿灯。

## 已经定下的做法

1. **仅 Electron 壳**  
   - `window.desktopShell.isDesktop === true` 时，⋯ / 抽屉 Preferences 出现「窗口」行；托盘与 macOS Window 菜单同一套动作。  
   - Web / Safari `:5173` **不出现**该行、不改浏览器窗口。

2. **适中陪伴窗**  
   - 主窗口收到约 **420×720**、贴当前显示器工作区右下（边距 24px）。  
   - 已是陪伴窗再点一次 → 回到上次普通尺寸（默认 1100×760）。  
   - 若当时在系统全屏，先退出全屏再落到陪伴窗。  
   - 下次启动若上次离开时是陪伴窗，仍按陪伴窗打开（**不**自动进全屏）。

3. **全屏静坐**  
   - 调用系统 `setFullScreen`，保留系统标题栏与红绿灯。  
   - 再点一次、绿色按钮或 Esc，按系统行为退出。  
   - **禁止** `frame: false`、自绘窗口按钮、Document PiP、页内假全屏。

4. **设置形态**  
   - 玻璃卡复用暖米玻璃（与 T41 置顶卡同类），贴右下。  
   - 禁止 `NSPanel` / 系统 Sheet。

## 共用机制核对

- **overlayBusy**：不新增叠层源。核对后确认问候 / 切语不被本刀挡住。  
- **HUD 呼吸驱动**：不碰计时。核对后确认 Focusing HUD 呼吸仍由现网驱动者表负责。  
- **z-index / dim**：新增 `#window-layout-preference-panel` 登记 **z=18**（玻璃卡带），与置顶卡同带；**不** inline 压 Support 26。  
- **新建可点击叠层**：窗口卡与 `#always-on-top-preference-panel` 同类偏好卡，**不**进 `OVERLAY_UI_SURFACE` / overlayBusy。Esc / 点空白自关。不新增 dim。
