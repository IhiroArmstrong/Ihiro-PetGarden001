## 0. 大白话

心里乱时写下的那一句，要不要被分成「接住」「邀你坐一会儿」「说不清」，还是这几类在向量上看起来都差不多。本步只在实验室用现网同一套向量模型试。分不开 → 对外永远只留接住或邀你坐。高危仍走现网安全层。用户界面这一刀不动。

## 1. 目标与非目标

### 1.1 目标

1. 离线分离试验：四类内部标签 **hold（接住）** / **invite_sit（邀你坐）** / **unclear（说不清）** / **crisis（高危）**。  
2. 标定句必须落在方向锁点名的近义域：觉察、接纳、专注、公案意象。英文优先。  
3. 只用现网 **Qwen3-Embedding-0.6B**。禁止换 bge-m3。  
4. 高危类 **只复用** 现网 `CONFIDE_SEMANTIC_CRISIS_PROTOTYPES`，不新增症状名单。阈值 **0.78**，不得为刷过线而下调。  
5. 输出汇总 JSON（无原句、无向量）。`isolationPassed` 为否 → 产品对外仍只许接住 / 邀你坐；本 PR **不**改发送链。

### 1.2 过线标准（与开工同锁）

与 T66 第二步阶段 A 同形，但问的是四类产品标签，不是心念流板块。

| 项 | 线 |
|---|---|
| 每类标定 | n ≥ 8（crisis 用现网原型，已 ≥8） |
| 非危机三类复述 | 每类 n ≥ 4 |
| 凝聚 | 每类板内句对平均余弦 ≥ **0.40** |
| 分离 | 任意两类质心余弦 ≤ 两类板内平均余弦较小值 **减去 0.10** |
| 产品关键对 | **hold vs invite_sit** 必须过分离；失败则整项失败 |
| 高危误伤 | 非危机标定/复述对现网危机原型的最大余弦 **< 0.78**；任一 ≥0.78 → 失败。不另造分类器 |
| 判定 | 上列全部满足 → `isolationPassed: true`，才允许以后内部多用标签。任一条失败 → 对外永远只留接住 / 邀你坐 |

真 embedding 不进 `test:smoke`。CI 只锁评分器 + 夹具条数。实验室缺 GGUF 时 exit 2，不得写成已过线。
