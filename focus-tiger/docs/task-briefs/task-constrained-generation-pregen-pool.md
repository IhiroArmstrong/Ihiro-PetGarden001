## 0. 大白话

探针已经说明：你开口的那一瞬间再把模型装进内存，多半来不及。评估页选了「空着的时候先编好几句，开口只拿一句」。本 Brief 把怎么存、何时编、编几句、编坏了怎么办写成可实现规格。点头之前，屏幕上仍是仓库里的固定句。点头也不等于立刻红队或改倾诉。

## 1. 目标与非目标

### 1.1 目标（点头后才写代码）

1. **只内存、不落盘**：进程内每通道最多 3 条已校验短句（四通道合计 ≤12）。禁止 `localStorage` / 文件夹带原文。重启池空，回退检索。  
2. **空闲填池**：非 FOCUSING、非倾诉正在 generate、桌面 companion 允许且非低配。推荐窗口：到达之后、点 Sit 之前，或 Idle 且用户未开口。**禁止**在开口回调里 `ensureReady`。  
3. **生成完即 unload**（除非倾诉仍需要 resident）。专注期间池已在内存，**不**为此保持 GGUF。与现网「专注时立即卸模型」对齐。  
4. **开口只取用**：有可用句则展示并从池删除；同会话不复用同一变体。池空 → 现网检索/固定句，记 `pool-empty`。超时不得记成模型 timeout。  
5. **入池前校验**：`matchForbiddenPatterns`（与 CI 同一张表）非空则丢弃；超长 / 空 / locale 串扰丢弃。开口不再二次模型校验。  
6. **kill switch**：沿用 `FT_CONSTRAINED_GEN=off` / `?constrainedGen=0`；生产默认关。关则永不填池，恒为检索臂。  
7. **本机元数据、无原文**：填池成功/失败、池空、是否碰到 focusing（须为 0）。**不进** T54 白名单，除非另改 T54 Brief（本刀不做）。

## 3. 冲突扫描

对照：场景 B 再聚焦、Y 结束低语、觉照邀请、到达安静句、倾诉、专注时卸载、T54 分享、陪伴契约。

- **语气**：入池句仍过禁词表，不得另写更松的闸。  
- **职责**：不替代安全线；不加第五通道；不记生成原文。  
- **无未决冲突**（与 focusing 立即 unload **对齐**）。

## 点击反馈（0–1 秒）

本次不新增用户可点控件。开口仍是现网那些触发；用户点 Sit / 结束 / 回来时，0–1 秒内仍应看到**今天已有的**短句或邀请，不得因填池失败而卡住无句。

| 控件 / 入口 | 点击后 0–1 秒内用户看到什么 | 持久化 |
|---|---|---|
| 现网开口（邀请 / 低语 / 再聚焦 / 到达句） | 与今天相同的出现方式；句子可能是池变体或固定句，用户分不出「正在生成」转圈 | 无原文落盘。失败 → 固定句，不空白 |
| kill switch / 无新钮 | 无新点击 | — |
