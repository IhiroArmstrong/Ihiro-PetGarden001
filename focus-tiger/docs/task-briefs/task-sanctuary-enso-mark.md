## 位置与视觉规格（解决「隐约」↔「彰显」张力）

> 用户拍板：**放在蒲团中间**，像镶嵌的大徽章——不是边缘微点。

| 规格 | 验收锚 |
|---|---|
| 锚点 | 蒲团几何中心（相对 Yin 坐垫 DOM / 舞台坐标；开修时量一次写进注释）→ **已量**：idle `frame_001` 相机可见正面 ≈ 自然坐标 `(552, 770)` / 1056×864（质量中心约 y=730，为可辨改钉正面） |
| **直径** | **蒲团可见直径的约 10%**（相对 2026-08-13 的 25% 再缩至约 40%）。须落在蒲团正中央、**不超出蒲团边界**、不盖袍/手；375 仍 ≥ ~20 CSS px |
| **默认透明度** | 盘体 **opacity 0.78–0.88**；勿低于 0.65（375 上会「看不见」） |
| Focusing | 可降至 **0.45–0.55** 或短暂隐藏——不挡计时感知；Rise 回 Idle 恢复默认 |
| Hover / 点按（可选） | 宽屏 hover：**opacity → 1.0** 约 180ms；点按**不**开商店（避免误触推销）。身份说明放 Settings 一句即可 |
| 层级 | 在蒲团纹理之上、Yin 躯干之下或与蒲团同层居中——**不得**盖住脸/眼；登记 `Z_INDEX.md` |
| 多分辨率 | 必测：**宽屏** + **375** + 真机若有。375 上盘径须落在蒲团内且 ≥ 约 20 CSS px |
| 文案 | 默认无气泡；Settings 可「Enso mark · Sanctuary」；禁夸耀成就腔 |
