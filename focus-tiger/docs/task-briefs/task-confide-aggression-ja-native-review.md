## 一、请你审什么

**一条** Confide 回复文案的日文版（`aggression-02`，池内**首选**、出现频率最高）。

用户刚说的话示例（触发路由，**不是**要你写的回复）：

- 中文：`我想打人` / `想打人`
- 日文：`人を殴りたい` / `殴りたい気分`

阿寅（陪伴角色）需要回一句**极短、克制、不评判、不默许攻击行为**的承接句。当前日文是 PO 改稿占位，**需要你判断语感是否自然**，并在必要时给出更好的说法。

## 二、硬性约束（审阅时不得违反）

### 2.1 禁止默许 / 点头 / 危机转介

| 禁止 | 说明 |
|---|---|
| 「聴いた」「うなず」等点头默许类 | 不得像认可用户要去打人 |
| 危机热线 / 专业转介全套 | 这是**他人攻击意图**桶，不是自伤 `safety_redirect` |
| 说教、命令、道德评判 | 不得「你不该打人」式训斥 |
| 鼓励或纵容攻击 | 不得暗示「打吧」「理解你想揍人」 |

### 2.2 禁止 L3 生成

本路由只走**固定语料池**，不走本地模型 generate。你审的是池里那一句，不是 prompt。

### 2.3 动画

用户看到回复时，阿寅**保持 Idle 呼吸**，不播鞠躬/点头 oneshot。文案不必写动作，但语气不要像在点头认可。

### 2.4 ⚠️ 禁止「打 / 敲 / 撞击」类动词词根（**最重要 · 易漏**）

**改稿时不要把动词换回带「打、敲、撞击、殴」意象的词根。**

包括但不限于：

- `当たる` / `当たっている`
- `たたく` / `叩く`
- `殴る`
- 以及任何让读者联想到物理击打、撞击的表述

**原因（请务必读）**：这条回复本来就是回应用户刚说的「想打人 / 人を殴りたい」。若在安抚句里意外复述「打 / 击 / 撞」的意象，等于在承接语里**重复攻击画面**——哪怕语法正确、语感更顺，也是产品红线。  
PO 改上一版稿时**刻意避开**了这类词根；母语者若只顾「读起来更自然」，很容易顺手改回更顺口但带击打意象的说法。**这不是语法问题，审阅者不会自动意识到要避开，必须在改稿时主动检查。**

**可接受的方向**：用「影响 / 吃不消 / 很难受」类无暴力联想的动词，例如 `こたえる`（被某件事深深影响到、吃不消），而不是「被什么东西打到了」。

## 附录 · 当前稿为何换掉上一版

上一版日文：`何かが、とてもきつくのたたいている。`

- 语法有问题（`きつくの` 不成立）
- 更严重：`たたく`（打）词根出现在回应「想打人」的句子里，构成攻击意象复述

故改为 `こたえる` 路线。你的润色须在**不引入 §2.4 词根**的前提下进行。
