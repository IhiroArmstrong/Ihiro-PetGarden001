# Task Brief · 宽屏 ⋯ 扇形 150°（加大圆心角与间距）

> **状态（2026-11-14）**：**PO 已锁几何**（本对话：窄屏抽屉不动；宽屏 150° 扇形；最右球贴水平面；向左每隔 30° 一球；5 球 = 150°；日后一级项在 150° 上均分）。**类：B**。  
> 口令「立刻开工」= 按本页改 `wideMenuRadialLayout.js` + 宽屏扇形标签，**不得**重开已合的五图标第三刀（#1307 / T25）。  
> 前序 SSOT：[task-wide-menu-radial-index.md](./task-wide-menu-radial-index.md)（分组、点组才出列表、矮窗退化仍有效）。本页只改**扇面几何与组名画法**。

## 一句话

宽屏点「⋯」后，五个组图标沿 **150°** 扇面展开：最右一颗与「⋯」同一水平线，其余向左每 **30°** 一颗；组名只画一层，贴在球外侧，互不叠字。窄屏仍是底部抽屉。

## 已经定下的做法

1. **窄屏（宽度 &lt; 480）**：不改。继续 `#ft-narrow-options-drawer`。
2. **锚点**：仍是 `#ft-wide-more-btn` 中心。不新开角落，不搬左上。
3. **扇面**：从正右水平 **0°** 起，逆时针（向左、向上）跨 **150°**。  
   - n 个一级组：步进 = `150 / n`（n=5 → 30°）。  
   - 现网五组角：`0°, 30°, 60°, 90°, 120°`（数学：`cx = ax + cosθ·R`，`cy = ay − sinθ·R`）。  
   - 日后加减一级组：只改组表，角由公式重算，扇面仍 150°。
4. **半径**：提到 **152px**（图标仍 44px），让 30° 弦长大于球直径，球与球之间留空。
5. **组名**：展开后**常驻**在各球外侧（沿半径向外）。**禁止**再给同一球挂 `attachGlassHoverTip`（截图里两套「Practice & moments」叠字的根因）。悬停/聚焦只加强该球，不另开全局气泡。
6. **点一下**：仍是点组图标才打开该组暖米玻璃列表（不改为悬停开列表）。
7. **退化**：矮窗 &lt;520px、或任一球顶/左/右被切出安全区（12px）→ 仍直接列表、不画扇。不得用 `#sprite-stage` 整块相交来退化。
8. **不挡坐下主球**：1280×800 / 1440×900 / 1280×720 上任一扇球不得与 Sit 主球外接圆相交（现有单测保留）。
9. **减弱动画**：`prefers-reduced-motion: reduce` 时仍只淡入。
10. **不改**：Support 五卡、付费行、分组表、窄屏抽屉、菜单逃生舱、z-index 登记（扇层沿用现网）。

## 已好清单（不变量）

- 宽屏够高时先出五个组图标，再点组出列表。
- 窄屏只有抽屉。
- 点组 0–1 秒内出现该组列表；Esc 只关最上一层。
- Sit 主球可点、不被扇球挡住。
