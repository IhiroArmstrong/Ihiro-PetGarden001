## 0. 大白话

很多天人不想开表，只想被问几句「此刻怎样」。产品里已有坐下前的 Notice 和练完三问，还缺这一扇**独立小门**。第一版只用审过的固定问句，按日期轮换；阿寅不下结论。有严重痛苦时，仍走已经做好的倾诉安全层。

## 2. 拍板已锁（PO 2026-11-26）

1. **入口**：不坐下也能打开；1～3 分钟；可跳过；**无连签、无红点愧疚**。  
2. **问句**：固定句库（locale 切片）；按 `dateKey` 轮换，近 N 日不重复（实现锁 **N=7**）。  
3. **零生成**：不问模型写问句、不写总结。收束句也来自固定池。  
4. **不下结论**：禁止「你今天焦虑了」类回声。观察式，过 **C-01**。  
5. **危机**：用户作答命中现网安全层 → **Layer 0**（T90–T92）；卡上 **G2 求助入口可见**。不得另造分类器。  
6. **验收复用四闸**，不发明第五套：见 §8。  
7. **首包**：本刀 **必须**进成长最小闭环；做不完则顺延包装，而不是砍掉本刀硬发。

我认为最合理的入口是 **Inspiration / 与觉察一句同组的菜单行 + 可选 Idle 轻入口（不新 FAB）**。弱方案：绑在 Sit 里（用户明确不要）；新首页大按钮（抢坐、膨胀）。

### 2.1 候选四问（审题用 · 实现进 locale 前须 G4）

1. What is happening within you right now?  
2. What emotion is most present today?  
3. What has been occupying your mind?  
4. What do you need to give yourself today?  

单日默认出 **1** 问（可「再看一句」最多到 4）。中文/日文观察式译法本刀 locale 切片；禁止临床词。

## 6. 点击反馈（A14）+ 边缘状态

| 控件 | 0–1 秒 | 持久化 |
|---|---|---|
| 打开入口 | 菜单行按压 + 卡开始淡入 | 无 |
| 作答确认 | 钮按压；下一问或收束 | 本机 `focus-tiger.daily-noticing.v1` |
| Skip / 关闭 | 卡收起 | skipped；无愧疚 toast |
| 危机命中 | 切到现网安全表面 | 不把危机原文写入觉察账（与倾诉「不存原句」对齐：本机可记 dateKey+crisisRouted:true，**不**记原文） |

| 边缘 | 预期 |
|---|---|
| 写盘失败 | 卡仍可关；不弹系统错误墙 |
| 无本地 AI | 本刀不依赖模型，行为不变 |
| 日语觉察一句仍隐 | **本入口仍可**（自我觉察 ≠ 倾诉）；若 PO 要日语一并隐，须本 Brief 补句——默认 **不隐** |
