## 一、目标

用户在倾诉（Confide）里问到「怎么开始坐」「接地练习在哪」这类**产品功能类问题**时，阿寅能给出**准确的指路短答**，而不是：

- 凭训练知识/记忆编一个可能过时或错误的答案
- 生成一段自己的操作教学（和已有 UI/知识库内容产生「第二套真相」）
- 沉默/答非所问，让用户觉得阿寅不懂产品

## 二、非目标（Non-goals）

- **不做开放问答**。只覆盖知识库里 `yin_may_retrieve: 是` 且 `审核状态: 已通过` 的条目；库外走现有 Confide 兜底，本 Brief 不重新定义。
- **不生成长文/教学/引导语**。命中后只输出短答或指路；接地、呼吸等练习的具体步骤绝不展开。
- **不覆盖急救型心理练习**。当前 `yin_may_retrieve: 否`；任何代码路径不得绕过该标记。
- **不做内部排障库接入**。Known Errors / 错误码不进倾诉生成。

## 三、已拍板的关键问题

### Q1 · 命中后原样念，还是转述？ → **方案 A：原样 / 模板输出**

- **结论**：知识库短答直接作为回复，**不走 L3 二次生成**。与 CI-00/02/03、语料 fail-open 一致：事实类路径不交给模型自由发挥。
- **「像阿寅」**：允许固定前缀/后缀壳句包裹短答（贴 Confide 已有模板风格）；**不允许**自由 paraphrase。
- **对正文的要求**：条目正文须是可直接对用户念的最终话术，不是待加工要点。`locale_keys` 继续绑定真实 UI 字符串键。
- 若语气仍生硬，先扩展壳句库，**不要**退回方案 B（转述）——方案 B 需审计字段（命中条目 id + 转述前后 diff）与防跑偏 guard，成本高，与「不新造第二套真相」冲突。

### Q2 · 命中阈值 → **高门槛；半命中只给指路**

- 置信度不够 → **未命中**，宁可不答。
- 问练习**步骤细节**、库里只有入口指路 → **半命中**，仍只输出指路短答；禁止 `RESET_GROUND_*` / `RESET_BREATH_*` 等引导语正文（与 KB-FUNC-0002 防呆一致）。

### Q3 · 未命中 → **记日志；回应走现有 Confide 策略**

- 未命中须可查（`turns.jsonl` 或专用 `kb_retrieval_miss` 事件——实现任务定 schema）。
- 本轮怎么回用户：L3 / 沉默 / 如实不确定等**现有**策略；本 Brief 不新定义兜底话术。
- 回流：建议双周或按未命中 Top N 复盘，决定是否补盘点条目。

### Q4 · 检索范围 → **单一闸门：`yin_may_retrieve: 是` ∧ `审核状态: 已通过`**

- `所属库` 是管理分类，**不额外限制**检索范围。
- 0003（备份）、0005（结束倾诉）已标 `yin_may_retrieve: 是` → 人审通过后与 0001/0002/0004 **同批可检索**，不单独延后。

### Q5 · 触发条件 → **Electron 宽屏 + 意图门闩；避让 embedding / 同坐卸载**

- 仅桌面宽屏；Web/窄屏不开。
- **非每轮都检索**：先过「像是在问产品功能」的规则/轻量分类（可与语义路由共用门闩，实现任务再拆）。
- **风险点**：同坐时本机模型卸载保流畅；若检索依赖 embedding，须评估与卸载窗口/embedding 工作闸是否冲突（见 `confide-embedding-lifecycle-arbitration.md`）。实现任务单独评估，本 Brief 不下技术结论。
