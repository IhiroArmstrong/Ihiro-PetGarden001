## 0. 大白话

日语倾诉还没开放时，用户会看到「还没有开放」的固定句。如果分类器没认出危机，这句话里本来没有求助入口。本刀只在这句后面接上已经合入的 T92 求助句（请拨打本地热线 / 紧急电话，不写号码）。不判断分数。

- 在 `language-not-yet-open` 三语文案末尾追加 `formatConfideSafetyResourceGuidance`（与 safety-01 同一套）。
- 明确自伤（如 `死にたい`）仍走 safety-01，不改成未开放。

## 2. 不做什么

- 不改 `0.78`。
- 不按症状扩名单。
