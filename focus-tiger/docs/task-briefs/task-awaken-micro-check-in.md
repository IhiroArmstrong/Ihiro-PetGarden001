# Task Brief · T52 觉照微打卡（你自己说感受）

> **状态（2026-10-23）**：Brief 待点头。依赖 **T51** 邀请表面或独立角落触点；不得阻塞 T51 合入。  
> **类**：B 类。  
> **口径**：`DESIGN.md`「觉照邀请」第 3 条。

## 一句话

一场结束问一次「现在更像哪一种」：顺 / 乱 / 倦。中途最多每天几次、几秒不理就消失。点一下只留下本地标签，用来以后校准何时该邀请，**不**显示分数、**不**宣布用户状态。

## 已拍板

1. 三种足够，不用李克特量表。  
2. 会话结束 1 次 = 主路径（零打扰）。  
3. 中途仅在状态**突变候选**时出微光，每天主动打卡 ≤ 4 次；10 秒不理消失（**SB-20** 同类）。  
4. 禁止把标签写进用户可见总结成「你今天焦虑了」。

## 冲突扫描

对照场景 **A/L** 结束庆祝、**C** 中途放弃、Reflection 三问、Honesty、Confide。

| 轴 | 结论 |
|---|---|
| **a. 强度** | 结束打卡必须 **轻于** Reflection；不得挡住 Skip / Continue。中途打卡轻于 T51 邀请。 |
| **b. 语气** | 三种姿态/短词，观察式；禁止诊断句。 |
| **c. 职责** | ≠ Honesty 补登；≠ Reflection 三问；≠ Confide。只校准邀请时机。 |

结束打卡与 Reflection **可同屏短暂共存**，但不得盖住 Reflection 主按钮。若冲突，**让位 Reflection**（本刀写死）。
