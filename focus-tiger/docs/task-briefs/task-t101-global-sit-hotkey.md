> **状态**：**排队中** · Brief 待点头 · **无运行时**（点头后另开实现旁支）。  
> **代号**：**T101**。人话：电脑已开着或收在菜单栏时，按一组全系统快捷键就能开始坐，不必先点进窗口。

## 0. 大白话

现在电脑版只有窗口在前台时，空格才能开始。Mac 用户最容易感到「离不开」的，是在别的软件里按一下就能坐下。本说明书把默认组合键、忙时拒绝、以及不得抢走语音按键写死。点头之前不改安装包。

## 2. 拍板建议（点头即锁）

1. **默认组合**：`Control+Option+S`（Sit）。**禁止**占用 `Control+Shift+Y`。  
2. **行为**：已在托盘或前台 → 0–1 秒内走与点 Sit / 深链 `start=sit` **同一内部 action**；默认本场 5 分钟（不写回稳定偏好）。忙（付款 / 倾诉 / 正在专注）→ **拒绝**，前台轻提示，不排队。冷启动未过 T76 四选 → 先唤窗走到达，再应用一次（与深链 defer 同形）。  
3. **可改键**：第一刀允许写死默认；Preferences 改键可第二刀。系统快捷键冲突时提示「这边用不上这组键」，不得静默。  
4. **退出后**：已 Quit → 快捷键无效。本刀 **不做** 登录时自动开。  
5. **网页**：无全局快捷键。网页用户走深链 / 空格。

我认为最合理的是：**Control+Option+S + 与深链同一 action + 忙时拒绝。** 弱方案是复用 Control+Shift+Y（会拆掉按键说话）。
