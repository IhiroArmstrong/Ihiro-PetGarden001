## 0. 大白话（给拍板用）

同一句话现在会被五处规则先后接走：字面正则、目录命中、产品闸、情绪否决、近邻。排在前面的先赢，所以生活句会念成「没有手册」，徽章句会念成赚币短答。

要改成：**一次算分，一个函数决定**。先只记影子，和今天的回复对照。你点头并带上回滚开关之后，才许改用户听到的话。

「句子里同时有问法词和产品词就不否决」**不要做成新正则**。改成看 **产品分是否明显高于情绪分**。

评测守 [PRINCIPLES.md](../PRINCIPLES.md) **R-0**：冻结集不退步，加上封存盲测通过。只拿实验室里调过的那十几句过关，不算过关。

## 一、目标

1. **一次 embedding**（已装的 Qwen3-Embedding-0.6B）同时打出各库分数：情绪 / 生活、产品 / 目录近邻、闲聊距离。安全 / 危机 / 他人攻击 / 边界仍在语义之前，本函数 **不可达**。  
2. **一个纯函数**按「安全已排除之后：情绪 / 生活自述 > 产品短答或诚实空态 > 闲聊 / 观察翼」做决定。目录命中、近邻命中也必须过这道分，不能再「命中了就念」。**情绪句与产品句之间按打分裁决，不按下方路由表层序**（表把倾诉写在产品之后，那是 Prompt 16 骨架里本函数钉在哪一层；不是「先产品后情绪」）。  
3. **前两刀**（影子即可开工，切 live 另点头）：  
   - 情绪否决：生活 / 情绪句不得进产品诚实空态。  
   - 目录误命中：情绪自述不得念成产品短答；徽章≠寅币不得念赚币短答（改回复前再确认一次空态）。  
4. **否决收窄**：产品分明显高于情绪分 → 走产品路径。不是「问法词 + 产品名词」关键词。旧规则 1 / 窄规则 1 **不接发送链**（CR-02）。  
   - **「明显高于」定义（冻结）**：差值门槛 `product_minus_mood_margin` **只在冻结集 + 中文开发集上定**，写入本 Brief 后冻结。盲测跑完 **不得再调**（调门槛 = 盲测泄露）。数值见下文「已冻结门槛」；现网 `DEFAULT_CONFIDE_KB_MOOD_VETO_MARGIN` 仍为 0，本门槛只用于影子仲裁 / 路由类实验室。  
   - **差距不足**：产品分未高出情绪分达该门槛时，**默认不走产品路径**（走情绪 / 观察翼或闲聊）。误把生活句念成「没有手册」的代价，比把含情绪措辞的真产品问放走更伤。  
   - **混合句与「产品高于情绪」**：对照集里这两类太少（混合 2 句、产品分高于情绪 3 句），只够回归。盲测须把它们**各自成类**，每类约 **60** 句，用来量这把刀的代价。  
5. **近邻多问法**：并进 Prompt 18 已锁的同一把尺子（离已审条目够近才命中；中间带仍按 Prompt 18 第九节，不放低 0.80）。

### 路由顺序（与 Prompt 16 骨架一致，本 Brief 钉仲裁职责）

| 顺序 | 层 | 本仲裁 |
|---|---|---|
| 1 | 安全 / 危机 / 他人攻击 | 不可达 |
