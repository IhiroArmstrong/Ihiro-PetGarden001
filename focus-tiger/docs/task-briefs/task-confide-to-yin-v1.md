## 分类硬约束（防走偏）

1. **分类器不得「发挥」**：只做明确规则匹配（关键词 / 短语表 → 路由）。  
2. **禁止**模糊打分选「最高分标签」硬凑。  
3. **匹配失败 → 固定兜底路由**（单一 `fallback` / `quiet_presence` 桶）：统一走向「阿寅安静地点头 / 抿茶」类回应 + 通用倾听短句池；**不得**猜测最接近标签。  
4. 多关键词同时命中：用**显式优先级表**（写死在配置里），不是相似度排序。  
5. **安全优先于情绪桶（强制）**：见下一节；安全层命中时 **不得** 再走情绪桶或禅意 `fallback`。

## 危机安全阀（MVP 骨架必留 · 2026-08-10）

> **问题**：自由文本倾诉可能出现远超日常情绪桶强度的内容（自伤 / 自杀念头 / 严重危机描述）。若只靠现有情绪关键词，常会 **无匹配 → `fallback` →「茶还热着」**——在需要负责任引导的时刻给出温柔但未接住的禅句，产品风险不可接受。  
> **不做**：运行时危机干预对话生成、假装心理咨询 / 专业救助、临床诊断或风险评估打分。  
> **要做（轻量 · 与「检索不生成」兼容）**：

| 项 | 口径 |
|---|---|
| 层位置 | `confideClassify.js` 内 **独立优先层**（先于 `anxious`/`tired`/…/`fallback`） |
| 机制 | 纯关键词 / 短语表（多语表可分阶段；先 en+zh 亦可） |
| 命中路由 | 固定 route id（建议 `safety_redirect`）——**不是**情绪桶 |
| 回应 | **唯一**人工写好的静态文案池（温和确认在场 + 建议联系专业人士 / 当地热线等资源提示）；**禁止**抽禅意语料 |
| 姿态 | 可极轻（如安静点头）；**禁止**庆祝 / 玩笑姿态 |
| 文案审稿 | 与倾诉禅句同级人审；未 `ok` 前不得挂完整倾诉发送（或发送后安全层必须已接线且文案 `ok`） |
| 诚实边界 | UI / 文案须避免「我们能帮你度过危机」类承诺；只做**转介提示**，不做治疗 |

**分类流水线（实现时锁死顺序）**：

```text
空文本 → 禁用发送（不进分类）
  → safety_redirect 关键词层（命中则停）
  → 情绪桶规则（anxious / tired / stuck / sad / scattered；显式优先级）
  → fallback
```

单测至少锁：① 安全关键词 → 必 `safety_redirect`、不得 `fallback`；② 无匹配 → `fallback`；③ 禁止 score 选桶。

## 语料库 · v1 最小情绪标签集

人工打磨；en + ja + zh 同构键。**样板桶**（`fallback` + `anxious`）六句 + **对齐四桶**（`tired`/`stuck`/`sad`/`scattered`）12 句已于 2026-08-10 全部 `ok`（语料门闩解除 · #222）。见 `docs/confide-corpus-seed.md`。

| 桶 / 路由 id | 粗粒度语义 | 示例触发词方向（实现时再落表） |
|---|---|---|
| `safety_redirect` | **安全优先路由**（非情绪桶） | 自伤 / 自杀 / 结束生命等危机向短语（表另立；勿与日常 sad 混桶） |
| `anxious` | 焦虑 / 紧绷 | 焦虑、担心、慌、紧张… |
| `tired` | 疲惫 / 耗尽 | 累、疲惫、困、撑不住… |
| `stuck` | 卡壳 / 停滞 | 卡住、卡住了、没思路、走不动… |
| `sad` | 低落 / 难过 | 难过、失落、心里沉、depressed、抑郁…（日常低落自述；**不是**临床诊断桶） |
| `scattered` | 分心 / 杂念多 | 心乱、静不下来、东想西想… |
| `fallback` | **唯一禅意兜底** | 无匹配时的温和收束；**不得**承接安全层应拦截的内容 |

**禁止桶**：单独开诊断式桶（把「抑郁/强迫」做成临床标签池）、评判式（「你不专注」）、教练式行动清单。日常自述 `depressed` / 抑郁 **并入现有 `sad` 语料**，禁止因此新开诊断桶，也禁止升格 `safety_redirect`。  
（`safety_redirect` 不是情绪桶，而是转介路由；禁止把它做成「危机共情禅句」池。）

**2026-08-22**：情绪类输入不得落入桌面第 3 层生成兜底；对不上的非情绪闲聊才允许短生成。单独 `help me` 不进词表。

## 语料措辞硬约束（2026-08-10 样板审稿补）

1. **承接，不建议**：禁止「不必修好 / 不必立刻解开 / 别担心 / 会好的」等替用户下结论或指导处理节奏的半句。只留意象或确认在场。  
2. **禁止呼吸 / 身体动作指令式短句**：如「呼吸来，呼吸去」「跟随呼吸」「吸—呼」——易被读成正念指导脚本，靠近「不是教练」红线。环境流动意象（风、茶、灯）可代替。规模化时**禁止**把呼吸引导写成可复用句式池。  
3. **不复读情绪标签**：禁止「我感觉到你很焦虑」类客服共情。  
4. 样板锚点句：`fallback-01`「听见了。寅安静地点头。」；anxious 流动意象示范：`anxious-03`「寅在这儿。风来了，风走了。」（**不用**呼吸版）。  
5. **安全路由文案例外**：允许明确、克制的资源转介句（专业人士 / 热线）；仍禁止假装治疗、诊断、恐吓。

种子稿状态见 `docs/confide-corpus-seed.md`（禅意 18 句均为 `ok`；`safety_redirect` 文案另槽，随 MVP 人审）。
