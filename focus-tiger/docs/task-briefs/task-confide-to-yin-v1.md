# Task Brief · 向阿寅倾诉（Confide to Yin）v1

> **状态（2026-08-10）**：文档定稿 · 分支 `docs/confide-to-yin-decision`。**本回合无运行时**；MVP 实现另开 `feature/confide-to-yin`。  
> **目的**：用户主动倾诉时，阿寅以「禅意倾听者」回应——**分类 + 语料检索**，禁止运行时生成对用户说话。

## 拍板摘要（2026-08-10）

| 项 | 口径 |
|---|---|
| 角色 | 禅师机锋 / 温暖茶友；**不是** AI Coach、百科、答疑客服 |
| 90% | 规则 / 模板 + 既有姿态（如 `teaDrinking`、点头）+ 短禅句 |
| 10%「向阿寅倾诉」 | **仅用户主动触发**；本地分类 → 人工语料库检索；短回应（约 30–50 字量级） |
| AI 合法位置 | **仅**离线批量扩写候选语料 → **人 review 后入库**；禁止运行时生成对话 |
| 入口（v1） | **A**：Idle 宽屏 ⋯ / 窄屏抽屉显式项（仪式感一次点击） |
| 分类（v1） | 规则 / 关键词；不够用再另立项轻量分类器 |
| 隐私 | 倾诉文本**不出设备**；不做人格 / 心理分析 / 趋势标签化 |

## 与既有能力边界

| 能力 | 关系 |
|---|---|
| Tiger Reflection Moment 三问 | **不动**；会话后可选反思 |
| `REFLECTION_ECHO_*` | 交题后通用共鸣；**不是**主动倾诉 |
| Focusing Tiger Anchor | Focusing 轻触阿寅 = Recover；**不**占用 Idle 倾诉入口 |
| Daily Wisdom / Quiet Line | 内容池并存；倾诉语料**分池**，禁止混用成「金句菜单」 |

## 分类硬约束（防走偏）

1. **分类器不得「发挥」**：只做明确规则匹配（关键词 / 短语表 → 情绪桶）。  
2. **禁止**模糊打分选「最高分标签」硬凑。  
3. **匹配失败 → 固定兜底路由**（单一 `fallback` / `quiet_presence` 桶）：统一走向「阿寅安静地点头 / 抿茶」类回应 + 通用倾听短句池；**不得**猜测最接近标签。  
4. 多关键词同时命中：用**显式优先级表**（写死在配置里），不是相似度排序。

## 语料库 · v1 最小情绪标签集

人工打磨；en + ja + zh 同构键。**样板桶**（`fallback` + `anxious`）六句已于 2026-08-10 全部 `ok`（语气基调门闩解除）。其余桶仍须每桶 ≥3 条 `ok` 后才可完整上线；见 `docs/confide-corpus-seed.md`。

| 桶 id | 粗粒度语义 | 示例触发词方向（实现时再落表） |
|---|---|---|
| `anxious` | 焦虑 / 紧绷 | 焦虑、担心、慌、紧张… |
| `tired` | 疲惫 / 耗尽 | 累、疲惫、困、撑不住… |
| `stuck` | 卡壳 / 停滞 | 卡住、卡住了、没思路、走不动… |
| `sad` | 低落 / 难过 | 难过、失落、心里沉… |
| `scattered` | 分心 / 杂念多 | 心乱、静不下来、东想西想… |
| `fallback` | **唯一兜底** | 无匹配 / 空文本拒绝后的温和收束（空文本应禁用发送，不进分类） |

**禁止桶**：诊断式（抑郁/强迫等临床标签）、评判式（「你不专注」）、教练式行动清单。

## 语料措辞硬约束（2026-08-10 样板审稿补）

1. **承接，不建议**：禁止「不必修好 / 不必立刻解开 / 别担心 / 会好的」等替用户下结论或指导处理节奏的半句。只留意象或确认在场。  
2. **禁止呼吸 / 身体动作指令式短句**：如「呼吸来，呼吸去」「跟随呼吸」「吸—呼」——易被读成正念指导脚本，靠近「不是教练」红线。环境流动意象（风、茶、灯）可代替。规模化时**禁止**把呼吸引导写成可复用句式池。  
3. **不复读情绪标签**：禁止「我感觉到你很焦虑」类客服共情。  
4. 样板锚点句：`fallback-01`「听见了。寅安静地点头。」；anxious 流动意象示范：`anxious-03`「寅在这儿。风来了，风走了。」（**不用**呼吸版）。

种子稿状态见 `docs/confide-corpus-seed.md`（样板六句均为 `ok`）。

## MVP 实现切片（文档定稿后另开 feature · 语气基调已解除）

1. Idle ⋯/抽屉入口 + 轻量面板（单行/短文本输入 + 发送 + 关闭）。  
2. `confideClassify.js`：规则匹配 → 桶 id 或 `fallback`（单测锁：无匹配必 `fallback`；禁止 score 选桶）。  
3. `confideCorpus.js` + locales / content 池：按桶取一条（日盐或会话内不重复）。  
4. 可选姿态：`nodBow` / `teaDrinking` / `mindfulAcknowledge`（低打扰；Celebrating 等高等级期间入口隐藏）。  
5. 存储（若需要）：仅本地最近 N 条；**不做**趋势分析；键名进重置白名单。  
6. 门闩：Arrival / Focusing / Honesty / Reflection / 微仪式期间 **隐藏或禁用**入口（禁止静默 return）。  
7. TEST_TRACKER + 单测：主路径 + 回流 + **无匹配 → fallback** 失败用例。

## 明确不做（本 Brief）

- 运行时 LLM / 端侧生成模型下载  
- 模糊相似度 / embedding 检索（未另拍板前）  
- 轻触阿寅作倾诉入口（留给未来其它 Idle 轻反馈）  
- 把倾诉塞进 Reflection Continue  
- 付费门 / Buy Tea CTA 挂在倾诉回应上  
- 情绪治疗、危机干预产品承诺（文案须保持观察式；危机场景只给通用陪伴句，不假装专业救助）

## 验证假设（实现前须心里有数）

主动倾诉触达率未知。若模板期参与率长期极低，入口优先级可后调——**不**因此提前上生成式。语料质量 ≫ 分类「智能程度」。
