# Task Brief · Voice Command Slice 3（坐着时说一句，等于点 Rise）

> **状态**：待 PO 点头。**无运行时。** 点头前禁止改解析器、麦克风、开始专注或结束专注。  
> **上游**：[`task-voice-command-routing.md`](./task-voice-command-routing.md) Slice 0–2 已在 `origin/develop`（#1008 规则、#1015 麦克风与开始专注、#1017 缺时长 chip）。本文件不改那些已拍板口径。

## 这一刀只做一件事

人已经在坐（专注进行中），用英语说「坐完了」，效果与点 **Rise** 相同。

不新增第二种结束方式。不把这句话做成「撤销刚才用语音开的那场」。

## 已建议、待你点头

| 项 | 口径 |
|---|---|
| 动作 | 仅 **结束当前这场**。走现有 Rise：未达标不庆祝、不记完成；伸懒腰后进 Reflection。对照场景 C。 |
| 禁止走的路 | 语音撤销条那条路（关掉计时、跳过 Reflection、再打开时长板）。那只留给撤销条上的 Undo。 |
| 何时听得懂 | 只有 **正在专注** 时，结束句才执行。时长板开着、还没开表、Idle、Arrival、Reflection：红字拒绝，界面不动。 |
| 句式 | `I'm done` / `End focus` / `End this focus` / `Rise`。 |
| 仍然拒绝 | 单独的 `Stop` / `Cancel`（含进行中）。避免一声误识别就结束，也避免和撤销条抢含义。 |
| 麦克风 | 同一颗麦、同一道门（英语界面 + Electron / macOS 宽屏）。专注进行中，麦出现在 **已有 Rise 旁边**。不新开浮层。时长板上的麦保持只负责「开始坐」。 |
| 解析 | 仍是关键词规则。不调本机陪伴模型。无 TTS。无云端。 |
| 点击后 0–1 秒 | 说完并识别为结束句：与点 Rise 相同，伸懒腰开始，专注不会静静继续。听不清或拒绝：红字，这场继续。不在静默白名单。 |

## 句式（本刀 golden set）

| 用户说 | 正在专注 | 没在专注 |
|---|---|---|
| I'm done | 等于点 Rise | 红字，不动 |
| End this focus / End focus | 等于点 Rise | 红字，不动 |
| Rise | 等于点 Rise | 红字，不动 |
| Stop / Cancel | 仍拒绝（与 Slice 2 相同） | 仍拒绝 |
| Start a 25-minute focus | 仍按 Slice 1–2（本刀不改开始） | 仍按 Slice 1–2 |

## 共用机制核对

本刀不新开 overlay，不接 overlayBusy，不改遮罩 dim。麦克风是专注进行中、已有 Rise 旁的控件。若实现时必须做成新的 fixed 层，停下来改本 Brief，先登记 z-index。

不涉及后台网络。

## 冲突扫描（写代码前）

对照场景 C（中途 Rise → 不庆祝 → Reflection）与场景 T（时长板点选后才开始）。结束句若走撤销条，会跳过 Reflection，与场景 C 冲突，故禁止。语气保持观察式，不追问为什么停下。职责不扩到倾诉、暂停、加时、换坐姿。

## 明确不做

暂停、加时、中途改时长、用语音选坐姿、倾诉里执行动作、日语或中文、全局快捷键、TTS、连续对话、把 `Stop` 改成结束。
