## 0. 大白话

产品怎么用，不要让阿寅在倾诉里自己念卡。先做能点的问卡入口，再让倾诉改口指向它。

**T22 第一版（旧称 T19）定形：** 菜单 Help Center **里面**顶部一个文字框，**语音录入一并做进第一版**（复用已有 Speak to type，不另开任务）。输入后列出 2–3 张可点的卡，或「没有合适的卡」。独立 Yin 倾听面是第二刀。

## 一、拍板锁（点头即锁）

1. **顺序。** Brief → T22 可点 → T23 才上跳转。目的地没好，倾诉不跳。T10 卡内称呼词捷径 **不是** 目的地。  
2. **T14 保留。** 倾诉卡内危机入口照旧。跳转句不写 Support、不写「别处」。  
3. **T22 第一版。** Help Center 面板顶部（不新开菜单行）：文字框 + 语音；提交后 **2–3** 张可点事实卡；**「没有合适的卡」** 空态。下面原有主题目录不动。卡仍 **手点**。「说 1/2/3 选卡」是后续改进，不是本版缺陷。  
4. **语音（第一版必做，复用现成）。** Speak to type：听写文字 **显示在输入框里**，用户能看见、能改，再提交检索。听错一个词检索会偏，所以禁止听完直接搜。Electron / macOS、英语听写；Web / 窄屏只键盘。禁止新语音栈。  
5. **检索怎么做（与 T10 同一思路，不用 1.7B 当家）。** 可办理操作是封闭集；问卡也一样：**关键词 / 句式规则 + 已有 embedding 近义匹配** 列出候选。**禁止**用 1.7B（或任何生成模型）自由决定「做什么 / 列哪张卡」。LLM 若将来兜底，只能在已列出的候选里选。T22 第一版 **不用** LLM 兜底。  
6. **≤8GB。** 低配隐藏的是本地 **陪伴生成** 入口，不是 Help Center，也不是事实卡 catalog。问卡检索走 catalog 关键词 + 可选 embedding，**不**依赖 1.7B。embedding 未就绪：字面关键词 + 分类浏览仍可用（与现网 `catalogKeywordSpeakAllowed` 在 embedding 非 ready 时走关键词同一路）。禁止做成「先下载模型才能问怎么备份」。  
7. **句式分流（一句话）。** 疑问句进知识库列卡；祈使句 **不在 T22 执行办理**（办理仍走 T10）；拿不准 → **不执行、改列卡**。例：Help Center 里说 *How do I back up my data?* 列备份说明卡；说 *Back up now* 不执行备份。  
8. **混合句（倾诉侧，T23）。** 不整句跳转。拿不准走陪伴。情绪句、个人事实、危机句不得被跳转。  
9. **Web / 窄屏。** Help Center 打得开才算有目的地。打不开 → T23 不跳转。  
10. **跳转句（英文，仅 T23）。**  
    *I keep how-to answers in Help Center. Open Help Center from the menu and type or speak your question.*（中文：再打字或语音问；与 T22 问卡入口一致。）  
11. **#1339 卡短答。** T17 只退役了验收。T23 合入前，倾诉里这段念卡 **仍对用户生效**。不按日期提前关掉。手测换说法的产品问时顺带看有没有错接。  
12. **黄金脚本 v1.1（T23）。** 通道期望随跳转改；必须加「情绪句、个人事实、危机句不得被跳转」。验收核心 = 2026-10-15 错句（`gs-h01`–`gs-h11`，英文先过）。不推倒 v1 句表。

**T23 只有一刀：** T22 可点之后，高置信度（CR-47 操作问法 ∧ 产品对象）才跳转。目的地没好 → 倾诉保持 **现在的** 诚实空态 / 现网短答，**不上** 跳转句。

## 三、变体矩阵（A10）

| 变体 | 入口 / 前置状态 | 预期（可见结果） | 自动化 |
|---|---|---|---|
| Electron 宽屏 | ⋯ → Help Center | 顶部问卡框（可语音）；目录仍在 | T22 补单测 |
| 窄屏抽屉 | 同一 Help Center 行 | 问卡键盘可用；无麦克风 | 场景 AX 回流 |
| Web | Help Center 打得开 | 只键盘；T23 可跳到此 | 有目的地才跳 |
| Web 无 Help Center | 打不开 | T23 不跳 | 单测锁 |
| ≤8GB Electron | 陪伴入口隐藏 | 问卡仍可用（关键词；有 embedding 则近义） | 禁止依赖 companion ready |
| embedding 未 ready | 问卡提交 | 关键词列卡或空态，禁止瞎列、禁止等 1.7B | 与 `catalogKeywordSpeakAllowed` 同路 |
| 英 / 日界面 | 问卡 | 日界面不声称日语听写 | Voice Input V1 同切 |
| 已购 / 付款 | 问卡 | 不打开 Support / Stripe | 不改付款路径 |

## 四、点击反馈（0–1 秒）（A14）

| 控件 / 入口 | 点击后 0–1 秒内用户看到什么 | 持久化三态 |

| 倾诉发送（仅 T23 后） | 跳转句或陪伴或诚实空态；高置信度才跳 | — |

## 五、边缘状态（A14）

| 边缘状态 | 预期 |
|---|---|
| 听写进框未提交 | 可改字；不自动检索、不执行办理 |
| 祈使句（如 Back up now） | 不执行；列相关说明卡或空态 |
| 0 张合适卡 | 「没有合适的卡」；不现编步骤 |
| 混合句进倾诉 | 陪伴；不得跳转 |
| 危机 / 个人事实 | 仍原通道；不得跳 Help Center |
| T22 尚未可点 | 倾诉 **不** 跳转；#1339 短答仍按现网跑 |
