# Task Brief · T26 Help Center 钮放在问号右边

> **状态（2026-10-20）**：**待 PO 点头。** 点头后新 Chat 开工 `feature/help-center-beside-question`。  
> **类**：**B**（Idle 左下会多一颗可点钮，打开帮助中心）。  
> **代号**：**T26**。**不是** T22 问卡、**不是** T14 危机资源、**不是**把「?」改成说明书。  
> **拍板入口**：2026-10-20 用户书面：Help Center 用合适按钮安在目前问号按钮右边。

## 一句话

在左下问号 `#onboarding-hint-help` 的**右边**加一颗 Help Center 钮。点它打开现有帮助中心。问号仍只出产品简介卡。

## 已经定下的做法

1. **新钮**紧挨问号右侧，同一热力簇行（`.weekly-practice-heatmap-cluster__row`）。宽屏与窄屏功能对等：窄屏问号是 `#ft-narrow-help-btn` 时，新钮仍在它右边。
2. **点新钮** → 0–1 秒内打开现有 `#help-center`（`HelpCenterUI.open()` / 现网 `openHelpCenter`）。不新做第二份帮助中心。问卡、目录、文章与 T22 现网相同。
3. **问号行为不改**：悬停/点击仍只出 `#onboarding-app-purpose`（简介 + 免责 + colophon）。简介卡里「Browse all topics」链保留。
4. **菜单行保留**：⋯ / 抽屉 Preferences → Help Center 仍在。新钮是快捷，不是搬家。
5. **外观**：暖米小圆钮，气质贴近问号，不用促销色、不挂朱砂角标。可读名称三语（en Help Center / zh 帮助中心 / ja ヘルプ）。文案走 locale 切片，不改正文三份总字典。
6. **不进 Support FAB**，不改付款。
