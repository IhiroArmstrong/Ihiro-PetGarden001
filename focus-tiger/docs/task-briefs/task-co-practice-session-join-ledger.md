## 1. 目标与非目标

### 1.1 目标

1. **场次接合键**：每一次**计时专注**从开始到结束（或中途放弃）共用同一个本机 `sessionId`。T57 下场行若发生在这场进行中，必须带上同一个 `sessionId`。没有键的旧行继续给 T58 用，**永远不算**纪念画条件 B。
2. **出示默认分钟流水**：这场开始时，记下时长条上 **Yin 出示的默认档分钟**；这场若计时坐完，再记下 **实际计入的分钟**。供以后算条件 C。C 在 T58 v1 下是**节奏稳定**的代理，不是「Yin 学会了你」——实现与验收文案都不得写成适配证明。
3. **重置 / 忘掉 / 分享 / 导出**口径一次写死（沿用 T60 教训）：新键进删除白名单；T58「忘掉」清接合账；**不进**研究分享白名单；**不进**练习云备份。
4. **只读汇总**（无界面）：纯函数能根据本机账算出「有接合键的 B 日数雏形」和「C 样本命中雏形」，方便补账后看能不能把人分开。不展示给用户。DEV `?product=1` 可从控制台调用。
5. **行为冻结**：邀请何时出现、点了怎样消失、变安静、暂停种类、时长条默认算法、T59「还是上次那个」那句字，**本刀一行都不改**。

### 1.2 非目标

- 不发画、不画 3～5 张、不出卡、不进珍藏抽屉。
- 不锁定 A/B/C 门槛数字（须真实分布；禁止用 persona 假设代替）。
- 不把觉照邀请、收工邀请算进 B。
- 不把时长条「用默认档坐完」算进 B（默认档只留给 C）。
- 不上传。不改 T54 payload。不改货架 Worker。
- 不把 C 的通过写成「Yin 学会了你 / 已适配」。v2 之前验收若出现这种描述 = 未过。

### 2.2 T57 行（沿用现键，扩字段）

键仍是 `focus-tiger.invite-outcomes.v1`。

| 字段 | 本刀 |
|---|---|
| `kind` / `outcome` / `ts` | 不变。无 `sessionId` 的旧行 **normalize 仍通过**（T58 连续拒绝/没理继续用）。 |

### 2.3 出示默认分钟流水（新键）

建议键：`focus-tiger.session-duration-offer.v1`。

建议行：

| 字段 | 说明 |
|---|---|
| `sessionId` | 与 §2.1 同一场 |
| `offeredDefaultMinutes` | 开场时时长条上出示的默认档（T58 改过的默认，或未改时的现网默认）。**不是**用户后来手滑改掉的那一档。T59 只回显「上次选的」、适应层未改默认 → 仍记下当时出示的数字（C 用）；按方向锁这 **不算 B**。 |
| `actualCompletedMinutes` | 计时坐完才填；放弃则保持空，本行不当 C 样本。 |
| `completedAt` | 坐完时间戳；未完成则无 |
| `source` | 只允许 `timed`。本刀不写 Honesty。 |

上限与 T57 同量级（约 240 行，超出丢最旧）。写盘失败：这场不记账，邀请与计时照旧，不弹错。

禁止字段：倾诉原文、邀请文案、顺/乱/倦、情绪标签、研究代号。

### 2.4 条件 B / C 怎么读（本刀只提供读口，不发放）

**B（共修回合 · 独立日雏形）** 三件都真才算一天最多一次：

1. 该 `sessionId` 有 T57 行：`kind ∈ {away, extend, long-sit}` **且** `outcome === accepted`；  
2. 同一 `sessionId` 在默认分钟流水里 `actualCompletedMinutes` 已填（计时坐完）；  
3. `dismissed` / `ignored`、觉照、收工、无 `sessionId` 的旧行，**都不算**。

**C（节奏稳定代理 · 不是适配证明）**

- 样本 = 最近已完成的 `timed` 行（N 与带宽后定；本刀测试可用固定夹具，例如带宽 ±20%、N=10、比例 0.7，**不写进产品门槛常量当发放线**）。  
- 命中 = `actualCompletedMinutes` 落在当场 `offeredDefaultMinutes` 的相对带宽内。  
- 关适应 / 该种类暂停 → 汇总函数须把 C 标成不可用（假），与方向锁一致。  
- **验收禁句**：不得把 C 通过描述为「Yin 学会了你」。只可说「实际分钟落在出示默认的带宽内（节奏稳定代理）」。

**A** 不新造账：继续读现网 `scoreEligibleLifetimeMinutes` 本机高水位。汇总函数可并列返回，便于以后看「只靠 A 的人」vs「有 B 的人」是否同一批。
