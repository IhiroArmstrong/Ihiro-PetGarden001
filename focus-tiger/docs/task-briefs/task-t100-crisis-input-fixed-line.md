**状态**：范围已按 2026-11-18 书面定下。**两个验收数字还没填。** 没填数字、也没写「按这份 Brief 开工」之前，禁止改 `src`。

## 1. 为什么写在同一页

红队里 12 条英语危机转述，输入侧一条都没接住。问号码、求附和、求代写告别，是同一个根因：进门时没认出危机，模型才自由发挥。分成三张单，容易只做最好写的「问号码」，把更伤人的「想走是合理的」留到后面。

改法相同：输入侧命中 → 现有求助句 → 不调用生成。不新写热线号码。测试分层共用。

## 2. 两刀（同一页，分开合入）

| 刀 | 先做什么 | 命中后 |
|---|---|---|
| **刀 1（先做）** | 危机语境里，求附和「想离开 / 想死是合理的」，或求代写告别、给「可以停下」的理由 | 现有 `safety_redirect` / safety-01 |
| **刀 2** | 危机语境里，问该打什么号码 | 同一句 |

刀 1 把共用的分类落点和回归测试立住。刀 2 只加「危机语境 + 问号码」，不另起一套句子。

## 3. 目标与非目标

**目标**：英文界面、本来会走到本地自由生成的那条发送，在生成之前认出上面三类请求，改走今天已有的安全固定句。

**非目标**：

- 不改输出闸规则，不把这张单算进 K=3。
- 不改 `RISK_REGISTER.md` 里 V-02 的正文。
- 不新写求助句，不写 988、911、110 或任何具体号码。
- 不在这张单里扩中文、日文。其它语言沿用各自现有路径。
- 不改 Help Center 问卡，不改 Web / 窄屏（今天就不自由生成）。
- 不改公案支持路径（#1738：那里不得出现危机热线句）。
- 不把第 3 轮那 12 条，或它们的近义句，写进正则、关键词、别名或新意图桶。只允许改安全分类的机制（召回、精度、层序）。见 `PRINCIPLES.md` 的 R-Confide-No-Symptom-List。

## 4. 只认「危机语境 + 具体请求」

单独出现「该打什么号码」不得触发。问牙医电话、客服电话必须放行。

「结束订阅」「结束一段关系」不得触发。

公案、禅定里谈死亡或「结束」而不是在求附和、求代写、求号码的，不得走这张单。

没命中的句子保持今天的路由。已有的「我不想活」仍走现有安全层，不得被这张单改坏。

## 5. 句子与锁

命中后展示的英文就是现有 safety-01：Heard. If this feels too heavy to hold alone, please call your local crisis helpline. … Yin is here — not a substitute for professional help.

同时走今天安全层已经有的生成锁（T91：直到退出应用前不再自由生成）。不新做第二把锁。
