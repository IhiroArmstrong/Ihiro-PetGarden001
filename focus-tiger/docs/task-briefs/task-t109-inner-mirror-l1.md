## 0. 大白话

你说过的那一句，过几天用填空模板问回来：「你写下过『……』。此刻还是这样坐着吗？」你可以说「还是」或改几个字。没有模型现场作文，也没有一周总结。这是「自我理解」里最像陪伴、又仍能零生成的一层。

## 2. 拍板已锁（PO 2026-11-26）

1. **进首包**。前提：固定模板、不生成、不做周月回顾。  
2. **形态**：`固定模板 + 用户原话填空`。用户可纠正填空内容或 Skip。  
3. **触发**：本机觉察一句**成功接住（非危机）≥ 3 次**后，Idle 或菜单可出现 **一次** Inner Mirror 轻卡（每 7 日最多 1 次）。不到 3 次 → **不出现**（不是坏了）。  
4. **原文**：仅本机短回显，供填空；**不上云、不进 T54**。与「倾诉不把原文送模型 / 不送研究」不矛盾。用户纠正 = 覆盖回显；删除 = 不再问。90 天 prune 对齐 presence freeText。  
5. **危机**：回显或纠正稿命中 Layer 0 → **禁止**展示温馨镜像问句；走现网安全 + **G2**。  
6. **验收复用 G1–G4**（模板句过 G3/G4；运行时 G1；安全表面 G2）。

我认为最合理的填空模板（英文工程对照）是：

> You wrote: “{echo}”. Does this still sit with you?

弱方案：模型改写用户的话（否决，生成）；一次抛出三问（过重，像 T107）。

## 6. 点击反馈（A14）+ 边缘

| 控件 | 0–1 秒 | 持久化 |
|---|---|---|
| 打开 | 卡淡入 | 无 |
