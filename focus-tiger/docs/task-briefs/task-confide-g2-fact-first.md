2. **帮助中心短摘**  
   短答落空（含错卡被拒）后，只检索用户向短摘，不整篇念、不现编步骤。这是 2026-10-13 第三刀，现网未接。收藏从哪来走这一层。

   查本机记录 / 一次该坐多久 / 陪伴。查记录用语义对工具，不往名单加句。无数据也不得编数字。查记录不得走生成。

   只允许陪伴语气。自动检查能否做，实现前另评；做不到则人工关单抽查。不是名单，也不新开路由层。
