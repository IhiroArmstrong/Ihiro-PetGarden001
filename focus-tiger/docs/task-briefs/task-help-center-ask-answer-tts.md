## 0. 大白话

帮助中心里已经可以用语音打字、并用语义检索找出最接近的说明。按我们一贯的标准：宽屏电脑版在答案出现后，也要把**最接近的那一篇**念出来，好让听的人也能学会怎么用产品。念的就是那一篇的标题加正文。关卡、再搜一次、或开始听写，都会停掉正在念的声音。网页和窄屏本来没有这套朗读，只显示字。

---

## 一、拍板锁

1. **有语音录入 + 语义检索的地方，就要念最接近的答案。** Help Center 问卡提交后，念排序第一篇的标题+正文。空结果念屏上「没有合适的主题」句。危机问卡念屏上 T92 求助句（与倾诉 T34「屏上有字就念」一致）。  
2. **念屏上的说明，不加第二套话术。**  
3. **不新增开关。** 不把这条挂到 Voice announcements（那条只管练习结束等公告）。停的办法：关帮助中心、再提交一问、点 Speak to type 开始录音（现有听写会先 `stopSystemTts`）。  
4. **办理指令仍走现网朗读。** `Back up now` 等封闭集仍由 Yin 指令复述出声；本刀**不**再念「没有合适的主题」。  
5. **目录浏览不自动念。** 从主题列表点开一篇（没有先问卡检索）不自动朗读。从问卡结果卡点开时再念该篇（用户换了一篇答案）。  
6. **Web / 窄屏 / 无桥：** 只见字、不念（现网 `canUseSystemTts`）。  
7. **不改检索排序、不改办理、不改付款、不加 `main.js` 行。**

**一句话：** 宽屏电脑版，帮助中心问完后念最接近那篇说明；停的办法还在。

## 变体矩阵（A10）

| 变体 | 入口 / 前置状态 | 预期（可见结果） | 自动化 |
|---|---|---|---|
| Electron 宽屏 · 命中 | 问卡产品问 | 0–1s 见主题卡，并开始念第一篇标题+正文 | `buildHelpCenterClosestAnswerSpeakText` 只拼第一篇 |
| Electron 宽屏 · 空 | 无关句 | 见空态句并念同一句 | empty 分支 |
| Electron 宽屏 · T92 | 危机句进问卡 | 见求助句并念同一句；不办理 | safety 优先于文章 |
| Electron 宽屏 · 点结果卡 | 多卡时点第二篇 | 念该篇标题+正文（最新一句赢） | `_openArticle(..., { speak: true })` |
| Electron 宽屏 · 目录点开 | 未检索 | 见正文、**不**因本刀出声 | 主题钮不传 `speak: true` |
| Electron 宽屏 · 办理 | `Back up now` | 仍见确认句；**不**念空态 | execute 路径不调用问卡朗读 |
| Voice announcements 关 | 问卡仍念 | 保持与倾诉切开 | 不读该偏好 |
| Web / 窄屏 | 无桥 | 只见卡、不念 | `canUseSystemTts` |
| 关卡 | 正在念 | 立刻停 | `close()` → `stopSystemTts` |

## 共用机制核对

Help Center 已有 overlay / 逃生层 / 宽屏靠边。本刀只在提交后和关卡时调用现有 `speakSystemTts` / `stopSystemTts`。**不**改 overlayBusy、HUD 呼吸、遮罩 dim、z-index。
