# Task Brief · 阿寅壁纸 / 数字周边（Digital Wallpapers · 免费赠送）

> **状态（2026-08-07）**：产品需要此功能；**v1 做法已锁为「候选静帧免费保存」**。本回合只文档；实现另开 feature。  
> **目的**：低成本品牌二次曝光（锁屏 / 桌面）；无门槛赠送。

## 权威边界

| 项 | 口径 |
|---|---|
| 交付 | 从**已有动画序列**精选高颜值静帧（坐禅 / 变花 / 看书等），提供 **若干张** 手机 + 桌面比例导出 |
| 用户动作 | 合适入口 → 预览候选 → **Save / Download** 到本机（对齐 Quiet Line「存图」气质） |
| 门槛 | **免费**；不绑 Pass / 请茶；不绑连续打卡 |
| 分享 | **不做**「一键发到 IG/X」核心承诺（与增长包一致） |
| 素材 | 须合法使用项目已有帧；导出文件名 **kebab-case ASCII**；可放 `public/wallpapers/` 或构建时从序列抽帧 |
| i18n | 菜单/卡 en + ja |

## 入口（建议）

Idle 宽屏 ⋯ / 窄屏抽屉 **平级**一项（与 Zen Cinema / Quiet Line 同级），礼物语气（如 **Wallpapers** / **Yin’s stills**）。  
**禁止** Reflection 边缘硬塞；**禁止**抢 Sit 主 CTA。

## 与 Quiet Line 的差异

| | Quiet Line | Wallpapers |
|---|---|---|
| 内容 | 当日金句 + 轻排版卡 | 阿寅高颜值静帧（可无字或极短 brand footer） |
| 触发 | 菜单主动 | 菜单主动 |
| 目的 | 文字社交货币 | 锁屏/桌面曝光 |

可复用 canvas / 下载模式；**不要**做成第二套支付或成就墙。

## 实现要点（将来）

1. 策展 3–6 张候选（注明源序列 id + 帧）；手机 9:16 + 桌面 16:9（或一张多裁切）。  
2. 确认卡：缩略图网格 → Save image。  
3. 自动化：清单长度 / 入口 visibility；人工：下载文件可打开、375 不挡主球。  

建议分支：`feature/digital-wallpapers-gift`。
