## 0. 大白话

有的句子一半在说心情、一半在问产品。今天要么只走产品短答 / 诚实空态，要么只走情绪语料，听起来像没听见另一半。

要改成（点头后才接线）：**先用现成语料接住情绪一句，再接现成短答或诚实空态。** 不新写句子，不加关键词正则，不调 0.01。

本刀 **不是** 把函数 A 切 live。函数 A 仍只负责「产品是否明显高于情绪」。合并回应是第三种**回复形状**。

---

## 1. 非目标（本规格锁死）

- 不改 `PRODUCT_MINUS_MOOD_MARGIN`（已冻 **0.01**）。
- 不改现网发送链（本 PR / 本会话）。
- 不新增产品词 / 情绪词正则；混合判定只用已有分句打分。
- 不用 L3 generate 写承接句或短答。
- 不把作废 holdout 原句写进生产示例库。
- 安全 / 危机 / 他人攻击 / 边界 / 练多久：本形状 **不可达**。
- 纯产品锚（场景 AE catalog 真命中）不得变成观察翼或空态。

---

## 2. 何时触发（混合句判定）

复用路由仲裁已有件，**禁止**新开关键词表：

1. 安全层已排除（与仲裁 Brief 层序一致：本形状够不到安全）。
2. 用已有 `splitUtteranceByPunctuation` 按标点分句（不是产品/情绪词表）。
3. 各句仍用现成产品闸 embedding：每句一个 `productScore`、一个 `moodScore`。
4. **混合**（同时成立才触发合并回应）：
   - **至少一句**按函数 A：`product − mood > 0.01`（产品半边成立）；**并且**
   - **至少另一句**产品并未明显高于情绪（`product − mood ≤ 0.01`，情绪半边成立）。
5. 整句只有一边 → **不**触发：纯产品走短答或诚实空态；纯情绪走现有情绪 / 观察翼。
6. 单句、无标点可分：不因「同一句里碰巧两个词」触发。不发明第二套切词。
7. 徽章≠寅币、纯闲聊、纯生活情绪：不走本形状。

函数 A 门槛数字 **不在本 Brief 重开**。本形状只问「两边分句是否同时在」，不问「再把 0.01 调高一点」。

### 2.8 情绪半边硬闸（2026-10-15 补条）

情绪半边那一分句必须 **同时**：

1. `moodScore` ≥ 路由开发集 v2 上、非函数 A 产品路径分句的 **5% 分位**（本次实验室 **0.50**，n=38；`npm run audit:routing-intent-feasibility`）；
2. `confideClassify` 落到 `anxious` / `tired` / `stuck` / `sad` / `scattered` 之一。

否则 **不合并**，退回单路径。不调 0.01。细则 [`task-confide-mixed-reply-mood-floor.md`](./task-confide-mixed-reply-mood-floor.md)。

## 3. 回应结构

用户听到 **恰好两段**，顺序固定：

| 段 | 内容 | 来源 |
|---|---|---|
| 1 | **一句**情绪承接 | 现有 `CONFIDE_CORPUS` 里、与该情绪半边路由对应、且 `review=ok` 的一条（见 §4） |
| 2 | 现有产品短答 **或** 现有诚实空态 | catalog / 近邻命中 → 已审短答正文一字不改；未命中 / 未就绪 → `formatConfideProductKnowledgeHonestyReply` 现句一字不改 |

禁止：第三段解释、续写步骤、把两段揉成一句新生成、用茶句 / 风景句填第一段。

`data-source`（实现时再锁，本规格倾向）：可见回复标明合并；产品段仍能对上 `product_knowledge` 或 `product_knowledge_honesty`。不得把整段标成 `generate`。

---

## 4. 承接句来源（现有语料，不用生成）

从 `confideCorpus.js` **按情绪半边已有路由**抽一条 `review=ok` 的现句，locale 跟面板走。

**允许池（按路由，不新写）**：`tired-*` / `sad-*` / `anxious-*` / `stuck-*` / `scattered-*` 等已有情绪桶、且本轮 `review=ok`。

**禁止池**（即使用上了「听见」字样）：

- `safety-01`（危机转介；场景 AE 禁拿来当普通听见）
- `aggression-*`（他人攻击；AE 禁 `Heard` / 点头）
- `fallback-01`（点头套话；与攻击对照冲突）
- `fallback-03` 及茶句马甲
- `CONFIDE_GENERATE_FAILURE_CORPUS_EXCLUDE_IDS`

抽法：情绪半边已能落到哪条情绪路由，就只在该路由池里抽；抽不到 → **不**合并，退回今天的单路径（产品或情绪），禁止 generate 补一句。

## 5. 冲突扫描

对照 [`FEATURE_CONFLICT_REVIEW.md`](../FEATURE_CONFLICT_REVIEW.md) 三轴 + [`SCENARIO_TESTS.md`](../SCENARIO_TESTS.md) 场景 AE。**有冲突疑点；实现前须 PO 书面拍板。** 本 PR 只记扫描，不接线。

### 5.1 「短答保持短」（知识库）

权威：[`product-knowledge-base.md`](../product-knowledge-base.md) — 陪伴可检索只出**已审核短答或指路**，不念长脚本；阿寅只许复述短答段。

| 轴 | 判断 |
|---|---|
| 强度 | 用户仍是发一句等一句。回复从一段变成两段，阅读变长。 |
| 语气 | 第一段观照、第二段指路，与「观照者不是客服脚本」可并存，前提是第一段真的短、且不说教。 |
| 职责 | 短答正文不得被改写或续写。合并只是**前面加一句语料**，短答段保持原句。 |

**疑点**：两段合计可能长过「一条短答」。缓解（须拍板）：第一段必须是语料里**已经是一句**的条目；第二段零改写；纯产品（§2.5）不合并，避免 AE 锚被拉长。

### 5.2 场景 AE

| AE 契约 | 与本形状 |
|---|---|
| catalog 真命中（接地练习在哪、A Quiet Line 在哪）→ `product_knowledge` | **纯产品、通常单句** → §2 不触发。禁止把这两锚改成观察翼或空态。若误判为混合 → **冲突**，须在实现单测锁「两锚不得合并」。 |
| 产品问未命中 → `product_knowledge_honesty` | 混合且产品半边未命中：第二段仍是该诚实空态，不放宽成 generate。 |
| 安全 / 攻击 / 边界 / 练多久 | 不可达。禁止用 `Heard.` 危机句或攻击池当第一段。 |
| 情绪桶 corpus only（「太累了」） | 无产品半边 → 不合并，仍单段情绪语料。 |
| 0–1 秒内见回复 | 多一次分句 embedding 时，热态增量仍受仲裁已锁 `product_path_ttft_hot_delta_ms = 100` 约束；超了就不得靠合并形状放行。 |

**结论**：与「短答保持短」、AE 真命中短答 **有冲突疑点**（长度 + 误触发）。**我认为最合理的**：规格先锁「纯产品不合并、短答零改写、两锚单测锁死」；实现仍等 PO 点头。不得把扫描写成无冲突。

## 7. 风险

1. **误触发**：分句后「情绪旁白 + 真产品」被合并，用户只问了按钮，却先听一句心情——伤「短答保持短」与 AE。缓解：§2 要两边分句；两锚锁死。
2. **漏触发**：情绪与产品写在同一逗号结构里、分句切不开 → 仍单路径。不靠新正则补。
3. **Heard / 茶句污染**：错抽 `safety-01` / `fallback-01` / 茶句 → 与 AE 攻击对照、观察翼套话禁令打架。缓解：§4 禁止池。
4. **诚实空态仍像没听见产品**：合并只让前半句像听见心情；产品未命中时第二段仍是 Help Center 空态，不能假装有手册。
5. **标签与形状缠在一起**：把合并算进 `mixed` 通过，可能掩盖函数 A 仍判错路径。报表须分列「路径对」与「靠合并过」。
6. **过拟合**：本会话已见作废 b-v2 / b-v5，不得用那些句子当实现例句或最终过关集。
7. **延迟**：分句 embedding 已测过热态增量；合并本身几乎不增模型，但不得在冷启动干等。
