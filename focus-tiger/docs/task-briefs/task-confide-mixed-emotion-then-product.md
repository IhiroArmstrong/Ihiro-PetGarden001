## 0. 大白话

有的句子一半在说心情、一半在问产品。今天要么只走产品短答 / 诚实空态，要么只走情绪语料，听起来像没听见另一半。

要改成：**先用现成语料接住情绪一句，再接现成短答或诚实空态。** 不新写句子，不加关键词正则，不调 0.01。

**影子**（A 类）可先于 CR-11：只算「若合并会怎么回」，用户听不到。用来给带 A 贴边句一个合法出口，打破「CR-11 等带 A、带 A 等 CR-45 live」的循环。

**live** 仍必须跟在 CR-11 切 live 一起或紧跟其后。禁止从后门把未过关的分句判定送进现网。函数 A 仍只负责「产品是否明显高于情绪」；合并是第三种回复形状。

## 2. 何时触发（混合句判定）

复用路由仲裁已有件，**禁止**新开关键词表：

1. 安全层已排除（与仲裁 Brief 层序一致：本形状够不到安全）。
2. 用已有 `splitUtteranceByPunctuation` 按标点分句（不是产品/情绪词表）。
3. 各句仍用现成产品闸 embedding：每句一个 `productScore`、一个 `moodScore`。
4. **混合**（同时成立才触发合并回应）：
   - **至少一句**按函数 A：`product − mood > 0.01`（产品半边成立）；**并且**
   - **至少另一句**产品并未明显高于情绪（`product − mood ≤ 0.01`，情绪半边成立）。
5. 整句只有一边 → **不**触发：纯产品走短答或诚实空态；纯情绪走现有情绪 / 观察翼。
6. 单句、无标点可分：不因「同一句里碰巧两个词」触发。不发明第二套切词（含不为英文 `and` / 破折号另开切词表）。切不开 → 漏触发、走单路径（§7.2）。
7. 徽章≠寅币、纯闲聊、纯生活情绪：不走本形状。

函数 A 门槛数字 **不在本 Brief 重开**。本形状只问「两边分句是否同时在」，不问「再把 0.01 调高一点」。

### 2.8 情绪半边硬闸（2026-10-15 补条 · 2026-10-17 标明暂定）

情绪半边那一分句必须 **同时**：

1. `moodScore` ≥ 路由开发集 v2 上、非函数 A 产品路径分句的 **5% 分位**（本次实验室 **0.50**，n=38；`npm run audit:routing-intent-feasibility`）。**这是暂定值**：5% 分位在 n=38 上大约只对应 2 条，不稳定。新未见封存集跑出后再复核，未复核不得把 0.50 写成永久门槛。
2. `confideClassify` 落到 `anxious` / `tired` / `stuck` / `sad` / `scattered` 之一。

否则 **不合并**，退回单路径。不调 0.01。细则 [`task-confide-mixed-reply-mood-floor.md`](./task-confide-mixed-reply-mood-floor.md)。

## 3. 回应结构

用户听到 **恰好两段**，顺序固定：

| 段 | 内容 | 来源 |
|---|---|---|
| 1 | **一句**情绪承接 | 现有 `CONFIDE_CORPUS` 里、与该情绪半边路由对应、且 `review=ok`、且过 §4.1 长度上限的一条 |
| 2 | 现有产品短答 **或** 现有诚实空态 | catalog / 近邻命中 → 已审短答正文一字不改；未命中 / 未就绪 → `formatConfideProductKnowledgeHonestyReply` 现句一字不改 |

禁止：第三段解释、续写步骤、把两段揉成一句新生成、用禁止池条目填第一段。两段之间不加过渡句。

`data-source`（实现时再锁，本规格倾向）：可见回复标明合并；产品段仍能对上 `product_knowledge` 或 `product_knowledge_honesty`。不得把整段标成 `generate`。

## 4. 承接句来源（现有语料，不用生成）

从 `confideCorpus.js` **按情绪半边已有路由**抽一条 `review=ok` 的现句，locale 跟面板走。

**允许池（按路由，不新写）**：`tired-*` / `sad-*` / `anxious-*` / `stuck-*` / `scattered-*` 等已有情绪桶、且本轮 `review=ok`。

**禁止池**（即使用上了「听见」字样）：

- `safety-01`（危机转介；场景 AE 禁拿来当普通听见）
- `aggression-*`（他人攻击；AE 禁 `Heard` / 点头）
- `fallback-01`（点头套话；与攻击对照冲突）
- `fallback-03` 及**独立茶句马甲**（禁止另抽茶句顶第一段）
- `CONFIDE_GENERATE_FAILURE_CORPUS_EXCLUDE_IDS`

允许池内已审句可以自带茶意象（现网 `anxious-01` / `tired-02` / `tired-03`）；那不是马甲，不得再剥一层。

抽法：情绪半边已能落到哪条情绪路由，就只在该路由池里抽；抽不到或全部超 §4.1 上限 → **不**合并，退回今天的单路径（产品或情绪），禁止 generate 补一句。

### 4.1 承接句长度抽查与上限（2026-10-17）

2026-10-17 对允许池 15 条 `review=ok` 情绪句（anxious/tired/stuck/sad/scattered × 各 3）点算英文可见字符：最短 24、最长 47（`sad-01` / `anxious-01`）。都是一两截短句，没有长段。

实现抽句时须过上限；超了跳过该条，池空则不合并：

| locale | 上限 |
|---|---|
| `en` | ≤ **72** 可见字符 |
| `zh` | ≤ **40** 字 |
| `ja` | ≤ **40** 字 |

并且该条在对应 locale 上，终止标点（`.!?。！？`）分段 **≤ 2**。上限是挡住以后误把长句写进允许池，不是把现网 15 条再砍短。

| 轴 | 判断 |
|---|---|
| 强度 | 用户仍是发一句等一句。回复从一段变成两段，阅读变长。 |
| 语气 | 第一段观照、第二段指路，中间无过渡，可能读起来先安慰再甩指路。缓解：§4.1 上限 + §8 人工通读 10–20 组实拼两段。 |

## 7. 风险

1. **误触发**：分句后「情绪旁白 + 真产品」被合并，用户只问了按钮，却先听一句心情——伤「短答保持短」与 AE。缓解：§2 要两边分句；两锚锁死。
2. **漏触发**：情绪与产品写在同一逗号结构里、分句切不开 → 仍单路径。不靠新正则补。中英日标点习惯不同，可能某语言几乎从不触发。缓解：§8 分语言统计触发率。
3. **Heard / 茶句污染**：错抽 `safety-01` / `fallback-01` / 独立茶句马甲 → 与 AE 攻击对照、观察翼套话禁令打架。缓解：§4 禁止池。
4. **诚实空态仍像没听见产品**：合并只让前半句像听见心情；产品未命中时第二段仍是 Help Center 空态，不能假装有手册。
5. **标签与形状缠在一起**：把合并算进 `mixed` 通过，可能掩盖函数 A 仍判错路径。报表须分列「路径对」与「靠合并过」。
6. **过拟合**：已见作废 b-v2 / b-v5，不得用那些句子当实现例句或最终过关集。
7. **延迟**：分句 embedding 已测过热态增量；合并本身几乎不增模型，但不得在冷启动干等。
8. **后门切 live**：CR-11 之前把合并接到发送链 = 用未过关的函数 A 分句决定用户听到什么。缓解：**影子可先**；**live 仍等 CR-11**；回滚须能关掉合并形状。

## 8. 验收

**影子会话**（可在 CR-11 前）：冻结集不退步；不改发送链；stdout / JSON 无原句；带 A 三类能按 §6 或门计分（分列）。

**live 会话**（仅在 CR-11 之后）：

- 冻结集不退步（R-0）。
- 新的未见路由封存：带 A 三类按 §6 或门（≥85%、n≥60；分列路径对 / 靠合并过）。
- AE 两锚各 1 句仍为单段短答（关单锁，不报通过率）。
- 不调 0.01。
- **回滚**：合并形状须能单独关掉；关掉后发送链与接线前逐字节行为一致（实现 PR 须带关开对照单测）。不得把函数 A live 绑死在合并开关上拆不开。
- **分语言触发率**：en / zh / ja 各报「可分句样本里实际触发合并」的比例。某一语言接近 0 须书面说明（漏触发可接受，不得靠新切词表硬拉平）。
- **人工通读**：从实现后的实拼结果抽 **10–20 组**两段（优先英文，中日各至少 2 组）。看的是读起来是否生硬，不是只看自动化绿。指标全绿但通读别扭 → 不得关单。
