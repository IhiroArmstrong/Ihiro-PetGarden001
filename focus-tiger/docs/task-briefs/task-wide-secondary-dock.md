# Task Brief · T42 宽屏次级面板不盖脸

> **状态（2026-10-23）**：PO 书面「按 T42 出 Brief」，并明示 **无需审核、连贯立刻开工**。  
> **类**：**B**（宽屏帮助中心等 Idle 玻璃卡会从正中挪开，阿寅脸露出来）。  
> **代号**：**T42**（电脑版十二条对照 #12 · 执行序 5）。  
> **分支**：`feature/t42-wide-secondary-dock` · 基线 `origin/develop`（含 T41 #1392）。

## 一句话

宽屏打开帮助中心（以及同一套规则下的成长旅程详情卡）时，卡片靠右或贴底，中间留给阿寅；窄手机仍可居中。断点与 **T41 倾诉贴边**相同。

## 已经定下的做法

1. **同一布局规则（叠 T41）**  
   - `≤479`：仍可居中。  
   - `480–899`：贴底一条，高度不超过约视口 42%。  
   - `≥900`：靠右栏，中线左侧留给阿寅。  
   - 断点函数复用 T41 `confideDockPlacement`（本刀抽出共用 CSS，倾诉卡也改走同一段，避免两套几何）。

2. **本刀负责的卡**  
   - `#help-center`（菜单 / 问号右边快捷 / 问号卡链，同一张）。  
   - `#growth-journey-detail`（首页旅程短行打开的详情卡；现网已贴底居中，宽屏改走同一贴边）。  

3. **遮罩与层级**  
   - 帮助中心遮罩仍 `#help-center-backdrop` z=17，卡 z=18。  
   - 只改卡的几何，不改 z、不改 dim 配方、不改问卡检索 / T34 口头办理。

4. **明确不做**  
   - Support / 会员 / Sanctuary / 请茶 / 艺术结账：**仍居中**（受保护付款路径）。  
   - 倾诉卡几何已由 T41 负责；本刀只把 CSS 收到共用函数，行为应不变。  
   - Arrival / Reflect / Honesty：现网已贴底，本刀不改练习流程。  
   - 问号简介卡仍贴问号，不改成右栏。  
   - 不做成系统 Sheet。

## 共用机制核对

- **overlayBusy**：不新增叠层源。帮助中心 / 旅程详情仍走现网 occupancy。核对后确认问候 / 切语不被本刀挡住。  
- **HUD 呼吸驱动**：不碰计时。核对后确认 Focusing HUD 呼吸仍由现网驱动者表负责。  
- **z-index / dim**：核对 `Z_INDEX.md` Idle 常驻 chrome。帮助中心遮罩仍 z=17，Support FAB / Ambient 音符 / 倾听耳（z=24）继续走 `overlayBackdrop` idle-chrome dim。`#help-center` 仍 z=18，**不** inline 压 Support 26。  
- **新建可点击叠层**：无。不进新的 `OVERLAY_UI_SURFACE` 行。
