## D. 时间线机制（只列用户能感到的）

| 时间点 | 有无真实机制 | 用户会感到什么 |
|---|---|---|
| 第 1 次打开 | 有 | 吹花、四选、默认无音乐、无说明书弹窗 |
| 隔 ≥3 日再来 | 有 | 可再吹花欢迎（同日刷新不吹第二次） |
| 连续约 7 个练习日 | 有 | 金辉仪式；旅程「看见」约需计入 35 分钟（轻练约一周） |
| 第 10 天 | **无专属机制** | 【推测】若几乎每天短坐，莲花可能已开、热力图较满 |
| 连续约 21 日 / 练习分数约 21 | 有 | 星石或芥子须弥诗印开始出现（分数=来过的天数 + 计入小时） |
| 约 30 日窗口 | 有（内部日志 day30，**无界面**） | 用户侧：徽章、莲花、旅程往「练习/安稳」走 |
| 计入约 360 / 720 / 2160 分钟 | 有 | 旅程阶段名向前，不倒退 |
| 终身约 25 分钟 | 有 | 第一朵莲花 |
| 终身约 600 / 3000 / 10800 分钟 | 有 | 勋章印记 |
| 连续约 100 日 | 有 | 星石仪式节点 |
| 练习日记录最多约 90 条 | 有（界面不拿来倒退阶段） | 近况节奏条可看见暂停与「您又回来了」 |
