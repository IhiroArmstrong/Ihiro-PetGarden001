## 替换主文档 §5 中「目前您还看不到：对阿寅说话」整段为：

### 想对阿寅说话（倾诉）：看您用的界面语言

**界面是英语时**（首发要对外的版本）：您可以点**菜单里的倾诉**，或点宽屏左上 / 窄屏下方条上的**耳朵**。打开后，您用英语写或说，阿寅像茶友一样听——不替您做设置，也不假装能治病。遇到很重的危机用语，它会请您找真实世界的求助电话，而不是硬聊下去。

**界面切成日语时**（首发同样会提供日语界面，但**不**包含日语倾诉）：菜单和耳朵会**不出现**；这是首发刻意砍掉的一块，不是您漏看了。若将来从别的入口误触，系统会用固定句子说明「倾诉对话目前只开放英语」，并仍提醒您有求助途径。日语界面里的按钮、帮助页可以照常是日语。

换语言：菜单 → **语言**（地球图标也可）。倾诉是否出现，跟**当前界面语言**走，不跟您是哪里人走。
