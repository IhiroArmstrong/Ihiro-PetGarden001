## 0. 大白话

用户要的是：心里乱时，有个地方写下这一句，被温和接住，不被评判。不是「和小老虎深度开导」。

## 1. 这是收回，不是新功能

2026-08-10 默认已经是：检索人工语料，禁止模型现场对用户说话。  
2026-08-18 给电脑宽屏开过一个窄口：语料没接住时，允许受约束短生成。

**本锁收回那条窄口。** 同一入口继续用。生成代码保留在仓库，默认不再走到用户看得见的回复。以后若要再开生成，须新的书面点头，不得把本锁读成「可以随时打开」。

层序仍锁死：

```text
0 安全（字面 → 现网语义危机层 → 修辞确认；固定转介句；模型不调用）
  → 高危命中：锁到退出应用前，不再继续这一场
  → 0b 伤害他人：专用接怒气句（不是热线、不是觉察一句 A/B）
  → 1 产品仪式 / Help Center（产品问仍去帮助中心，不进情绪句）
  → 2 人工固定句（内部标签只给路由用，界面不写「你好像在……」）
  → 2b 边界尊重（「还不确定要不要说」不得压成情绪句）
  → 3 桌面自由生成：本锁关闭
```

伤害他人可见句的恢复规格见 [`task-restore-aggression-dedicated-pool.md`](./task-briefs/task-restore-aggression-dedicated-pool.md)（B 类；点头前不改 `src/`）。

相似度不够、灰区：并进**接住**（最短一句即可）。**禁止**再设「说不清」独立类。接住句与邀坐句可同库并存，**禁止**用向量决定该回哪一种。禁止硬凑标签。

## 2. 第一份安装包：入口要开

纠正 2026-11-12 书面风险接受里「倾诉对客关闭」那一句。

| 项 | 本锁 |

| 日语界面 | 入口继续隐藏 |
| 名字 | 包装日前若未点头英文名，可暂用现名 Chat with Yin；**行为须已按本锁**（不自由生成、有免责、高危固定求助） |
| 新名字 + 一次一句界面 | 固定句经你们定稿后才切；切名不等于另开入口 |
| 识别率 | 不得写成已达标。免责 + 当地资源仍是过关线（T97） |
| V2 否决项 | 仍未当临床通过。打开入口 ≠ V2 已过 |

打开入口的最低行为（包装日前必须齐，不等分离试验）：

1. 免责：这是自我觉察记录，不是心理支持、不是咨询。  
2. 高危自伤：现有安全层；命中后只给标准化求助，锁到退出应用。  
2b. 明确想伤害别人：专用接怒气句（场景 AE 3b）。**不是**热线，**不是**第 3 条的 A/B。  
3. 其余非高危：人工固定句。对外句库只许 **接住** 与 **邀你坐一会儿**（不自动开练习）。挑选靠日期/盐，**不是**向量分类；二者不当成模型能分开的两类。  
4. 不调用云端大模型；桌面现场生成不进入用户气泡。  
5. 不存原文（只许哈希 / 计数；不进备份）。界面不提供「翻旧留言」。

窄窗发送钮被挡（R2L-02）**#1791 已合**。帮助中心 / KB catalog 对客改口 **#1790 已合**。
