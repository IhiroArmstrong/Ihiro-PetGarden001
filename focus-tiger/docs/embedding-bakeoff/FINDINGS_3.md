## 任务 C · 池化

这份 GGUF 的 `qwen3.pooling_type` 元数据值是 `3`。在所带的 llama.cpp 头文件里，`3` 是 `LLAMA_POOLING_TYPE_LAST`（`llama/llama.cpp/include/llama.h:176-180`）。

`getEmbedding(tokenCount)` 在池化类型不是 NONE 时，取的是序列向量，传入的下标不用（`llama/addon/AddonContext.cpp:735-738`）。LAST 的选位是位置最大的那个 token，也就是最后一个（`llama/llama.cpp/src/llama-graph.cpp:296-318`），再取出那一行隐藏态（同文件 `3579-3583`）。

这和官方 `last_token_pool`（取最后一个 token 的隐藏态）一致。未另从已经建好的 context 再读一次运行时枚举；若运行时把元数据改成别的池化，则这一条要重核。本回合没有看到这种改写。
