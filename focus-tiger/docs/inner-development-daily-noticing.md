## 0. 大白话

我们要帮**没有心理疾病诊断的普通人**，也能慢慢变得更清醒、更稳、更有韧性——不是先问「你有没有问题、怎么治」。

产品里已经有不少「看见自己」的零件，但都**绑在坐下练完**这条线上；还缺一个名字清楚、**不坐下也能做**的每日觉察入口。

将来第一刀用**审过的固定问句按规则轮换**，不让模型现场写问句、也不给用户下结论。严重痛苦仍走现网**倾诉安全层**（固定求助与锁定），不能把「不做治疗」理解成「忽视风险」。

## 1. 产品出发点（Human Inner Development）

### 1.1 与传统心理健康产品的区别

| | 常见心理健康产品 | Focus Tiger / Samatia（本锁） |
|---|---|---|
| 默认问题 | 用户现在有没有问题？如何缓解？ | 即使没有心理疾病，怎样更清醒、更稳定、更能自主地生活？ |
| 成功形象 | 症状减轻、量表改善 | 觉察力、情绪韧性、内在稳定、自我理解、生活智慧（缓慢积累） |
| 系统角色 | 评估、干预、有时近似治疗 | 正念伙伴、练习条件、观察式陪伴；**不诊断、不处方、不替代持证专业人士** |

四条成长面向（产品叙事用，**不是**四个独立 App 模块）：

| 面向 | English | 产品里怎么养（现网 + 缺口） |
|---|---|---|
| 自我觉察 | Self-Awareness | Notice、回顾三问、**缺口 = Daily Noticing** |
| 心智力量 | Mind Strength | 同坐、分心回来、接地；不另开「抗压仪表盘」 |
| 情绪韧性 | Emotional Resilience | 观照站位、接地/环顾、T51 可接暂停、Journey/诚实「回来就能再坐」；**Recover** 仅指专注内回神（见 §8）；倾诉 = 被听见，**不是**治疗 |
| 内在智慧 | Inner Wisdom | T79 带着问题坐、Daily Wisdom、Quiet Line、静思典藏 |

权威练习弧线仍见 [`CORE_LOOP.md`](./CORE_LOOP.md)（觉察 → 专注 → 心流 → 内在成长）与 [`PRODUCT_POSITIONING.md`](./PRODUCT_POSITIONING.md) 核心使命。

### 1.2 边界（与「不做诊断」并列 · 必读）

下列条款 **与**「不下结论、不贴病理标签」**同等优先级**，任何人加功能前须对照本节：

1. **不是治疗**：本产品及 Daily Noticing 方向**不得**写成治疗焦虑、抑郁或其它临床病症；不得承诺疗效。免责与 wellness 落点见 [`PRODUCT_POSITIONING.md`](./PRODUCT_POSITIONING.md) §四 · `PRINCIPLES.md`「一般身心练习，不是诊疗」。
2. **不做诊断、不下结论**：不问卷打分、不输出「你今天很焦虑」类总结；阿寅/系统只帮忙**看见**，不替用户定性（**C-01**、**C-03**）。
3. **严重痛苦与风险不忽视**：用户流露自伤、伤人、崩溃等**危机信号**时，**必须**走现网倾诉 **Layer 0 安全链**（语义危机层 → 固定转介 → 必要时锁到退出应用前），规格见 [`NOTICING_ONE_LINE.md`](./NOTICING_ONE_LINE.md) §1 层序 · 已合 **T90–T92**。  
   - **Daily Noticing 不是**危机评估工具；若未来入口与倾诉/觉察一句共用文本框，**禁止**用生成问句绕过输出闸。  
   - **不得**因「我们不做治疗」而弱化或隐藏求助资源（当地资源、免责声明见 **T97** 过关线口径）。
4. **倾诉（Confide / 觉察一句）职责分开**：倾诉 = 被听见 + 安全；Daily Noticing = 结构化自我观察练习。**禁止**把每日觉察做成第二条开放生成聊天。

## 4. 缺口定义（Daily Noticing · v0 方向）

### 4.1 用户故事（Brief 前锁方向）

Kelly 某天不想开表，只想花 **1～3 分钟**看看自己今天怎样。她走进 **Daily Noticing**，看到 **一至四个固定问句**（不必一次答全），自己写或点选即可；没有「达标」「连续天数」压力；阿寅**不**在结尾给人生建议或心理诊断。

### 4.2 第一刀内容引擎（PO 2026-11-26 收紧）

| 项 | 本锁 |
|---|---|
| 问句来源 | **固定句库**（locale 切片），Brief 阶段审题 |
| 轮换 | **按规则轮换**（例如按日 `dateKey`、近 N 日不重复），与 `daily-wisdom` / Quiet Line **分池分 key** |
| AI / 生成 | **第一刀禁止**。不调用 companion 生成问句；不新增需对抗测试的生成路径。理由：与 [`NOTICING_ONE_LINE.md`](./NOTICING_ONE_LINE.md) · **T100** 输出侧刚性闸同一纪律 |
| 阿寅角色 | 可有一句观察式**收束**（仍来自固定池），**禁止**根据用户输入现场推理结论 |
| 留存评估 | 固定版跑出留存与可选完成率后，**再评估**是否加「AI 选题」（须新 Brief + 输出闸评审） |

### 4.3 候选四问（Brief 审题用 · 非运行时承诺）

英文工程对照（与 Reflection 对齐 tone，**禁止**临床词）：

1. What is happening within you right now?  
2. What emotion is most present today?  
3. What has been occupying your mind?  
4. What do you need to give yourself today?

中文版 Brief 须单独写观察式译法，不得变成「你应该……」。

### 4.4 第一刀禁止

- 第五套「打卡」UI（连签、红点、未做愧疚文案）  
- 0–100 情绪分、性格标签、「心流失败」类文案  
- 与到达 / 回顾 / T52 **抢同一叠层**（须写让位规则，默认轻于 Reflection）  
- **2026-12-08 首包**塞入运行时（**T95** 发包装窗口不插队）  
- 未按 [`task-daily-noticing-v1.md`](./task-briefs/task-daily-noticing-v1.md) 且无 T 号时写 `src/`
