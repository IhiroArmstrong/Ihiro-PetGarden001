## 0. 字段与粒度（本版拍板）

无单独 PO 字段条文时，沿用基准 §3.4 / §8，而**不**把发现稿表（如 B1 `1-01`…）一一复制成登记册主键。

| 列 | 含义 |
|---|---|
| **编号** | 本册主键：`V-*` = 否决项单列；`RR-*` = 组织风险行 |
| **来源维度** | ①–⑩；否决项写 V1–V4 |
| **来源编号** | 发现稿里的 `10-01` / `9-02b` 等，便于回溯，**不是**本册主键 |
| **等级** | 否决 / P0 / P1 / P2 / P3（沿用发现稿；本册不改判） |
| **概率 · 影响** | 高 / 中 / 低（组织判断；标「推断」的不是新证据） |
| **缓解** | 已合代码或已写明的下一步；禁止把「部分好转」写成否决已过 |
| **负责人 / 槽位** | 已有任务代号则写 T 号 + [SCHEDULING_GLOSSARY.md](../SCHEDULING_GLOSSARY.md) §1 槽位；否则 **待治理登记** |
| **触发信号** | 什么现象出现时必须重开这条，而不是等下次完整审计 |
| **状态** | 开放 / 部分缓解 / 已处理（残余） / 候选未编号 / 通过（残余） |

B1 正文已写明：发现稿里的 P2/P3 **不是**已编号的登记册行。本册对内部维护债按**主题合并**；P0/P1 与否决项 **不合并、不稀释**。
