## 3. 第一版对外只许两类非危机句

第 0 档 = 现网安全层（字面 → 语义危机 0.78 → 修辞确认 → 现有求助固定句）。不另造危机分类器。

非危机只许：

- **A 接住**
- **B 邀你坐一会儿**（先接住，可选邀请，明说不坐也可以，不自动开练习）

**不做**轻松闲聊档。两类里每一句都必须在「其实是危机」时同样安全：路由把 A 判成 B 或反过来，**不得**产生安全代价。分离试验不再作为开门条件。

禁止在危机语境里变味的方向（句库 lint 落地，见句库 Brief）：休息 / 歇歇 / 放下 / 解脱 / 不用再撑；辛苦了 / 你已经尽力了；没关系 / 会好的 / 别想太多；我会一直陪着你 / 只有我懂。
