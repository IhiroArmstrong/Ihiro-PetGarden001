# Task Brief B4b — 可访问性与多语言审计

- 所属基准：`AUDIT_BASELINE.md` v1.1
- 负责维度：⑦ 可访问性与国际化（6%）
- 建议执行方式：独立新会话，一个会话只做本 Brief
- 输出目录：`docs/audit/findings/<日期>/`

## 1. 目标

评估产品对辅助技术用户和多语言用户是否可用、是否一致：WCAG 2.2 AA 关键项、屏幕阅读器可用性、多语言无截断与混用、日期时区与数字格式正确；找出不足并给出优化计划。

## 2. 范围

**纳入：**

- 用 axe 或等价工具的可访问性扫描；色彩对比、动效减弱、语义与 ARIA、关键任务的屏幕阅读器抽测
- i18n：硬编码扫描、占位符与复数、文本膨胀导致的截断、多语言混用、AI 输出语言一致性
- 日期/时间/时区/数字/货币格式；周起始日；跨日夜间逻辑

**不纳入：**

- 英文/欧美文案「母语级」质感（见 B4a）
- 冷启动与常驻资源等性能指标（见第 0 轮事实底稿 + B4a 解读）

## 3. 输入

- `docs/audit/AUDIT_BASELINE.md`（必须先通读）
- `docs/audit/facts/<日期>/`（第 0 轮。网页类扫描仅针对**宣传站** `marketing-site/`，不用于桌面练习壳）

## 4. 检查清单

- [ ] 用 axe 或等价工具扫描，列出违规项及对应 WCAG 2.2 AA 条款
- [ ] 色彩对比度、字号可缩放、动效减弱（prefers-reduced-motion）、闪烁与自动播放控制
- [ ] 语义与 ARIA：关键控件可访问名称；动态内容 live region
- [ ] 屏幕阅读器抽测（NVDA / VoiceOver）：至少 2 个关键任务
- [ ] i18n：硬编码、占位符、截断、混用
- [ ] 日期/时区/数字/货币；欧盟无障碍法案（EAA）适用性初判（标「法务确认项」，不下法律结论）

## 5. 输出格式

产出文件：`docs/audit/findings/<日期>/B4b-a11y-i18n-findings.md`。

评分表须含「检状态」列（已检 / 部分已检 / 未检）。未检项不得给 0–4 分。

## 6. 证据要求

- a11y：附工具原始报告路径 + 违规元素选择器/文件位置
- 屏幕阅读器：附环境、任务步骤、观察记录

## 7. 通用规则

见 `AUDIT_BASELINE.md`「审计原则」「证据要求」「发现条目标准格式」。只读审计；不写产品代码。

## 8. 完成标准（Definition of Done）

- [ ] 维度 ⑦ 有检状态、得分（若已检）或「未检」说明与覆盖率
- [ ] a11y 违规清单与 i18n 问题清单已产出
