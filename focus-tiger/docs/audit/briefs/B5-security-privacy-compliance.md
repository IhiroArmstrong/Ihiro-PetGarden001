# Task Brief B5 — 安全、隐私与合规审计

- 所属基准：`AUDIT_BASELINE.md` v1.1
- 负责维度：⑨ 安全、隐私与合规（10%）；**含一票否决项 V1、V3、V4**（v1.1 收窄表述见基准第 4 节）
- 建议执行方式：独立新会话，一个会话只做本 Brief
- 输出目录：`docs/audit/findings/<日期>/`

## 1. 目标

评估产品在数据收集、同意、备份与上传、存储与传输安全、依赖与密钥管理方面是否达到面向欧美用户展示的最低工程要求；识别否决项与硬伤；**不出具法律意见**。

## 2. 范围

**纳入：**

- 所有用户数据的产生、存储、传输、上传、备份、删除路径
- 研究共修（Practice Study）数据方案与同意页三语文案、上传接口
- 数据备份与恢复、邮件订阅、支付/订阅（Stripe 等）、权限与 entitlement
- 依赖与供应链、密钥与配置、构建与发布产物

**不纳入：**

- 模型输出内容质量与危机路由行为学细节（见 B6；**「数据是否被不当外传」始终归本 Brief**）

## 3. 输入

- `docs/audit/AUDIT_BASELINE.md`（必须先通读）
- `docs/audit/facts/<日期>/`（**须含**：网络请求与同意对照、依赖/漏洞扫描、密钥历史扫描摘要）
- 仓库全部源码、`docs/`、PR、任务账

## 4. 检查清单

### 产品与合规声明（先于「新做年龄闸/医疗合规项目」）

- [ ] **非医疗 / wellness 声明**是否在用户**可见**位置出现（如 `?` 简介卡 en+ja 路径；给出界面路径或字符串 key + 截图证据）
- [ ] **非儿童产品**声明或等效用户可见提示是否存在；**无证据前不得建议**新增年龄闸或大规模医疗合规项目（若建议，标 `[假设]` 并写验证）

### 数据与否决项

- [ ] **数据地图**：每一类数据（来源/用途/存储/是否离设备/保留期/删除）
- [ ] **V1**：仅当**数据离设备**且无有效同意时否决。`facts/` 须含 **同意文案与实际网络请求对照**。用户主动备份寄送：单独表列出触发点、说明是否清楚
- [ ] 同意与撤回、捆绑、三语一致性；撤回后是否停止上传；已上传数据删除路径（工程视角）
- [ ] 数据最小化与匿名化；日志是否含个人内容（含 Confide；细节可与 B6 交叉引用）
- [ ] 用户权利（访问/导出/删除）：工程实现对照 GDPR/CCPA **要点**，结论写「缺口/无缺口」，**法务确认项**单列
- [ ] **V4**：用户数据是否**存在可验证的恢复路径**（备份/导出/迁移）。**特别核对（P1 风险候选）**：桌面改名 / 数据目录迁移（如 Application Support 路径变更）导致界面**像**「进度清空」时，**产品内**是否提示用户使用**改名前导出的备份**恢复？若仅见于仓库文档、应用内无提示 → **登记为 P1 风险**，**不是** V4 否决
- [ ] 传输与存储：TLS、本地与备份加密策略、密钥管理
- [ ] 接口安全：认证、限流、校验、越权、日志脱敏
- [ ] STRIDE：至少覆盖 本地应用 / 上传接口 / 支付订阅 / AI 调用 边界（Threat 列表即可）
- [ ] **V3**：面向用户安装产物的依赖漏洞；**传递依赖**；许可证；锁文件；供应链脚本风险
- [ ] **密钥扫描**：当前树 + **历史提交**（报告只写「发现/未发现 + commit 范围」，**禁止**复述密钥）
- [ ] 语音/本地 AI 等高危操作：确认、误触发、越权
- [ ] 第三方服务与子处理者清单；隐私政策与实际行为一致性（**法务确认项**）
- [ ] 支付与订阅：欧盟消费者等（**法务确认项**）

## 5. 输出格式

产出文件：`docs/audit/findings/<日期>/B5-security-privacy-compliance-findings.md`。

须含：`数据地图表`、`网络请求清单`、`同意与请求对照表`、`STRIDE 威胁表`、**`否决项判定表（V1/V3/V4 + 检状态）`**。

## 6. 证据要求

见 `AUDIT_BASELINE.md` 第 6 节；密钥与合规额外：

- 不得在报告正文重复密钥内容
- 合规结论统一为「对照 XX：存在/不存在缺口」+ 「法务确认项」列表

## 7. 通用规则

只读审计。未检**不打分**。P0 含否决时顶部 `🚩`。

## 8. 完成标准（Definition of Done）

- [ ] V1/V3/V4 每一项有**通过/未通过/未检**+ 证据指针
- [ ] 已完成改名迁移提示核对（见 V4 特别项）并**显式结论**
- [ ] 「法务确认项」列表独立成段
