## 1. 诊断（问题在哪）

已有结构是 **Reward Progression**（练习 → 分数 / 莲花 / 徽章 / 印 / 寅币 / 珍藏）。用户看得见「做了多少、解锁多少」，还不够感到：

> 我和 Yin 一起走了这么久，而且 Yin 真的见证了我的变化。

要补的是 **Relationship + Identity Progression**：关系加深，不是角色变强。

**不**再堆徽章。**不**推翻 `score / lotus / badge / seal / coins`。

## 4. 阶段（内部，不是等级）

Yin **不升级**。关系可以进入不同深浅。

内部可用 0–6 键（First Meeting → Walking Together）给 Journey **分组着色**。

**禁止（P0 即生效的产品禁令）：**

- 主界面 / HUD 显示 Stage N、Level、经验条
- 把 `score ≥ n` 直接映射成阶段
- 把阶段名硬编码成用户可见句子（门槛日后会调，已读过的措辞不能绑死）

阶段观察维（推导用，**不是**新累计账本）：Practice / Consistency / **Return** / Variety（可选，不得挡阶段）/ Reflection（只用已有到场选择，不逼写日记）。

## 5. Keep Going 与 Come Back

连续（7 / 21 / 100）已有 MilestoneGlow。成长还必须看见 **中断之后回来**。

| 概念 | 是 | 不是 |
|---|---|---|
| **Keep Going** | 连续练习日被安静记得 | 强迫签到、断了就惩罚 |
| **Come Back** | 练习日出现缺口后再出现新的练习日 → 「You came back.」 | 不计分、不上榜、不比连续「更高级」 |
| **Reset & Return（#636）** | 同一次专注被打断后的短练习 | **≠** 隔日/隔周归来 |

P0 验收：新用户不吵；断签再来不愧疚；老用户打开 Journey 能感到被记得。

## 6. Yin Memory（练习见证，六条）

系统保存**成长里程碑**，不是假装复杂人格。

1. First practice  
2. 7 days of returning  
3. 21 days  
4. First return after a pause  
5. First different practice (Sit / Breath / Honesty 等扩到第二种)  
6. 100 days of returning  

可选第七条（池已存在，可进同一列表）：First lotus。**不**为此新做徽章。

落点：**扩 Journey Log**，不新开 Growth Album，不占用珍藏「记忆小册」页签（那条仍是「我选择留下的」）。

静默入账；用户打开 Journey 才看见。禁止每次 +1 / New Evolution 弹窗。

**≠** `YIN_PERSONAL_MEMORY.md`（倾诉侧、要同意）。  
**≠** YPE `returns_often`（内部 Pack，不进 Confide L3）。
