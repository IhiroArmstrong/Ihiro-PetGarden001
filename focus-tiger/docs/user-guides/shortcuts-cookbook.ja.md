# ショートカット手順 · Focus Tiger

コピーして使ってください。これは Apple / Things / Raycast / Alfred の公式プラグインではありません。アプリは集中モード・ヘルスケア・Things を読みません。

**パソコン版（インストール済み）の座り URL:**

`focus-tiger://app/?product=1&start=sit&min=5`

**ウェブ:** いま使っている練習ページに同じクエリ（`?product=1&start=sit&min=5`）。宣伝サイトのトップ（`twinsology.com`）には置かないでください。パソコン版が入っていないと `focus-tiger://` は何も起きません。

座れる分数は `1` / `3` / `5` / `10` / `20` だけです。ほかの数字は無視されます。支払い中・会話中・すでに座っているときは、リンクは二場目を開きません。

---

## 1. ワンタップ · 5分の座り

1. **ショートカット** を開く。
2. 新規 → 操作 **URLを開く**。
3. 上のパソコン URL（またはウェブ URL）を貼る。
4. 保存。iPhone ならホーム画面に置けます。

制限: `focus-tiger://` はパソコン版が入っているときだけ。ウェブは通常の Safari。アプリ内ブラウザでは失敗しやすいです。

---

## 2. カレンダー · アプリから追加

1. アプリで毎日の座りリマインダーを先に設定。
2. **カレンダーに追加** で `.ics` をダウンロードし、カレンダーに取り込む。
3. 予定を開くと同じ座り URL が開きます。

これは **同期ではありません**。アプリ側の時刻を変えたら、もう一度書き出してください。古い予定が残ったり、二重になったりすることがあります。「アプリと常に一致」とは書かないでください。

---

## 3. 集中モード · 同じ URL を開く

アプリは集中モードを読まず、Focus Filter も入れません。

1. **ショートカット** → **オートメーション**（またはシステム設定 → 集中モードからショートカットを実行）。
2. 集中が **オン** になったとき（または指定時刻）に、§1 と同じ URL を開く。
3. 会議中に突然座り始めたくなければ **実行前に尋ねる** をオンに。

Mac のオートメーションは OS によって違います。動かないときはカレンダーかランチャーを使ってください。

---

## 4. Things · 自分のタスクだけ（プラグインなし）

公式拡張はありません。傾きの原文を `things://` に書いて戻すこともしません。

- Things のタスク **メモ** に座り URL を置く。
- または自分のショートカット「URLを開く」を Things から呼ぶ。

---

## 5. Raycast / Alfred

| アプリ | 手順 | URL |
|---|---|---|
| Raycast | Quicklink を作り、パソコンの座り URL を貼る | `focus-tiger://app/?product=1&start=sit&min=5` |
| Alfred | Workflow → **Open URL** | 同じ |

分数を差し込むなら `1` / `3` / `5` / `10` / `20` だけ。パソコン版が無いと何も起きません。

---

## Apple ヘルスケア

マインドフル分数の記録は **初期オフ** のままです。この手順ではオンにしません。あとで設定でオンにしても、書き込みはあなたが入れたショートカット経由だけです。アプリはヘルスケアを読みません。

---

## これは次のものではありません

- Things / Notion / Slack / Zapier の公式プラグイン
- 別の URL スキーム
- 最初の Mac インストール包にアプリ内ヘルプが入ることの約束
