## 1. 引导简介（问号打开的那一组）

### 1.1 现状怎么「阻断」

产品面已经收窄成两件事：薄荷绿点只悬停出 tip（指针离开即收，**不阻断**）；点问号只出产品简介，不再铺一堆 tip。

真正阻断的是**点按钉住**的简介栈，不是悬停 tip：

| 层 | 阻断方式 |
|---|---|
| 全屏遮罩 | 固定铺满视口、半透明压暗 + 模糊、整层可点；点遮罩会关卡（隐私页开着时会连隐私一起关） |
| 简介卡 | 居中、标成必须处理的对话框；要关须点「知道了」或点遮罩 |
| 免责全文卡 | 从简介里再点开的第二张对话框，须点关闭 |
| 隐私说明 | 从简介点开；共用上面那张全屏遮罩；含可勾选项（本地记忆 / 相关同意） |
| 实验室免责首卡 | 仅调试参数才会出，须点关闭；默认产品路径不出 |

悬停问号：简介贴在按钮旁、**没有遮罩**，指针离开后会收。点按才会变成「罩住全屏、直到你关掉」。

### 1.2 打算怎么呈现

**我认为最合理的是：点按也沿用现在的「贴在问号旁的玻璃简介卡」，拿掉全屏遮罩；不要改成悬停小字条组件。**

理由：简介里有滚动正文、免责链接、隐私勾选，不是一句 label。现成的悬停小字条只适合短句、离开关闭，装不下隐私页。玻璃卡已经在悬停路径用过，点按只需与悬停共用同一张卡，区别只是点按后钉住、直到点卡上的关闭。

较弱备选：整卡改成悬停小字条 —— 隐私与免责放不下，仅当你决定把隐私挪到偏好设置里才合理。

次级页：

- 免责全文：仍从简介内链接打开，叠在简介上方的小玻璃卡，**无全屏遮罩**。
- 隐私说明：仍从简介打开；**默认同样无全屏遮罩**。勾选是否必须「处理完才能点下面」，见边界情况，不在本方案里擅自改同意语义。

实验室免责首卡不在本刀产品路径，实现时保持原样或随手去掉对话框标记即可，不单独立项。

### 1.3 保持不变

- 何时出现：仍是点/悬停问号；仍禁止点问号铺开其它 tip。
- 文案、隐私勾选、免责链接、桌面内存说明、页脚。
- 关闭回调、已读标记（点问号仍可记「帮助已看过」）。
- 薄荷绿悬停 tip 的触发与收起。

### 1.4 不再阻断之后的边界

| 情况 | 判断 |
|---|---|
| 简介还开着，用户点了坐下 / 起来 / 菜单 | 预期：下面点得动。实现时应在进入忙碌叠层时**自动收卡**（与「仪式中不喷 tip」同一类门闩），避免简介飘在专注画面上。 |
| 隐私页开着时误点下面，勾选没做完 | **不确定，需 PO 判断**：是允许随时点走（同意保持未改），还是隐私页仍要求先关再操作。 |
| 窄屏简介挡住坐下按钮 | 卡片贴问号、限制高度可滚；若仍挡主按钮，优先缩高度而不是恢复全屏罩。 |
| 与提醒条、留痕底条抢层 | 简介不再铺全屏后，层叠登记要改「遮罩」那一行；实现时按层叠表改，不另造更高的罩。 |

## 2. 小圈留痕 / 选句

### 2.1 现状怎么「阻断」

典型出现在一场足够长的练习起来之后（约三秒底条），不是专注计时正中间；忙碌叠层占用满时会推迟出现。

| 层 | 阻断方式 |
|---|---|
| 留痕底条 | 底部居中玻璃条；**没有**全屏遮罩。标成对话框但未标「必须先处理」。点「留下痕迹」或「跳过」。条在时会占用一层忙碌名额，其它同类条可能让路。 |
| 选句列表 | 屏幕中央玻璃列表；**没有**全屏遮罩，周围花园理论上点得到。取消可回到底条。选句期间换占另一层忙碌名额，底条暂时藏起。点选后提交网络（用户点了才发，不是后台请求）。 |

所以：底条已经接近非侵入；审计里「像模态」主要来自中央选句列表 + 对话框角色 + 叠层占位，不是一块点不透的黑罩。

### 2.2 打算怎么呈现

**我认为最合理的是：底条外观与文案不动；选句改为从底条向上展开的同一条玻璃列表，不要居中大卡，也不加全屏遮罩。**

理由：用户已经在底部做「留 / 跳过」决定，选句是下一步，不应跳到屏幕中央。现成悬停小字条装不下一列短语按钮。

较弱备选：整段改成一次性短 tip「可以留一句」——会丢掉选句与跳过，和现有圈内痕迹职责冲突，除非 PO 砍掉选句。

叠层占位：建议**先保持**（避免与菜单 / 接地练习抢点击）。这不是系统确认框，只是「同时只亮一条底部交互」。若你希望留痕出现时仍能开菜单，实现开工时再单列一条「是否释放占位」。

### 2.3 保持不变

- 一场只提示一次、时长门槛、推迟到不忙碌。
- 留 / 跳过 / 取消回条 / 选句提交与失败红字。
- 回应他人痕迹的选句（同一套列表，仅文案套不同）。

### 2.4 不再阻断之后的边界

| 情况 | 判断 |
|---|---|
| 选句开着时点老虎额头 / 坐下 | 周围本就可以点；实现后更明显。若正在提交，按钮已禁用，点别处不应取消这次提交。 |
| 选句与摸头热区重叠 | 历史已用更高一层挂在页面根上解决；展开式底栏须复测窄屏列表每一行都点得到。 |
| 条还在时开菜单 | 若仍占忙碌名额，菜单可能暂时不出现——这是占位策略，不是罩子。是否改占位另拍。 |
